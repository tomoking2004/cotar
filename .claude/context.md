# 視覚言語モデルにおけるタスク類似性に基づく内部表現整合学習に関する検討

中野 友晴 ／ 2026-08-23 時点

## 0. 要約

視覚言語モデル（VLM）が画像への質問に答えるとき，**同じ解き方で解ける質問どうしは，モデルの内部表現も互いに近いだろうか．** 近くないなら，近づくように学習を課したとき，何が得られて何を失うだろうか．これが本研究の問いである．「解き方が同じ」は，質問を解く演算子の系列——タスク署名——が一致することで代表させる（→ [§2.1](#21-解き方を比べられる形にするタスク署名)）．署名が一致する質問どうしの内部表現を互いに近づける項を，通常の学習に足す——これを**整合**と呼ぶ（→ [§2.2](#22-整合損失)）．

**本研究の目的は，整合が表現に何をし，何をしないかを測ることである．** 正解率を上げることは目的ではない——上がらないこと自体が，理由とともに測られた結果である．目的を六つの問いに分け（→ [§1.3](#13-六つの問い)），四つに答え，二つを未回答のまま残した．

| | 問い | 答え |
| --- | --- | --- |
| 問い1（読み取り） | 表現は，署名を線形に読み取れる形で担うか | 整合前でも 83.1% の問で当てられるが，表現どうしの距離としてはわずかに近いだけである．整合はこれを **95.9%** へ上げる（+12.8pt） |
| 問い2（組成） | その効果は，損失が教えていない演算子の組み立てにまで及ぶか | **及ぶ**——分類器の当てはめに使っていない組み合わせについて，演算子の集合を丸ごと当てた問の割合が 35.8% から 45.2% へ（+9.3pt） |
| 問い3（代償） | 正解率を，損なわないか | **損なわない**——低下は最大でも 1.25pt |
| 問い4（利得） | 正解率は，上がるか | **上がらない**——誤りは署名より後の段階で起きている |
| 問い5（忠実性） | モデルは，整合した構造を使って答えを出しているか | **未回答**——最優先で測る（→ [§7.1](#71-問い5に答える整合した構造は迂回されていないか)） |
| 問い6（頑健性） | 整合した表現は，画像を揺らしても保たれるか | **未回答**（→ [§7.2](#72-問い6に答える画像を加工したとき整合した表現は安定するか)） |

**問い2 の答えが，本研究の非自明な所見である．** 問い1 の増分そのものは，用いた損失の定義から予想できる——同じラベルの表現を近づける損失は，そのラベルを線形に分離しやすくするからである．予想できないのは次の点である：損失が与えているのは「署名が同じか違うか」だけなのに，整合後の表現は，分類器が一度も見ていない演算子の組み合わせを言い当てる．

**この数字は，質問の形を読んで当てたものではない．** 質問の語数や答えが yes/no かといった，質問の形式の特徴を回帰で除いても，整合の効果は 12.76pt から 12.76pt へ動かない．形式の特徴だけから当てると 35.3% にとどまり，常に最も多い署名と答える 28.8% をわずかに上回るだけである（→ [§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた)）．

**「モデルを解釈できるようになった」とは，まだ言えない——それが問い5 である．** 表現から署名が読み取れること（デコード可能性）と，モデルが答えを出す過程でその署名を使っていること（忠実性）は別だからである．とくに，整合した構造が答えの生成に関与しない方向へ押し出された（迂回された）可能性を，まだ排除できていない．この判定が済むまでは，整合の強さや掛ける層を変えて試しても意味がない（→ [§7.1](#71-問い5に答える整合した構造は迂回されていないか)）．

**答えは一点についてのものである．** 整合の強さ $\lambda = 0.1$，第16層，単一モデル，単一データセット——設計を変えた測定は一つもしていないので，「この設定ではこうなった」より広くは言えない（→ [§6.3](#63-答えの及ぶ範囲)）．

**問い1–4 についての記述はすべて実施済みで，測定は実際に走って結果が保存されている．問い5・問い6 と [§7](#7-次の一手未実施) は未実施の計画である．**

## 1. 背景と問い

### 1.1 出力が同じでも，内部表現が同じとは限らない

VLM の頑健性は通例，入力を少し変えても答えが変わらないこと——出力の頑健性——で測られてきた．しかし Wani らは，**答えが変わらないまま内部表現が大きく変化する**ことを示した．画像に，正解を変えない加工（平行移動・拡大縮小・回転や，画像への文字の重ね書き）を施すと，答えが変わらなかった問についても内部表現は変化する．幾何的な加工での変化量は小さいが，文字の重ね書きでは，無関係な画像を入れたときの変化量に迫ることがある．

つまり，**出力の頑健性は，表現の頑健性を含意しない**——出力を見ているだけでは，内部で何が起きているかは分からない．著者ら自身は対処法を示さず，未解決の課題として残している．

### 1.2 本研究の目的と，すること

Wani らが見ているのは「同じ入力を揺らしたときの変化」である．これに対して，**別々の質問どうしの表現が互いに近いかは分かっていない．** 後者が本研究の問いである．

**目的は，同じ解き方で解ける質問の表現を近づける操作が，内部表現に何をし，何をしないかを測ることであって，正解率を上げることではない．** 上がらないこと自体が，理由とともに測られた結果である．

**することは一つである．** 署名が一致する質問どうしの内部表現を明示的に近づける項を，通常の学習に足す（→ [§2](#2-提案手法署名が一致する質問の表現を近づける)）．整合の有無とラベルの意味だけを変えた三つの群を乱数種3つで学習し（計9回，→ [§3](#3-実験設定)），表現の側と出力の側の両方で測る（→ [§4](#4-検証方法)・[§5](#5-結果)）．

### 1.3 六つの問い

以下，問いを番号と名前で呼ぶ．**前の四つは実施済みで，検証方法・結果・答えを同じ番号の節に置いてある．後の二つは未実施で，答えるための測定を [§7](#7-次の一手未実施) に置いてある．**

| | 問い | 測る対象 | 状態 |
| --- | --- | --- | --- |
| **問い1（読み取り）** | 整合前の表現は署名をどれだけ担っており，整合はそれを変えるか | 表現の中身 | [§4.1](#41-問い1の検証署名を当てるプローブ) → [§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) |
| **問い2（組成）** | その効果は，損失が一度も教えていない構造——署名がどの演算子から組み立てられているか——にまで及ぶか | 表現の中身 | [§4.2](#42-問い2の検証演算子を当てるプローブ) → [§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) |
| **問い3（代償）** | 正解率を，損なわないか | 出力 | [§4.3](#43-問い3の検証正解率) → [§5.3](#53-問い3正解率への代償はあっても僅かである) |
| **問い4（利得）** | 正解率は，上がるか．上がらないなら，誤りはどこで起きているか | 出力 | [§4.4](#44-問い4の検証署名の出現回数での層別と正誤で分けたプローブ) → [§5.4](#54-問い4正解率は上がらず誤りは署名より後の段階で起きている) |
| **問い5（忠実性）** | モデルは，整合した構造を使って答えを出しているか | 表現の使われ方 | **未回答**（→ [§7.1](#71-問い5に答える整合した構造は迂回されていないか)） |
| **問い6（頑健性）** | 整合した表現は，画像を揺らしても保たれるか | 表現の安定性 | **未回答**（→ [§7.2](#72-問い6に答える画像を加工したとき整合した表現は安定するか)） |

**問い1–4 は「整合は何をしたか」を，問い5–6 は「その変化は，何かに効くのか」を問う．** 前者は9回の学習が残したもので測れ，後者は新しい測定を要する．

**問い5 と問い6 は，答えが出ていないだけで，本研究の問いである．** 問い5 を外せば「読み取れる」ことだけを主張して「使われている」かを黙ることになり，問い6 を外せば [§1.1](#11-出力が同じでも内部表現が同じとは限らない) で挙げた出発点の問題に応えないまま終わる．**問い1 と問い2 が答えるのは「読み取れるか」までで，そこから先は問い5 と問い6 が引き受ける．**

**問い1 と問い2 はどちらも表現の中身を測るが，別の量である．** 問い1 が問うのは署名そのものを言い当てられるかで，問い2 が問うのはその署名を組み立てている演算子を言い当てられるかである．整合損失は前者だけを教えており，後者は一度も教えていない．

**問い4 が利得を期待するのは，署名ごとに表現がまとまるなら二つの利点がありうるからである**——未見の演算子の組み合わせへの汎化と，学習にほとんど現れない署名への転移である．前者は問い2 と同じ言葉で呼べてしまうが，測る対象が違う：問い2 は表現から演算子を読み取れるかを，問い4 はその質問に正解できるかを問う．

**六つの重みは，同じではない．** 問い1 と問い2 が現時点での主張であり，**問い5 は，その主張が何を意味するかを決める**——迂回されていれば，問い1・問い2 の答えは表現の形式が変わったことしか意味しない．問い3 は，内部状態を読めるようにする手法にとって満たせなければ手法そのものが成り立たない必須条件であり，問い4 は満たせなくても成り立つ期待である．問い6 は，出発点の問題に応えるかを問う．

### 1.4 表現に手を入れた先行例

表現のレベルに手を入れて正解率を上げた前例が，VLM に既にある．VLsI（Lee ら）は，大きい VLM が層を追って推論を進めていく様子を小さい VLM に写すことで，小さいモデルの正解率を上げた．**答えだけを教えるより，途中の表現まで教えるほうが，学習に届く手がかりは多い**——この前提の傍証として援用する．ただし VLsI は外部の大きいモデルを教師とする蒸留であり，しかも層どうしの表現を直接突き合わせるのではなく，各層の特徴をいったん自然言語へ写してから合わせる．本研究は教師を持たない同一モデル内の自己整合で，表現そのものを直接近づける．したがって傍証にとどめ，中核の仮説の支柱には据えない．

## 2. 提案手法——署名が一致する質問の表現を近づける

### 2.1 解き方を，比べられる形にする——タスク署名

GQA は画像への質問応答データセットである．各サンプルは画像・質問文・答えに加えて **functional program** を持つ．program は答えに至る道筋を段階ごとに書き下したもので，各ステップが演算子と引数と依存先を持つ．“Who is wearing the dress?” なら

| 順 | 演算子 | 引数 | 依存 |
| --- | --- | --- | --- |
| 0 | `select` | `dress` | — |
| 1 | `relate` | `person, wearing` | 0 |
| 2 | `query` | `name` | 1 |

——「ドレスを選び，それを着ている人物へ関係をたどり，その名前を答える」．**この program が付いていることが GQA を採用した理由**で，解き方が同じかどうかを人手を介さずに判定できる．

ここから演算子の系列だけを取り出したものを**タスク署名**（以下，署名）と呼ぶ．上の例なら `select > relate > query` である．“What is the boy wearing?” も同じ署名なので同じタスク，“What color is the cup?” は `select > query` で別タスクとなる．タスク類似性は連続量ではなく署名が一致するか否かの二値とし，一致する対を**正例対**（整合損失が近づける対）とする．

以降，「解き方が同じ」はすべて「署名が一致する」の意味で用い，測定はすべて署名について行う．**署名が解き方の正しい形式化かどうかは，本研究では検証していない**（→ [§6.3](#63-答えの及ぶ範囲)）．

**引数を捨てるのは意図的である．** 引数まで一致を求めると，正例対がほとんど同じ質問になってしまい，表現が近いのが当たり前になる．その帰結として，同署名の質問は答えが互いに違う（`select > relate > query` の答えは “women” だったり “tie” だったりする）．

**注意すべき交絡がある．** GQA の質問文はこの program から自動生成されているので，質問文の言い回し——どの語が現れ，どの2語が隣り合うか——と署名は，作りからして相関している．極端な場合には，演算子の名前がそのまま質問文に現れる（報告用データに現れる 118 種の演算子のうち 10 種が該当する——`and`・`or`・`common` など）．質問文を読むだけで分かってしまう分は，差し引かなければならない（→ [§4.1](#41-問い1の検証署名を当てるプローブ)）．

### 2.2 整合損失

バッチ $B$ 件について，モデルが答えを出す途中で保持している内部表現を $h_1,\dots,h_B \in \mathbb{R}^{H}$，その署名ラベルを $y_1,\dots,y_B$ とする．正規化した表現とそのコサイン類似度を $z_i = h_i / \lVert h_i \rVert_2$，$s_{ij} = z_i^{\top} z_j$ とし，$i$ の正例の集合を $P(i) = \{\, j \neq i \mid y_j = y_i \,\}$ と書く．**整合損失**は署名をラベルとする supervised contrastive loss（SupCon——同じラベルの表現どうしを近づけ，違うラベルの表現どうしを遠ざける損失）であり，

$$
\mathcal{L}_{\mathrm{align}}
\;=\;
\frac{1}{|\mathcal{I}|}\sum_{i \in \mathcal{I}}
\left[\,
\log \sum_{j \neq i} \exp\!\left(\frac{s_{ij}}{\tau}\right)
\;-\;
\frac{1}{|P(i)|} \sum_{p \in P(i)} \frac{s_{ip}}{\tau}
\,\right],
\qquad
\mathcal{I} = \{\, i \mid P(i) \neq \varnothing \,\}
$$

第1項がバッチ全員との近さ，第2項が同署名との近さで，**この差を小さくすることが，同署名だけを相対的に近づけることにあたる．** 和を取る相手 $\mathcal{I}$ は，同署名の相手がバッチにいる $i$ だけである——いなければ近づける先が無く，第2項が定義できない．$\tau$ は温度で，学習可能なパラメタとし初期値を $0.07$ とする．

全体の目的関数は $\mathcal{L} = \mathcal{L}_{\mathrm{LM}} + \lambda\, \mathcal{L}_{\mathrm{align}}$ で，**整合の強さ** $\lambda$ は $0.1$ とする．$\mathcal{L}_{\mathrm{LM}}$ は**答えのトークンにのみ**掛かる通常の交差エントロピーである．

### 2.3 どこに掛けるか——射影を挟まない中間層の一点

整合損失は，生の内部表現に直接掛ける．SupCon の原論文は，表現を低次元へ写す小さなネットワーク（射影 head）の出力の上で損失を計算している．本研究があえて射影を挟まないのは，**挟むと仮説が反証不能になる**からである——学習可能な射影があれば，内部表現をまったく変えずとも射影の側を変えるだけで損失を下げられてしまう．

**掛ける先は，第16層（全32層の中間）で，質問を読み終えて答えを書き出す直前の位置にあるベクトルそのものである**（次元は $H = 960$）．整合が触るのはこの1つの位置にある1本のベクトルだけで，画像と質問文のトークンはそれぞれ別の位置に手つかずで残る．残る16ブロックはそれらの位置へ注意を向けて読み直せるので，整合が乱したものは後段で計算し直せる．ただし層も位置も，ここ以外は試していない（→ [§6.3](#63-答えの及ぶ範囲)）．

**射影を外しても，迂回の余地は残る．** 学習可能な射影が無い以上，損失を下げるには第16層のベクトルそのものが変わるほかなく，実際に変わった（→ [§3.4](#34-整合が働いたことの確認)）．しかしモデルには，後段が読まない方向の中でそのベクトルを動かすという逃げ道が残っている——このとき署名の構造は表現に載るが，答えの生成には関与しない．射影を外して防げたのは最も安い迂回だけで，どちらが起きたかを判定するのが [§7.1](#71-問い5に答える整合した構造は迂回されていないか) である．

## 3. 実験設定

### 3.1 モデルとデータ

モデルは軽量な VLM **SmolVLM-500M-Instruct** を使う——計算資源の都合による．言語側は32層で，表現の次元は 960 である．

学習は GQA の `train_balanced` で1エポック．943,000 問のうち，同署名の相手がいない 884 問は正例対を組めないので除く．バッチは16 署名を無作為に選び，各署名から2件ずつ引いて $B = 32$ 件とする．1エポックは，残る 942,116 問と同じ件数を引き終えるまで（29,441 バッチ）と定める——署名を単位に引き直すので，各問がちょうど一度ずつ出るわけではない．学習率 $10^{-5}$，勾配ノルムは $1.0$ で打ち切る．**乱数種 42・43・44 の3つで，3群 × 3種 ＝ 9回の学習を行った**（1回 約2時間53分，通しで約26時間）．署名でまとめたバッチを作るのは学習時だけで，評価は自然な分布のまま行う．

報告は `testdev_balanced` 12,578 問で行う．GQA の `test` 分割は答えが伏せて配布されていて手元で採点できず，`testdev` は GQA 自身が，学習には使わせず答えを添えて配る分割として用意したものだからである．**学習・検証・報告の3分割は，質問 ID も画像 ID も完全に排他である**——報告に使う 398 枚の画像は，学習中に一度も現れない．

### 3.2 三つの群

**proposal が「baseline と違い，かつ ablation とも違う」ことによって初めて，差を生んだのが署名ラベルであると言える．** どちらか一方だけでは，対照学習という形式そのものの効果と区別がつかない．

1. **baseline**：$\lambda = 0$．整合損失を掛けない．
2. **proposal**：ラベル $y_i$ を署名とする．
3. **ablation**：$\lambda$ も損失の形も同じまま，バッチの中でラベル $y_i$ を無作為に並べ替える．ラベルを作り直すのではなく並べ替えるので，ラベルの分布と正例対の数は厳密に保たれ，正例対の定義だけが無意味になる．

**ablation は表現を壊すために置く群ではない．** 変えるのはラベルの意味だけである——表現を壊す群を置いても，署名ラベルの効果とモデルを損なった効果とが混ざり，対照にならない．ただし，そう設計したことと，そう終わることは別である（→ [§3.4](#34-整合が働いたことの確認)）．

**この対照が答えるのは「ラベルに意味が要るか」までである．** 並べ替えたラベルは意味を持たないので，proposal との差は意味のあるラベルが要ることを示す．しかし，そのラベルが**署名である必要があるか**は示さない——答えの型のような別の意味のあるラベルで整合しても同じことが起きるなら，[§6.1](#61-答えたこと問い14) の答えは署名についてではなく，意味のあるラベル一般についてのものになる．質問の形式（語数・答えの型）を表現から回帰で除いても効果が動かないこと（→ [§4.1](#41-問い1の検証署名を当てるプローブ)）は，この疑いのうち**表現の側**を塞ぐが，**整合するラベルの側**は塞がない（→ [§7.4](#74-答えが署名に固有かを確かめる別のラベルで整合する)）．

**この対照は，Hewitt と Liang の control task にあたる．** 彼らは，表現から性質を当てる線形分類器（**プローブ**．→ [§4.1](#41-問い1の検証署名を当てるプローブ)）の精度が表現の構造を映しているのか，分類器が課題を覚えただけなのかを分けるために，無作為な出力を割り当てた課題を本来の課題と並べ，その差（selectivity）で読むことを提案した．本研究の ablation はラベルを無作為に置換する点でこれと同じ役割を負う——ただし彼らが語の型に対する出力を無作為化するのに対し，こちらはバッチの中で置換するので，ラベルの分布と正例対の数が厳密に保たれるという違いがある．

### 3.3 乱数種3つの，まとめ方

群ごとの数値は乱数種3種の平均で報告し，ばらつきが読みに効くところには標準偏差を添える（$n$ 個の値の，平均からの偏差の二乗和を $n-1$ で割った平方根．本研究では種の数 $n = 3$ である）．

**群間の比較は同じ乱数種どうしを対にして行う**——同じ種の3群は同じ順序で同じデータを見るので，対にすることで初期化とデータ順序の効果が相殺される．乱数種 $i$ での群 $A$ の値を $x_i^{A}$ と書くと，群 $A$ と群 $B$ の差は，種ごとに引いた $d_i = x_i^{A} - x_i^{B}$ の上で測る．その平均を $\bar{d}$，標準偏差を $s_d$ と書く——どちらも，各群の値についてではなく，$n$ 個の差 $d_1,\dots,d_n$ について上と同じように取ったものである．

$\bar{d}$ 自体が乱数種の引き次第で揺れる量なので，その揺れを標準誤差 $s_d/\sqrt{n}$ で見積もり，$\bar{d}$ の両側にその定数倍を取る：

$$
\bar{d} \;\pm\; t_{n-1,\,0.975}\,\frac{s_d}{\sqrt{n}},
\qquad
t_{2,\,0.975} = 4.303
$$

$t_{n-1,\,0.975}$ は自由度 $n-1$ の $t$ 分布の 97.5% 点で，**標本が少ないほど大きくなる**——$n = 3$ の $4.303$ は，標本が十分あるときの $1.96$ の2倍以上ある．

95% とは「同じ手順で区間を作り続ければ，そのうち 95% が真の差を含む」という意味である．区間が $0$ を含まないなら，差の向きは手元のデータで決められる．**含むなら，「差が無い」ことが示されたのではなく，向きを決められないというだけである．** 標本が3つなので区間は広く，そこから読める上限も緩い．

**同じ設定でも，乱数種を変えれば結果は変わる．** その変わる幅を，設定を変えていない baseline の3本だけからも測っておく．群間の差がこの幅の内側にあるなら，設定の違いによる差なのか，乱数種の違いによる差なのかを区別できない．

### 3.4 整合が働いたことの確認

問い1–4 を測る前に，操作が意図どおり働いたことを確かめる．**proposal と ablation の値は配管の確認であって，仮説の支持証拠ではない**——ここで動く量は，整合損失が直接小さくしようとしている量そのものだからである．baseline の値だけは事情が違う．整合が何も掛かっていない群なので，こちらが動かした量ではなく，整合前の幾何そのものの記述である（→ [§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた)）．

報告用データから抜いた 4,000 件で測る．長さ1に揃えた表現の対を，署名が一致するものと一致しないものに分け，コサイン類似度のそれぞれでの平均を**同署名の類似度**・**異署名の類似度**と呼ぶ．**分離度**はその差を，両者を込みにした標準偏差で割ったもの（Cohen's d）で，$1$ なら「標準偏差1つ分だけ離れている」と読む（割るのは，類似度そのものの大きさに左右されずに比べるためである）．

**分離度は baseline $0.731 \pm 0.029$，proposal $2.469 \pm 0.073$（3.4倍），ablation $0.413 \pm 0.093$ である．** proposal の値は3種でほぼ完全に再現し（標準偏差は平均の3%），ablation では上がらない．整合損失は，設計どおりに働いた．

内訳を見ると，proposal は同署名どうしの類似度も $0.946 \to 0.738$ と下げている．**同署名を近づけたのではなく，同署名の類似度も下がったが，異署名の類似度がそれ以上に下がった**（$0.923 \to 0.218$）結果として分離度が上がっている．ablation は逆に同署名・異署名を問わず類似度 $0.99$ 超で，すべての表現がほぼ同じ向きに集まった．

**その集まり方は，ablation のラベルに情報が無いことの裏づけになる．** 全ベクトルが同じ向きに揃えばどの対も $s_{ij} = 1$ になり，[§2.2](#22-整合損失) の式では $1/\tau$ が打ち消し合うので，温度がいくつであっても整合損失は $\log(B-1)$ になる．$B = 32$ なら $\log 31 = 3.434$ で，ablation が到達した値は3種ともこの $3.434$ である——並べ替えたラベルは，損失が掴めるものを何も残していない．署名ラベルを与えた proposal では $2.12$ まで下がる．

## 4. 検証方法

**問い1–4 の検証方法をここに置く．** 問い5 と問い6 は未実施なので，その測り方は計画として [§7.1](#71-問い5に答える整合した構造は迂回されていないか)・[§7.2](#72-問い6に答える画像を加工したとき整合した表現は安定するか) にある．

### 4.1 問い1の検証——署名を当てるプローブ

表現を入力として署名を当てる線形分類器を当てはめ，それがどれだけ当たるかを見る．**当たるほど，署名の情報がその表現から線形に取り出せる形で載っていることになる．** この道具はこの分野で**プローブ**（probe）と呼ばれるので，以下その名で用いる．長さ1に揃えた表現に線形写像を当てて署名ごとのスコアを作り，最も高い署名をこのプローブの答えとする．学習するのはその線形写像だけである．以下「読み取り精度」と書くのは，評価側でこの答えが正解の署名と一致した問の割合である．

**プローブが読むのは，整合損失が掴んでいるベクトルそのものである**（第16層の，質問を読み終えた1トークン．1問あたり 960 次元が1本）．別の位置や別のプーリングを測っているのであれば，以下の数値は解釈できない．評価時のバッチは正解の答えを含むが，プールする位置は答えより前にあり，各トークンは自分より前の位置しか見られない仕組みなので，正解の混入は構造的に起こりえない．

- 学習側と評価側の両方に例が要るので，**まず 10 問以上ある署名に限る**——報告用の 12,578 問・904 署名から，10,990 問・145 種が残る．
- 残った 10,990 問を，**問ごとに確率 1/2 で学習側と評価側に振り分ける**（乱数種は固定）．
- **学習側からさらに 2 割を取り分けた検証スライスで打ち切る**——検証スライスでの読み取り精度が最も高かった時点の写像で評価し，評価側には一度も触れない．固定のステップ数で全群を打ち切ると，当てはめの速さの違いが，担っている情報の量の違いに見えてしまうので採らない．
- **床**は，評価側で最も多い署名が占める割合である（何も学習せず，常にその署名と答えても当たる下限）．

[§2.1](#21-解き方を比べられる形にするタスク署名) の交絡には，三つの対照を置く．

- **言い回しプローブ**：表現の代わりに質問文の言い回しを入力にした，同じ線形分類器．その語が現れるかどうかを語ごとに 0/1 で並べたものを入力にする——回数ではなく有無で，語の順序は残らない．語順をすべて捨ててしまわないよう，隣り合う2語の組を同じ形に並べたものも作り，両方を測って高いほうを報告する．**これは「質問文の語だけで当たる水準」であって，質問文から原理的に取れる情報の上限ではない**——語の順序も文の構造もほとんど使っていないので，質問文をもっと丁寧に読めばこれより上がありうる．群間の差を測る対照ではなく，得られた値が質問文を読むだけで説明できてしまわないかを見る基準である．
- **書き出しを分離した分割**：質問文の先頭4語が同じ質問は必ず同じ側へ寄せる．**評価側では質問の書き出しが必ず未見になるので，書き出しと署名の対応を覚えるだけでは当たらない**（ただし5語目以降の語まで未見になるわけではない）．寄せた結果，1種が片側だけに落ちて採点できなくなるので，この分割で残るのは 10,978 問・144 種である．
- **タスク形式の残差化**：上の二つは「質問文だけでどこまで当たるか」を競わせる対照だが，表現からタスク形式そのものを取り除いた後に何が残るかは別に測る必要がある．Sahoo らは，3つの推論ベンチマークを 100% で分離していたプローブが，出典・選択肢数・応答長を回帰で除いた途端にチャンスまで落ちる例を示した．本研究では**出典と選択肢数は定義上存在しない**（全問が単一コーパスの同一生成過程から来ており，多肢選択ではない）ので，残るのは長さである．質問の語数・答えの文字数・答えが yes/no かの3つをタスク形式の特徴とし，そこから表現を予測する ridge 回帰を当てて，その予測を引いた残差の上で同じプローブを当て直す．署名ラベルは回帰に一切入らない．また，タスク形式の特徴だけを入力にしたプローブも並べて報告する．

  **残差化は，署名がタスク形式と正当に共有している分も一緒に落とす**——存在確認で終わる手順は実際に yes/no の答えを生む．**したがって残差化後の値は，タスク形式を除いてなお残る量の下限である．**

### 4.2 問い2の検証——演算子を当てるプローブ

[§4.1](#41-問い1の検証署名を当てるプローブ) には反論が立つ——**整合損失は署名どうしの見分けやすさを上げ，プローブは署名どうしの見分けやすさを測るので，学習が自分の教えたことを読み返しているだけではないか．** これを切るために，損失が一度も教えていない構造で測る．整合損失が与えているのは「署名が同じか違うか」だけであり，署名がどの演算子から組み立てられているかも，二つの署名が演算子を共有することも，一切教えていない．

- **ラベルを「使われている演算子の集合」に取り替える**——報告用データに現れる 118 種の演算子のうち，延べ 50 回以上現れる 46 種について，含むか含まないかを並べた 0/1 ベクトルにする（この下限は，次の分割の両側に例が揃うために置いてある）．
- **分割を署名単位で切る**——904 署名のうち 449 種をプローブの当てはめ側，残る 455 種を評価側に置く．評価側の演算子の組み合わせは，当てはめ側に一度も現れない（個々の演算子は当てはめ側にもある）．

  **ここで「未見」と言うのは，プローブにとってであって，モデルにとってではない．** 評価側の署名も，それを組み立てている演算子も，モデルは学習中に見ている．モデルにとって未見の署名を切り分ける測定は [§4.4](#44-問い4の検証署名の出現回数での層別と正誤で分けたプローブ) の $0$ の層であり，別の量である．

報告は AUC と完全一致率の2つである．**AUC** は，ある演算子を含む問と含まない問を1組ずつ取ったとき，含む側により高いスコアが付く割合である——でたらめなら $0.5$，完全に並べ替えられていれば $1$ になる（評価側に正例と負例の両方がある 42 種について平均する）．**完全一致率**は，46 個の予測がすべて正解と一致した問の割合である．当てはめと打ち切りは [§4.1](#41-問い1の検証署名を当てるプローブ) と同じ手順で，検証スライスで見るのはここでは AUC である——打ち切りに使う指標は，いつでも報告する指標と同じものにする．

### 4.3 問い3の検証——正解率

**正解率**は，各ステップで最も確からしい語を選んで（貪欲デコード）作らせた答えを，GQA 公式の評価器で採点した，正解した問の割合である（12,578 問すべて採点，採点漏れ0問）．群間で比べられる損失は $\mathcal{L}_{\mathrm{LM}}$ だけである——$\mathcal{L}$ には整合する群にのみ補助項が乗るので，同じ量ではない．

### 4.4 問い4の検証——署名の出現回数での層別と，正誤で分けたプローブ

**全体の正解率は，頻出する署名に支配される．** 問い4 が期待する利得は，未見の演算子の組み合わせと，学習にほとんど現れない署名という，どちらも稀な側にある——全体の平均を見ているかぎり，そこに効果があってもなくても数値は動かない．「効果が無かった」と「効果が現れうる場所で測っていなかった」を分けるために，問題を層別する．

- 報告用の 12,578 問を，**その質問の署名が学習側に何回現れたか**で $0$／$1$–$10$／$11$–$100$／$101$–$1{,}000$／$1{,}001$ 回以上の五つの層に分ける．最も上の層を開いたままにするのは，一つの署名だけで報告用データの相当部分を占めるので，上限を切らないと頭が他をすべて呑み込むからである．
- **群間の比較は，各層の中で同じ質問集合の上で行う**（[§3.3](#33-乱数種3つのまとめ方) と同じ，種ごとに対にした差）．層ごとに正解率の水準は違うが，その違いは層の中の群間の差には効かない．
- 層別には問ごとの正誤が要る．公式の評価器は全体の値しか返さないので，**問ごとの判定はこちらで採点し直し，その全体値が公式の値と一致することを確かめたうえで層別に使う．** 報告する全体の正解率は，[§4.3](#43-問い3の検証正解率) のとおり公式の評価器のものである．

上がらなかった場合に，その原因が署名の同定にあるのかを分けて測る．[§4.1](#41-問い1の検証署名を当てるプローブ) のプローブを，**モデルが正解した質問と誤答した質問に分けて当てる．** 誤答した質問の表現からも署名が読み取れるなら，誤りは署名を取り違えた結果ではなく，署名より後の段階で起きていることになる．この判定が要求するのは誤答側の読み取り精度の水準だけで，二つの大小ではない——二つに入る質問の中身が違うので，大小そのものは比べられない．

## 5. 結果

3群 × 3乱数種の9回の学習による．群ごとの数値は3種の平均である．

### 5.1 問い1——整合は，署名の読み取り精度を 12.8pt 上げた

**この増分の向きは，損失の定義から予想できる．** 同じラベルの表現を近づけ違うラベルを遠ざける損失は，そのラベルを線形に分離しやすくする——だから「上がった」こと自体は発見ではない．この節が確定させるのは向きではなく，三つの対照である：増分が署名ラベルに固有であること（ablation），質問文からは説明できないこと（言い回しプローブ），質問の書き出しを未見にしても保たれること．予想から外れる所見は [§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) にある．

| 第16層の表現からの，署名の読み取り精度 | 通常の分割 | 書き出しを分離した分割 |
| --- | --- | --- |
| baseline（整合前） | 83.1% | 81.1% |
| **proposal（整合後）** | **95.9%** | **95.6%** |
| **整合の効果（proposal − baseline）** | **+12.8pt** | **+14.6pt** |
| ablation | 81.6% | 78.3% |
| （参照）言い回しプローブ（質問文だけを入力） | 69.7% | 66.1% |
| （参照）タスク形式の特徴だけを入力 | 35.3% | 34.3% |
| （参照）床（最も多い署名の割合） | 28.8% | 31.0% |

- **整合前も，署名は読み取れる——ただし幾何として近いわけではない．** baseline の 83.1% は床の 28.8% から遠い一方，同署名の類似度 $0.946$ と異署名の $0.923$ の差はわずかで，分離度は $0.73$ にとどまる（→ [§3.4](#34-整合が働いたことの確認)）．[§0](#0-要約) 冒頭の問い——同じ解き方で解ける質問どうしは近いか——への答えがこれである：わずかに近いだけだが，署名の情報は線形に取り出せる．
- **整合は，読み取り精度を 83.1% から 95.9% へ上げた（+12.8pt）．** 種ごとに対にした差は $12.41 / 12.43 / 13.46$ で，3種とも向きが同じうえ，いずれも 12pt を超える．書き出しを分離した分割では +14.6pt と，差はむしろ広がる．これが問い1 に対する答えである（→ [§6.1](#61-答えたこと問い14)）．
- **ablation では上がらない（81.6%，整合前と −1.5pt）．** 対照学習という形式そのものではなく，署名ラベルが差を生んでいることの，最も直接的な対照である．しかも ablation は [§3.4](#34-整合が働いたことの確認) のとおり分離度が baseline より低い（$0.413$ 対 $0.731$）のに，読み取り精度は baseline のままである——表現どうしの距離と，そこから線形に取り出せる情報の量は，別の量である．
- **類似度が $0.99$ を超えても，署名の情報は消えない．** 全ベクトルが細い円錐に収まっても，平均方向に直交する小さな成分が署名によって系統的に変わっていれば，線形写像はそれを取り出せる（分類器の重みの大きさに制限は無いので，成分をいくら小さくしても線形に分離できるかどうかは変わらない）．したがって ablation の 81.6% は「壊し損ねた残り」ではなく，$\mathcal{L}_{\mathrm{LM}}$ だけで保たれる水準である——情報が無いときの水準は床の 28.8% であり，そこからは遠い．
- **得られた値は，質問文を読むだけでは説明できない．** 質問が program から生成されている以上，質問文の言い回しと署名は相関している（→ [§2.1](#21-解き方を比べられる形にするタスク署名)）が，言い回しプローブは 69.7% にとどまり，整合後はそこを +26.2pt 上回る（書き出しを分離しても +29.5pt）．なお整合前でも +13.4pt 上回るので，署名は整合前の表現からも言い回しプローブを超える精度で読み取れる．
- **タスク形式を残差化しても，増分は動かない．** 質問の語数・答えの文字数・答えが yes/no かを回帰で除いた表現の上で測り直すと，読み取り精度は baseline 82.9%・proposal 95.6% となり，整合の効果は 12.76pt から 12.76pt へ，小数第2位まで変わらない（書き出しを分離した分割でも 14.55pt → 14.57pt）．タスク形式の特徴だけを入力にしたプローブも 35.3% で，床の 28.8% を 6.5pt 上回るにとどまる．
- **Sahoo らが示した機構——プローブが読んでいたのはタスク形式だった——は，ここでは働いていない．** 彼らの設定ではタスク形式を除いた途端に読み取り精度がチャンスまで落ちたが，本研究では除いても 0.24pt しか落ちない（→ [§4.1](#41-問い1の検証署名を当てるプローブ)）．なお ablation の落ち幅だけは 1.05pt とやや大きく，一方向に集まった表現に残る署名の情報は，整合した表現のそれよりタスク形式に寄っている．

### 5.2 問い2——損失が教えていない演算子の組み合わせも，読み取れるようになる

| プローブが一度も見ていない演算子の組み合わせについて | 演算子ごとの AUC | 組み合わせの完全一致率 |
| --- | --- | --- |
| baseline（整合前） | 0.903 | 35.8% |
| **proposal（整合後）** | **0.951** | **45.2%** |
| ablation | 0.913 | 32.6% |
| （参照）言い回しプローブ（質問文だけを入力） | 0.936 | 29.2% |

- **整合は，プローブが見ていない組み合わせの完全一致率を 35.8% から 45.2% へ上げた（+9.3pt）．** 「署名が同じか違うか」しか教えられていないモデルが，損失が小さくしようとしていない量を言い当てている——[§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) の増分は，学習が自分の教えたことを読み返した結果ではない．これが問い2 に対する答えである（→ [§6.1](#61-答えたこと問い14)）．
- **ablation では上がらない（32.6%，整合前より $-3.2$pt）．** [§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) と同じ対照が，損失が教えていない構造の上でも成り立つ——対照学習という形式そのものではなく，署名ラベルがこの増分を生んでいる．
- **ただし増分は [§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) より小さい．** 完全一致率では +9.3pt だが AUC では +0.048 にとどまる．損失が直接作っている構造から離れるほど，増分は小さくなる．
- **演算子を1つずつ判別する能力では，整合前の表現は言い回しプローブに劣る**（AUC 0.903 対 0.936）．整合後にようやく上回るが，その差は +0.015 しかない．これを「表現は質問文より多くの情報を持つ」と読んではいけない——言い回しプローブは質問文から取れる情報の上限ではないので（→ [§4.1](#41-問い1の検証署名を当てるプローブ)），わずかに上回ったことは何の上限も超えていない．言えるのは，組み合わせ全体を当てる課題（完全一致率）でのみ差が大きく開くことである（整合前でも +6.7pt，整合後は +16.0pt）．

### 5.3 問い3——正解率への代償は，あっても僅かである

| 正解率（`testdev_balanced`） | baseline | proposal | ablation |
| --- | --- | --- | --- |
| 乱数種 42 | 53.04 | 52.73 | 54.21 |
| 乱数種 43 | 53.77 | 53.43 | 53.51 |
| 乱数種 44 | 53.96 | 53.11 | 54.05 |
| **平均 ± 標準偏差** | **53.59 ± 0.49** | **53.09 ± 0.35** | **53.92 ± 0.37** |

**どの群間にも有意差は無い．** proposal の baseline に対する差は種ごとに $-0.31 / -0.34 / -0.85$，したがって $\bar{d} = -0.50$，$s_d = 0.303$，$s_d/\sqrt{3} = 0.175$ で，[§3.3](#33-乱数種3つのまとめ方) の区間は

$$
-0.50 \;\pm\; 4.303 \times 0.175 \;=\; -0.50 \pm 0.75 \;=\; [-1.25,\; +0.25]
$$

3種とも負ではあるが，この区間は $0$ を跨ぐ．baseline を乱数種だけ変えて3本走らせたときのばらつき（標準偏差 $0.49$，幅 $0.92$pt）の内側でもある．ablation を絡めた残り2組も同様に $0$ を跨ぐ．

**符号が揃っている以上「差は無い」とは言わない．言えるのは上限である——低下は最大でも $1.25$pt，$53.6$ に対して2%強にとどまる．** $\mathcal{L}_{\mathrm{LM}}$ も3群で $0.658 / 0.657 / 0.660$ であり，群間の差は乱数種ごとのばらつきより小さい．これが問い3 に対する答えである（→ [§6.1](#61-答えたこと問い14)）．

### 5.4 問い4——正解率は上がらず，誤りは署名より後の段階で起きている

署名の学習での出現回数で層別しても，**利得の現れる層は無い**：

| 署名の学習での出現回数 | 質問数 | yes/no の割合 | baseline | proposal | proposal−baseline |
| --- | --- | --- | --- | --- | --- |
| 0（未見） | 162 | 91.4% | 69.14 | 67.90 | −1.23 |
| **1–10** | 320 | 78.1% | 70.21 | 68.02 | **−2.19** |
| 11–100 | 778 | 69.4% | 61.91 | 62.25 | +0.34 |
| 101–1,000 | 1,567 | 57.2% | 64.26 | 63.45 | −0.81 |
| 1,001+ | 9,751 | 27.6% | 50.41 | 49.96 | −0.45 |

**5つの層のうち4つで proposal が下回る．** 唯一上回った 11–100 の層（$+0.34$）は種ごとの差が $-1.16 / +1.03 / +1.16$ と符号すら揃わないので，利得ではなく乱数種のばらつきである．信頼区間が $0$ を跨がないのは 1–10 だけで，3種すべてで下回り，差は $-2.19$（$[-4.24,\,-0.13]$）——学習にほとんど現れなかった署名では，整合は正解率を下げる．

**一方，未見（0回）の層からは，低下も利得も読み取れない．** 162 問しかなく，種ごとの差は $+2.47 / -1.85 / -4.32$ と符号が割れ，区間は $[-9.77,\,+7.30]$ に広がる．平均が $-1.23$ であることを，低下の証拠として読んではいけない．

なお，行ごとに正解率の水準が違うのは署名の出現回数ではなく質問の型を映している（出現回数の少ない行ほど yes/no 型が多く，yes/no は正解率が高い）．**群間の比較は各行で同じ質問集合の上で行うので，この交絡を受けない．**

**誤答の原因は，署名の取り違えではない．** [§4.4](#44-問い4の検証署名の出現回数での層別と正誤で分けたプローブ) のとおりプローブを正誤で分けて当てると，どの群でも誤答した質問のほうが読み取り精度がわずかに高い（baseline 81.8% 対 84.6%，proposal 95.4% 対 96.4%）．つまりモデルが答えを外した質問でも，その第16層の表現からは正しい署名が 96.4% の精度で読み取れる——署名の情報が表現に在ってなお，答えは誤っている．誤答は，解き方を別の解き方と取り違えた結果ではなく，署名より後の段階で起きている．したがって署名の表現をどれだけ良くしても，それらの誤答は直らない．

**ただし，誤答側のほうが高いことを「誤答した問のほうが署名を読み取りやすい」と読んではいけない**——二つの群に入っている質問の中身が違うためである．誤答は最も多い署名 `select > relate > query` に偏っており（誤答した問の約36%，正解した問では約17%），プローブにとって最も当てやすい署名が誤答側に多く集まっている．上の結論が要求するのは誤答側の水準が高いことだけで，二つの群の大小には依らない．

**これは実験の偶然ではなく，整合という操作の構造から予期できたことである．** 整合損失が与える署名ラベルは program の注釈から作られており，モデルが推論時には受け取らない情報なので，外から情報が入ってはいる．しかしそれは誤答の原因になっていない変数についての情報である．既に取り違えていない変数を教え直しても，答えは変わらない．したがって $\lambda$ や掛ける層を変えても正解率は動かないと考えられる．

**この最後の一段は，測定ではなく推論である．** 層別の数値と正誤で分けた読み取り精度そのものは測定が保証するが，$\lambda$ や層を変えても覆らないという見込みは保証しない——それを検証するのが [§7.5](#75-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ) である．また本節の二つの説明——誤答が署名より後の段階で起きていることと，それが設計の調整では覆らないこと——は，どちらもプローブが迂回された副産物を読んでいないことを前提とする（→ [§6.2](#62-答えていないこと問い5問い6)）．

## 6. 問いに対する答え

### 6.1 答えたこと（問い1–4）

| | 答え | 答えの及ぶ範囲 |
| --- | --- | --- |
| **問い1（読み取り）** | **担う**——整合前でも 83.1%，整合後は 95.9%（+12.8pt） | 質問文の言い回しでも，タスク形式でも説明できない．10 問以上ある 145 署名についての値である |
| **問い2（組成）** | **及ぶ**——プローブが見ていない組み合わせの完全一致率 35.8% → 45.2%（+9.3pt） | 組み合わせ全体を当てる課題でのみ差が開く．演算子を1つずつ判別する能力では +0.015 |
| **問い3（代償）** | **損なわない**——低下は最大でも 1.25pt | 「差が無い」ではなく，上限つきの答えである |
| **問い4（利得）** | **上がらない**——誤りは署名より後の段階で起きている | 転移は否定される．未見の組み合わせは 162 問しかなく判定できない |

問い1 と問い2 が，現時点での主張である．一文で言い切れば——**署名が一致する質問の表現を近づける学習は，第16層の表現に，署名を線形に読み取れる形を与え，その形は，署名を組み立てている演算子まで読み取れるところにまで及ぶ．** 前者は損失の定義から予想でき，後者は予想できない．後者が非自明なのは，損失が与えているのが「署名が同じか違うか」だけで，演算子のことも，二つの署名が演算子を共有することも，一度も教えていないからである．

**問い1 の答えには，整合前についての部分がある．** 整合前の表現でも署名は 83.1% で読み取れ，床の 28.8% からは遠い——一方その幾何は，同署名と異署名の類似度の差が $0.023$，分離度が $0.73$ にとどまる．[§0](#0-要約) 冒頭の「同じ解き方で解ける質問どうしは近いか」への答えは，**わずかに近いだけだが，署名の情報は線形に取り出せる**，である．

**問い3 の答えは，必須条件が上限つきで満たされたことを言う．** 3種とも符号が負である以上「差は無い」とは言わないが，低下は最大でも 1.25pt であり，内部状態を読めるようにする代償としてこの水準にとどまる．整合の強さを一つしか試していないので，この上限が $\lambda$ を変えても保たれるかは測っていない（→ [§7.5](#75-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ)）．

**問い4 の答えは，半分である．** 期待した二つの利点のうち，学習にほとんど現れない署名への転移は，測れる精度で否定される（1–10 の層で $-2.19$pt，区間が $0$ を跨がない唯一の層）．未見の演算子の組み合わせへの汎化は，162 問しかなく判定できない．問い2 が表現の側で組成の汎化を確かめたことは，出力の側の汎化を確かめたことにはならない——測る対象が違う（→ [§1.3](#13-六つの問い)）．**残る半分を埋めるには，同じ層別を表現の側でも行う**（→ [§7.3](#73-問い4の答えを完成させる稀な署名を表現の側で測る)）．

**上がらない理由まで測れたことは，答えの一部である．** 誤答した質問でも署名は 96.4% の精度で読み取れるので，誤りは署名の同定ではなく，その後の段階で起きている——署名の表現をどれだけ良くしても，それらの誤答は直らない．正解率を上げることを目的に置かなかった [§1.2](#12-本研究の目的とすること) の立場に対して，上がらないことが，理由とともに測られた．ただし**その「後の段階」がどこかは測っていない**——視覚的な対象の特定か，演算子列の実行か，その双方かは分けていない．そこは候補であって，結論ではない．

**答えた四つを貫く一文は，次のものである．** 整合は，表現の形式を組み替えるが，答えの決まり方は変えない．ただしこの一文には，[§6.2](#62-答えていないこと問い5問い6) の留保が掛かる．

### 6.2 答えていないこと（問い5・問い6）

**問い5——モデルが署名を使っているかは，測っていない．** 線形に読み取れても，モデルが答えを出す過程でそれを参照しているとは限らない．読み取れても答えの生成に寄与していないなら，それは解釈ではなく副産物である．現時点で主張できるのは「表現の形式が組み替わった」までであって，「モデルを解釈できるようになった」ではない．これが最大の留保であり，[§7.1](#71-問い5に答える整合した構造は迂回されていないか) が答える．

この留保は本研究に固有のものではなく，probing という枠組みへの既知の批判である（Belinkov による総覧がある）．Elazar らは BERT で，プローブの精度とその情報がタスクで果たす役割の相関がほぼゼロであることを示した——順位相関 0.085．彼らの実験では，プローブが最もよく読めた性質（句境界，83–85%）が，除いても下流タスクの性能をまったく下げない性質だった一方，読み取り精度の低い性質（依存関係ラベル，76%）を除くと性能は 87 ポイント落ちた．**読める量と使われる量は，同じ方向にすら動かない．**

**とくに，整合した構造が迂回されていないかを確かめていない**（→ [§2.3](#23-どこに掛けるか射影を挟まない中間層の一点)）．整合が答えの生成に関与しない方向で起きているなら，モデルはその構造を使わずに答えを出せる．このとき正解率が変わらなかったこと（→ [§5.3](#53-問い3正解率への代償はあっても僅かである)）は，整合が中立だったことの証拠にも，迂回されたことの証拠にもなる．二つを分けるまで，どちらとも言えない——この判定を先に済ませないかぎり，$\lambda$ も層も変えて試す意味がない．迂回されているなら，別の場所で整合しても迂回された場所が一つ増えるだけだからである．

**問い6——画像の加工に対して表現が安定になったかも，測っていない．** [§1.1](#11-出力が同じでも内部表現が同じとは限らない) で挙げた出発点の問題は，答えが変わらないまま内部表現が動くことだった．整合した群でその動きが小さくなるなら本研究はその問題に応えたことになり，変わらないなら整合が変えるのは表現の形式だけだったことになる．どちらであるかを [§7.2](#72-問い6に答える画像を加工したとき整合した表現は安定するか) が決める．

### 6.3 答えの及ぶ範囲

**設計の選択肢を，一つも変えて試していない．** $\lambda = 0.1$，第16層，質問を読み終えた位置，$\tau$ の初期値 $0.07$ は，いずれも一組の値で固定したままである．[§6.1](#61-答えたこと問い14) の四つは「この一点における整合の効果」であって，「整合という手法の最良の姿」ではない．とりわけ [§5.3](#53-問い3正解率への代償はあっても僅かである) の僅かな正解率の低下と [§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) の読み取り精度の利得が $\lambda$ でどう釣り合うかは未測定であり，これを測るのが [§7.5](#75-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ) である．

**答えが署名に固有だとは，まだ示していない．** [§3.2](#32-三つの群) の ablation が示すのは，並べ替えた無意味なラベルでは同じことが起きない，までである．別の意味のあるラベルで整合しても同じ増分が出るなら，[§6.1](#61-答えたこと問い14) の問い1・問い2 の答えは「署名を近づけると」ではなく「意味のあるラベルで近づけると」と書き直さなければならない．これを分けるのが [§7.4](#74-答えが署名に固有かを確かめる別のラベルで整合する) である．

**署名が解き方の形式化として最良だとは示していない．** GQA 公式の一貫性（consistency）指標は含意関係にある質問対に整合した答えを要求するが，`val_balanced` の 20,867 対のうち 52.1% は署名が異なる——本研究の損失が引き離す対に対して，公式指標は揃った答えを求めている．ただし，この食い違いは署名の誤りではなく，二つが別のものを捉えていることの現れである．GQA の含意関係は同じ場面についての問を結び，署名は解く手順を区別する．事実，署名が異なる対の 44.2% は yes/no 型の問と自由回答型の問を組にしており（署名が一致する対では 0.0%——手順が同じなら答えの型も必ず同じである），最も多い食い違いは `select > relate > query` と `select > relate > relate > query` の対，すなわち関係をたどる回数が1つ違うだけの対である．それでも，手順を演算子の系列で代表させることが最良かどうかは，別の形式化と比べていない以上，未検証である．

**適用範囲は一点である．** 単一モデル・単一データセット・単一層・1エポックでの結果であり，規模や別のデータセットへの転移は測っていない．

### 7.1 問い5に答える——整合した構造は，迂回されていないか

**[§6.2](#62-答えていないこと問い5問い6) の最大の留保に答える．これが済むまで，本研究は「解釈できる」と主張できず，設計を変えて試す意味も無い．** 判定するのは次の二択である．

- **中立**——整合した構造は答えの生成に関与しているが，正解率を上げも下げもしない．
- **迂回**——整合した構造は答えの生成に関与しない方向へ押し出され，モデルはそれを使わずに答えを出している．

**どちらに転んでも，結論の文が書ける．** 中立なら「整合は，答えを決める方向に読み取れる手順の構造を，正解率の代償なく載せる」．迂回なら「生の内部表現への対照学習は，読めるが使われない構造を作る」——表現を整形する手法一般への警告として，それ自体が独立した知見である．**結論が書けないのは，この測定を走らせなかった場合だけである．**

[§5.3](#53-問い3正解率への代償はあっても僅かである) の「正解率が変わらない」は，二つのどちらとも整合する．**迂回であれば，[§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) の読み取り精度は表現の形式が変わったことしか意味しない**——問い1・問い2 の答えが生き残るかどうかを決める測定である．

**この判定は，新しい手法ではない．** 表現から情報を除いて振る舞いの変化を見るやり方は Elazar らの **amnesic probing** として確立しており，本研究が第1段に置くランダム直交基底の対照も，彼らが Rand 対照——同じ本数のランダムな方向を除き，性能低下が単なる階数の減少で説明できてしまわないかを見る——として既に使っている．本研究が新しいのは手法ではなく，掛ける対象である：既にある表現から性質を除くのではなく，損失で作り込んだ構造が使われているかを問う．

**素朴な方法——整合を掛けた表現を壊して出力の変化を見る——は採らない．** 言語モデルには，ある層を潰すと別の層がその働きを肩代わりする自己修復が知られており（McGrath ら），「壊しても出力が変わらない」は「その層が答えの生成に寄与していない」ことを意味しない．Elazar ら自身も，**後段の層が除いたはずの情報を復元することがある**と限界に挙げている．

#### 第1段：署名は，出力が読む方向に載っているか

**モデルを走らせずに済み，保存済みの表現と出力層の重みだけで完結する．**

1. **答えの選択を決める方向が張る部分空間 $U$ を作る．** 出力層は，最終層の表現に重み行列を掛けて語ごとのスコアを出す．その行列の1行が1語に対応し，ある語の行と表現との内積が，その語のスコアである——どの語が選ばれるかを決めているのは，これらの行が指す方向にほかならない．GQA の答えは閉じた語彙なので（報告用データで 722 種），答えの先頭トークンに対応する行だけを抜く（答えが決まるのは先頭トークンの位置だからである）．抜いた行を並べた行列から列ごとの平均を引き，その上位 $m$ 個の主成分を正規直交な列として並べたものが $U \in \mathbb{R}^{H \times m}$ である．$m$ はこの部分空間の次元で，$8$／$32$／$128$ の3通りを試す．平均を引くのは，すべての答えの行に共通する成分が，どの答えのスコアも同じだけ動かし，答えの選択を決められないからである．
2. **$U$ の中と外で読み取り精度を比べる．** 長さ1に揃えた第16層の表現 $z$ を，中の成分（$U$ 上の座標 $U^{\top} z$——$m$ 個の数）と，外の成分（$z - U U^{\top} z$——$H$ 次元のまま，$U$ に載る分だけを抜いたもの）に分け，[§4.1](#41-問い1の検証署名を当てるプローブ) と同じプローブをそれぞれに掛ける．対照として，出力層と何の関係もない $m$ 次元のランダムな正規直交基底を置く——次元が広ければどんな部分空間でもある程度は当たるので，$U$ の中で当たること自体は証拠にならない．

**判定は，読み取り精度の水準ではなく，[§5.1](#51-問い1整合は署名の読み取り精度を-128pt-上げた) の +12.8pt がどこで生き残るかで行う．** 整合による増分が $U$ の中で保たれていれば，整合が作った構造は答えを決める方向に載っており，迂回は否定される．増分が $U$ の外にだけ現れ，中ではランダム基底と変わらなければ，迂回である．$m$ の3通りで結論が変わらないことを確かめる——一つの $m$ でしか成り立たない結論は，その $m$ の性質である．この段で決着するなら，ここで止めてよい．

なお $U$ は最終層の空間で定義した部分空間であり，それを第16層のベクトルに当てている．**両者は同じ $H$ 次元だが，同じ空間ではない**——この近似が持つかどうかが，第2段の主題である．

#### 第2段：整合した群は，その位置への依存を減らしていないか

第1段の $U$ は，上のとおり「第16層の表現がそのまま最終層へ運ばれる」と置いた近似である．したがって**ランダム基底と差が付かなければ，「迂回された」ではなく「近似が粗すぎた」かもしれない．** また第1段が見ているのは方向の重なりであって，proposal が baseline より第16層に依存しなくなっていないかではない——迂回とは依存の低下なので，本来はこちらが直接の量である．

**どちらも，第16層の摂動が最終表現へどれだけ伝わるかを測れば埋まる．** これは間の16ブロックを線形化して勘定に入れる J-lens の考え方であり（Gurnee ら），$U$ の $m$ 本を第16層へ引き戻したものを $U$ の代わりに使い，3群で比べる．要るのは与えられた方向に対するベクトル–ヤコビ積だけで，$m$ 本それぞれについて逆伝播を1回流し，Gurnee らと同じく位置とプロンプトにわたって平均を取る——計算量は $m$ ×（平均を取るプロンプトの本数）の逆伝播にとどまり，$H \times H$ の行列そのものを作る必要はない．方向そのものを探す問いへ進めば話は変わるが（どの層に掛けるのが妥当かは層ごとの計算を要求する），それは順序の問題である．

**第2段は第1段で決着しなかったときだけ走らせ**，判定の形は第1段と同じなのでやり直しにはならない．

### 7.2 問い6に答える——画像を加工したとき，整合した表現は安定するか

**問いの出発点（→ [§1.1](#11-出力が同じでも内部表現が同じとは限らない)）へ輪を閉じる測定である．** Wani らが示したのは「出力が同じでも内部表現は変化する」ことだった——それが本研究の動機であるのに，整合した群でその変化量が小さくなるかを，まだ測っていない．

3群それぞれについて，画像に正解を変えない加工（平行移動・拡大縮小・回転・文字の重ね書き）を施し，加工の前後で第16層の表現がどれだけ変化するかを比べる．**変化量そのものではなく，無関係な画像対の距離分布を基準にした比で報告する**——Wani らと同じ形の指標にすることで，値が単位に左右されなくなる．幾何的な加工では Wani らの測定でも変化量は小さいので，群間の差が現れうるのは主に文字の重ね書きである．

**Wani らの値と直接は比べられない．** 彼らが測ったのは言語側の最終層で，モデルは Qwen3-VL と LLaVA-OneVision，データは SEEDBench・MMMU・POPE である．本研究が測るのは SmolVLM の第16層，GQA の画像である．**借りるのは指標の形だけで，読めるのは3群のあいだの差である．**

| 結果 | 意味 |
| --- | --- |
| 整合した群で変化量が小さい | **整合は表現の安定性を高める．**[§1.1](#11-出力が同じでも内部表現が同じとは限らない) の問題に直接応えたことになる |
| 差が無い | 整合が変えるのは**表現の形式だけ**であり，安定性には及ばない——射程を限定した主張になる |
| 整合した群で変化量が大きい | 分離を強めた副作用として脆くなっている．**代償が正解率の上限だけでは済まなくなる**ので，必ず確かめる |

### 7.3 問い4の答えを完成させる——稀な署名を，表現の側で測る

**[§6.1](#61-答えたこと問い14) の問い4 の答えを，半分から全体にする．** 転移が否定されたこと（1–10 の層で $-2.19$pt）は出力の側の測定であり，同じ層別を表現の側では行っていない．[§5.4](#54-問い4正解率は上がらず誤りは署名より後の段階で起きている) と同じ五つの層の上で [§4.1](#41-問い1の検証署名を当てるプローブ) のプローブを当て直せば，二択が分かれる．

- **表現も組み替わっていない**——稀な署名では，同署名の相手がバッチに揃うことが少なく，整合損失がほとんど働かなかったことになる．このとき正解率の低下は，整合が届かなかった場所で起きた副作用である．
- **表現は組み替わっているが，出力に届かない**——読み取り精度は稀な層でも上がっているのに，正解率は下がる．このとき問い4 は問い5 に合流し，[§7.1](#71-問い5に答える整合した構造は迂回されていないか) の判定がここでも効く．

**この測定は [§7.1](#71-問い5に答える整合した構造は迂回されていないか) の判定を待たない．** 設計を何も変えず，保存済みの表現を層別に読み直すだけだからである．ただし層が細かくなるぶん，[§4.1](#41-問い1の検証署名を当てるプローブ) の「10 問以上ある署名に限る」という条件が層ごとに掛かり直す——稀な層ほど署名あたりの問数が少ないので，どの層で読み取り精度を採点できるかを先に確かめる．

### 7.4 答えが署名に固有かを確かめる——別のラベルで整合する

**[§6.1](#61-答えたこと問い14) の問い1・問い2 の答えは「署名が一致する質問の表現を近づけると」で始まる．その「署名が」を支えているのは，いまのところ [§3.2](#32-三つの群) の ablation だけである**——並べ替えた無意味なラベルでは同じことが起きない，までしか言えない．

第4の群を足す．$\lambda$ も損失の形も同じまま，ラベルを**答えの型**（yes/no か自由回答か）にする．署名はこれを厳密に細分する——手順が同じなら答えの型も必ず同じで，`val_balanced` の含意対では例外が 0.0% である（→ [§6.3](#63-答えの及ぶ範囲)）．したがってこのラベルは，署名が持つ情報のうち最も粗い部分だけを取り出したものになる．

| 結果 | 意味 |
| --- | --- |
| 増分が出ない | **答えは署名に固有である．** 問い1・問い2 の答えはそのまま立つ |
| 増分の一部が出る | 出た分は，署名のうち答えの型で説明できる部分である．答えを「署名を近づけると」から「署名の粗い分割でも」へ書き直す |
| 同じ増分が出る | 答えは署名についてではなく，**意味のあるラベル一般についてのもの**になる |

**この対照で最も効くのは，演算子を当てるプローブ（→ [§4.2](#42-問い2の検証演算子を当てるプローブ)）である．** 答えの型は演算子の集合をほとんど決めないので，[§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) の +9.3pt がこの群でも出るなら，組成の所見は署名とは無関係だったことになる．

**乱数種3つの3 run で足り，約9時間である．** ただし [§7.1](#71-問い5に答える整合した構造は迂回されていないか) の判定より後に置く——迂回されているなら，どのラベルで整合しても迂回された構造が一つ増えるだけである．

### 7.5 答えの及ぶ範囲を広げる——整合の強さ，そして別のモデルとデータ

**[§6.1](#61-答えたこと問い14) の四つの答えは，すべて $\lambda = 0.1$ という一点についてのものである．** 「読み取り精度は上がり，正解率はほとんど落ちない」は，二つとも単一の測定であって，**読み取り精度が安く買えたのか，代償がまだ始まっていないだけなのかを区別できない．** 区別するには，同じ二つの量を複数の強さで測って並べるほかない．

$\lambda \in \{0.03,\ 0.3,\ 1.0\}$ を追加する．$\lambda = 0$ は baseline，$\lambda = 0.1$ は proposal として**既に測ってあるので，走らせ直さない**．乱数種は 42 の1本から始める——曲線の形は1本で見え，区間を締めるのは形が見えてからでよい．**同じ種の run は初期化もバッチの順序も共有するので，新しい点は既存の2点とそのまま同じ軸に載る．**

| 読めるもの | それが答える問い |
| --- | --- |
| 読み取り精度が $\lambda$ とともに飽和する強さ | 整合はどこまで強めれば足りるか |
| 正解率が乱数種のばらつきを超えて落ち始める強さ | 問い3 の上限は，どこまで有効か |
| 両者の隔たり | **整合は安く買えるのか**——一点では答えようのなかった問い |

**これは [§5.4](#54-問い4正解率は上がらず誤りは署名より後の段階で起きている) の推論を検証する測定でもある．** そこでは「$\lambda$ を変えても正解率は動かない」と述べたが，それは推論であって測定ではない．**動けば，その推論は誤りである．**

掛ける層についても同じことが言える（第8層・第24層）．ただし**強さと層を同時に振らない**——一つの曲線に二つの説明が混ざる．

**モデルとデータセットを増やすのは，この節のどれよりも高い．** [§6.3](#63-答えの及ぶ範囲) の「適用範囲は一点である」を外すには，別の規模の VLM と別のデータセットで同じ四つを測り直すほかない．**ただし別のデータセットには，署名を作れることが要る**——GQA を選んだのは functional program が付いているからで（→ [§2.1](#21-解き方を比べられる形にするタスク署名)），注釈の無いデータセットでは署名そのものが定義できない．したがって規模を振るほうが先で，データセットを替えるにはまず署名に代わる形式化が要る．
