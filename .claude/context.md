# 視覚言語モデルにおけるタスク類似性に基づく内部表現整合学習に関する検討

中野 友晴 ／ 2026-08-27 時点

## 0. 要約

視覚言語モデル（VLM）が画像への質問に答えるとき，**同じ解き方で解ける質問どうしは，モデルの内部表現も互いに近いだろうか．** 近くないなら，近づくように学習を課したとき，何が得られて何を失うだろうか．これが本研究の問いである．「解き方が同じ」は，質問を解く演算子の系列——タスク署名——が一致することで代表させる（→ [§2.1](#21-解き方を比べられる形にするタスク署名)）．署名が一致する質問どうしの内部表現を互いに近づける項を，通常の学習に足す——これを**整合**と呼ぶ（→ [§2.2](#22-整合損失)）．

**本研究の目的は，整合が表現に何をし，何をしないかを測ることである．** 正解率を上げることは目的ではない——上がらないこと自体が，理由とともに測られた結果である．目的を六つの問いに分け（→ [§1.3](#13-六つの問い)），五つに答え，一つを未回答のまま残した．

| | 問い | 答え |
| --- | --- | --- |
| 問い1（読み取り） | 表現は，署名を線形に読み取れる形で担うか | 整合前でも 83.1% の問で当てられるが，表現どうしの距離としてはわずかに近いだけである．整合はこれを **95.9%** へ上げる（+12.8pt） |
| 問い2（組成） | その効果は，損失が教えていない演算子の組み立てにまで及ぶか | **及ぶ**——分類器の当てはめに使っていない組み合わせについて，演算子の集合を丸ごと当てた問の割合が 35.8% から 45.2% へ（+9.3pt） |
| 問い3（代償） | 正解率を，損なわないか | **損なわない**——低下は最大でも 1.25pt |
| 問い4（利得） | 正解率は，上がるか | **上がらない**——誤りは署名より後の段階で起きている |
| 問い5（忠実性） | モデルは，整合した構造を使って答えを出しているか | **使う度合いを下げている**——構造は答えを決める方向に選んで載らず，その位置への依存が2割前後下がる（迂回） |
| 問い6（頑健性） | 整合した表現は，画像を揺らしても保たれるか | **未回答**（→ [§7.1](#71-問い6に答える画像を加工したとき整合した表現は安定するか)） |

**問い2 の答えが，本研究の非自明な所見である．** 問い1 の増分そのものは，用いた損失の定義から予想できる——同じラベルの表現を近づける損失は，そのラベルを線形に分離しやすくするからである．予想できないのは次の点である：損失が与えているのは「署名が同じか違うか」だけなのに，整合後の表現は，分類器が一度も見ていない演算子の組み合わせを言い当てる．

**この数字は，質問の形を読んで当てたものではない．** 質問の語数や答えが yes/no かといった質問の形式から内部表現を予測し，予測できる分を差し引いても，整合の効果は 12.76pt から 12.76pt へ動かない．形式の特徴だけから当てると 35.3% にとどまり，常に最も多い署名と答える 28.8% をわずかに上回るだけである（→ [§5.1](#51-問い1整合は署名の読み取り精度を上げた)）．

**「モデルを解釈できるようになった」とは，まだ言えない——それが問い5 である．** 表現から署名が読み取れること（デコード可能性）と，モデルが答えを出す過程でその署名を使っていること（忠実性）は別だからである．測ってみると，整合が載せた構造は答えを決める方向に**選んで**載っておらず，しかも答えはその位置に以前より頼らない——**迂回である**（→ [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた)）．したがって読み取り精度の増分は，表現の形式が組み替わったことを意味するのであって，モデルが署名を使うようになったことを意味しない．**本研究の主張は，この範囲の中にある．**

**答えは一点についてのものである．** 整合の強さ $\lambda = 0.1$，第16層の質問を読み終えた位置，単一モデル，単一データセット——設計を変えた測定は一つもしていないので，「この設定ではこうなった」より広くは言えない（→ [§6.3](#63-答えの及ぶ範囲)）．

**問い1–5 についての記述はすべて実施済みで，測定は実際に走って結果が保存されている．問い6 と [§7](#7-次の一手未実施) は未実施の計画である．**

## 1. 背景と問い

### 1.1 出力が同じでも，内部表現が同じとは限らない

VLM の頑健性は通例，入力を少し変えても答えが変わらないこと——出力の頑健性——で測られてきた．しかし Wani らは，**答えが変わらないまま内部表現が大きく変化する**ことを示した．画像に，正解を変えない加工（平行移動・拡大縮小・回転や，画像への文字の重ね書き）を施すと，答えが変わらなかった問についても内部表現は変化する．幾何的な加工での変化量は小さいが，文字の重ね書きでは，無関係な画像を入れたときの変化量に迫ることがある．

つまり，**出力の頑健性は，表現の頑健性を含意しない**——出力を見ているだけでは，内部で何が起きているかは分からない．著者ら自身は対処法を示さず，未解決の課題として残している．

### 1.2 本研究の目的と，すること

Wani らが見ているのは「同じ入力を揺らしたときの変化」である．**別々の質問どうしの内部表現が互いに近いかどうかは，そこでは問われていない**——それが本研究の問いである．

**目的は，同じ解き方で解ける質問の内部表現を近づける操作が，何をし，何をしないかを測ることであって，正解率を上げることではない．** 上がらないこと自体が，理由とともに測られた結果である．

**することは一つである．** 署名が一致する質問どうしの内部表現を明示的に近づける項を，通常の学習に足す（→ [§2](#2-提案手法署名が一致する質問の内部表現を近づける)）．整合の有無とラベルの意味だけを変えた三つの群を乱数種3つで学習し（計9回，→ [§3](#3-実験設定)），表現の側と出力の側の両方で測る（→ [§4](#4-検証方法)・[§5](#5-結果)）．

### 1.3 六つの問い

以下，問いを番号と名前で呼ぶ．**前の五つは実施済みで，検証方法・結果・答えを同じ番号の節に置いてある．最後の一つは未実施で，答えるための測定を [§7](#7-次の一手未実施) に置いてある．**

| | 問い | 測る対象 | 状態 |
| --- | --- | --- | --- |
| **問い1（読み取り）** | 整合前の表現は署名をどれだけ担っており，整合はそれを変えるか | 表現の中身 | [§4.1](#41-問い1の検証署名を当てるプローブ) → [§5.1](#51-問い1整合は署名の読み取り精度を上げた) |
| **問い2（組成）** | その効果は，損失が一度も教えていない構造——署名がどの演算子から組み立てられているか——にまで及ぶか | 表現の中身 | [§4.2](#42-問い2の検証演算子を当てるプローブ) → [§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) |
| **問い3（代償）** | 正解率を，損なわないか | 出力 | [§4.3](#43-問い3の検証正解率) → [§5.3](#53-問い3正解率への代償はあっても僅かである) |
| **問い4（利得）** | 正解率は，上がるか．上がらないなら，誤りはどこで起きているか | 出力 | [§4.4](#44-問い4の検証署名の出現回数での層別と正誤で分けたプローブ) → [§5.4](#54-問い4正解率は上がらず誤りは署名より後の段階で起きている) |
| **問い5（忠実性）** | モデルは，整合した構造を使って答えを出しているか | 表現の使われ方 | [§4.5](#45-問い5の検証答えを決める方向で当てるプローブと位置への依存の大きさ) → [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) |
| **問い6（頑健性）** | 整合した表現は，画像を揺らしても保たれるか | 表現の安定性 | **未回答**（→ [§7.1](#71-問い6に答える画像を加工したとき整合した表現は安定するか)） |

**問い1–4 は「整合は何をしたか」を，問い5・問い6 は「その変化は，何かに効くのか」を問う．** 前者は9回の学習が残した表現と予測だけで測れ，後者は学習後の重みを開いて測り直すことを要する．

**問い5 を立てたのは，読み取れることと使われていることが別だからである．** これを外せば「読み取れる」ことだけを主張して「使われている」かを黙ることになる．**問い6 は，答えが出ていないだけで，本研究の問いである**——外せば [§1.1](#11-出力が同じでも内部表現が同じとは限らない) で挙げた出発点の問題に応えないまま終わる．

**問い1 と問い2 はどちらも表現の中身を測るが，別の量である．** 問い1 が問うのは署名そのものを言い当てられるかで，問い2 が問うのはその署名を組み立てている演算子を言い当てられるかである．整合損失は前者だけを教えており，後者は一度も教えていない．

**問い4 が利得を期待するのは，署名ごとに表現がまとまるなら二つの利点がありうるからである**——未見の演算子の組み合わせへの汎化と，学習にほとんど現れない署名への転移である．前者は問い2 と同じ言葉で呼べてしまうが，測る対象が違う：問い2 は表現から演算子を読み取れるかを，問い4 はその質問に正解できるかを問う．

**六つの重みは，同じではない．** 問い1 と問い2 が現時点での主張であり，**問い5 は，その主張が何を意味するかを狭めた**——迂回と答えが出た以上，問い1・問い2 の答えは，表現の形式が組み替わったことより広くは読めない（→ [§6.1](#61-答えたこと問い15)）．問い3 は，内部状態を読めるようにする手法にとって満たせなければ手法そのものが成り立たない必須条件であり，問い4 は満たせなくても成り立つ期待である．問い6 は，出発点の問題に応えるかを問う．

### 1.4 表現に手を入れた先行例

表現のレベルに手を入れて正解率を上げた前例が，VLM に既にある．VLsI（Lee ら）は，大きい VLM が層を追って推論を進めていく様子を，各層の特徴をいったん自然言語へ写して小さい VLM に教え，小さいモデルの正解率を上げた．**答えだけを教えるより，途中の表現まで教えるほうが，学習に届く手がかりは多い**——この前提の傍証として援用する．ただしあちらは外部の大きいモデルを教師とする蒸留であり，本研究は教師を持たない同一モデル内の自己整合で，表現そのものを直接近づける．したがって傍証にとどめ，中核の仮説の支柱には据えない．

## 2. 提案手法——署名が一致する質問の内部表現を近づける

### 2.1 解き方を，比べられる形にする——タスク署名

GQA は画像への質問応答データセットである．各サンプルは画像・質問文・答えに加えて **functional program** を持つ．program は答えに至る道筋を段階ごとに書き下したもので，各ステップが演算子と引数と依存先を持つ．“Who is wearing the dress?” なら

| 順 | 演算子 | 引数 | 依存 |
| --- | --- | --- | --- |
| 0 | `select` | `dress` | — |
| 1 | `relate` | `person, wearing` | 0 |
| 2 | `query` | `name` | 1 |

——「ドレスを選び，それを着ている人物へ関係をたどり，その名前を答える」．**この program が付いていることが GQA を採用した理由**で，解き方が同じかどうかを人手を介さずに判定できる．

ここから演算子の系列だけを取り出したものを**タスク署名**（以下，署名）と呼ぶ．上の例なら `select > relate > query` である．“What is the boy wearing?” も同じ署名なので同じタスク，“What color is the cup?” は `select > query` で別タスクとなる．タスク類似性は連続量ではなく署名が一致するか否かの二値とし，一致する対を**正例対**（整合損失が近づける対）とする．

以降，「解き方が同じ」はすべて「署名が一致する」の意味で用い，測定はすべて署名について行う．**署名が解き方の正しい形式化かどうかは，本研究では検証していない**（→ [§6.3](#63-答えの及ぶ範囲)）．

**引数を捨てるのは意図的である．** 引数まで一致を求めると，正例対がほとんど同じ質問になってしまい，表現が近いのは当たり前になる．捨てたことで，同じ署名の質問どうしでも答えは違う（`select > relate > query` の答えは “women” だったり “tie” だったりする）．

**注意すべき交絡がある．** GQA の質問文はこの program から自動生成されているので，質問文の言い回し——どの語が現れ，どの2語が隣り合うか——と署名は，作りからして相関している．極端な場合には，演算子の名前がそのまま質問文に現れる（報告用データに現れる 118 種の演算子のうち 10 種が該当する——`and`・`or`・`common` など）．質問文を読むだけで分かってしまう分は，差し引かなければならない（→ [§4.1](#41-問い1の検証署名を当てるプローブ)）．

### 2.2 整合損失

バッチ $B$ 件について，モデルが答えを出す途中で保持している内部表現を $h_1,\dots,h_B \in \mathbb{R}^{H}$（以下，単に**表現**と書く．質問文の言い回しを指すことはない），その署名ラベルを $y_1,\dots,y_B$ とする．正規化した表現とそのコサイン類似度を $z_i = h_i / \lVert h_i \rVert_2$，$s_{ij} = z_i^{\top} z_j$ とし，$i$ の正例の集合を $P(i) = \{\, j \neq i \mid y_j = y_i \,\}$ と書く．**整合損失**は署名をラベルとする supervised contrastive loss（SupCon——同じラベルの表現どうしを近づけ，違うラベルの表現どうしを遠ざける損失）であり，

$$
\mathcal{L}_{\mathrm{align}}
\;=\;
\frac{1}{|\mathcal{I}|}\sum_{i \in \mathcal{I}}
\left[\,
\log \sum_{j \neq i} \exp\!\left(\frac{s_{ij}}{\tau}\right)
\;-\;
\frac{1}{|P(i)|} \sum_{p \in P(i)} \frac{s_{ip}}{\tau}
\,\right],
\qquad
\mathcal{I} = \{\, i \mid P(i) \neq \varnothing \,\}
$$

第1項がバッチ全員との近さ，第2項が同署名との近さで，**この差を小さくすることが，同署名だけを相対的に近づけることにあたる．** 外側の和は，バッチの全件ではなく $\mathcal{I}$ について取る．$\mathcal{I}$ から外れるのは，同じ署名を持つ質問が同じバッチに1件も無い質問である——近づける先が無いので $P(i)$ が空になり，第2項が $0$ で割ることになる．ただし本研究のバッチは各署名から2件ずつ引くので（→ [§3.1](#31-モデルとデータ)），外れる質問は生じない．$\tau$ は温度で，学習可能なパラメタとし初期値を $0.07$ とする．

全体の目的関数は $\mathcal{L} = \mathcal{L}_{\mathrm{LM}} + \lambda\, \mathcal{L}_{\mathrm{align}}$ で，**整合の強さ** $\lambda$ は $0.1$ とする．$\mathcal{L}_{\mathrm{LM}}$ は**答えのトークンにのみ**掛かる通常の交差エントロピーである．

### 2.3 どこに掛けるか——射影を挟まない中間層の一点

整合損失は，生の内部表現に直接掛ける．SupCon の原論文は，表現を低次元へ写す小さなネットワーク（射影 head）の出力の上で損失を計算している．本研究があえて射影を挟まないのは，**挟むと仮説が反証不能になる**からである——学習可能な射影があれば，内部表現をまったく変えずとも射影の側を変えるだけで損失を下げられてしまう．

**掛ける先は，第16層（全32層の中間）で，質問を読み終えて答えを書き出す直前の位置にあるベクトルそのものである**（次元は $H = 960$）．

**画像と質問文を読み終えているのは，プロンプトの中でこの位置だけである**——言語側は自己回帰なので，各トークンは自分より前の位置しか見られない（**causal attention**）．答えの先頭トークンも，この位置から出たスコアで選ばれる．整合がここに載せた構造が答えの決まり方に届きうるのは，そのためである．

**整合が触るのは，この1本のベクトルだけである．** 画像と質問文のトークンは，それぞれ別の位置に手つかずで残る．残る16層はそれらの位置を注意で読み直せるので，整合でこのベクトルの情報が損なわれても，後段はもとの位置から読み直せる．ただし層も位置も，ここ以外は試していない（→ [§6.3](#63-答えの及ぶ範囲)）．

**射影を外しても，迂回の余地は残る．** 学習可能な射影が無い以上，損失を下げるには第16層のベクトルそのものが変わるほかなく，実際に変わった（→ [§5.0](#50-確認整合損失は設計どおり働いた)）．しかし，この位置が必ず読まれることは，そこに載った構造まで読まれることを意味しない．960 次元のベクトルから答えのスコアへの写像は多対一であり，動かしても出力がほとんど変わらない方向が残る——署名の構造がそこに載れば，表現には載るが答えの生成には関与しない．射影を外して防げたのは，表現を変えずに済ませる迂回だけである．どちらが起きたかを測ったのが [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) である．

## 3. 実験設定

### 3.1 モデルとデータ

モデルは軽量な VLM **SmolVLM-500M-Instruct** を使う——計算資源の都合による．言語側は32層で，表現の次元は 960 である．

学習は GQA の `train_balanced` で1エポック．943,000 問のうち，同署名の相手がいない 884 問は正例対を組めないので除く．バッチは16 署名を無作為に選び，各署名から2件ずつ引いて $B = 32$ 件とする．1エポックは，残る 942,116 問と同じ件数を引き終えるまで（29,441 バッチ）と定める——署名を単位に引き直すので，各問がちょうど一度ずつ出るわけではない．学習率 $10^{-5}$，勾配ノルムは $1.0$ で打ち切る．**乱数種 42・43・44 の3つで，3群 × 3種 ＝ 9回の学習を行った**（1回 約2時間53分，通しで約26時間）．署名でまとめたバッチを作るのは学習時だけで，評価は自然な分布のまま行う．

報告は `testdev_balanced` 12,578 問で行う（以下**報告用データ**）．GQA の `test` 分割は答えが伏せて配布されていて手元で採点できず，`testdev` は GQA 自身が，学習には使わせず答えを添えて配る分割として用意したものだからである．**学習・検証・報告の3分割は，質問 ID も画像 ID も完全に排他である**——報告に使う 398 枚の画像は，学習中に一度も現れない．

### 3.2 三つの群

**proposal が「baseline と違い，かつ ablation とも違う」ことによって初めて，差を生んだのが署名ラベルであると言える．** どちらか一方だけでは，対照学習という形式そのものの効果と区別がつかない．

1. **baseline**：$\lambda = 0$．整合損失を掛けない．
2. **proposal**：ラベル $y_i$ を署名とする．
3. **ablation**：$\lambda$ も損失の形も同じまま，バッチの中でラベル $y_i$ を無作為に並べ替える．ラベルを作り直すのではなく並べ替えるので，ラベルの分布と正例対の数は厳密に保たれ，正例対の定義だけが無意味になる．

**ablation は表現を壊すために置く群ではない．** 変えるのはラベルの意味だけである——表現を壊す群を置いても，署名ラベルの効果とモデルを損なった効果とが混ざり，対照にならない．ただし実際には，ablation の表現はほぼ同じ向きに集まった（→ [§5.0](#50-確認整合損失は設計どおり働いた)）．それでも署名の読み取り精度は baseline とほぼ変わらないので，対照としては働いている（→ [§5.1](#51-問い1整合は署名の読み取り精度を上げた)）．

**この対照が答えるのは「ラベルに意味が要るか」までである．** 並べ替えたラベルは意味を持たないので，proposal との差は意味のあるラベルが要ることを示す．しかし，そのラベルが**署名である必要があるか**は示さない——答えの型（yes/no か自由回答か）のような別の意味のあるラベルで整合しても同じ効果が出るなら，[§6.1](#61-答えたこと問い15) の答えは署名についてではなく，意味のあるラベル一般についてのものになる．分けるには，そのラベルで学習し直すほかない（→ [§7.3](#73-答えが署名に固有かを確かめる別のラベルで整合する)）．

### 3.3 乱数種3つの，まとめ方

群ごとの数値は乱数種3種（$n = 3$）の平均で報告し，ばらつきが読みに効くところには標準偏差を添える．

**群間の比較には，乱数種を対にした $t$ 検定（対応のある $t$ 検定．paired $t$-test）を用いる．** 対にするのは，同じ種の3群が同じ順序で同じデータを見るからである——種ごとに引き算すれば，初期化とデータ順序の効果が相殺される．乱数種 $i$ での群 $A$ の値を $x_i^{A}$ と書き，$d_i = x_i^{A} - x_i^{B}$ の $n$ 個について平均 $\bar{d}$ と標準偏差 $s_d$ を取る．報告するのは検定の $p$ 値ではなく，同じ枠組みが与える差の 95% 信頼区間である：

$$
\bar{d} \;\pm\; t_{n-1,\,0.975}\,\frac{s_d}{\sqrt{n}},
\qquad
t_{2,\,0.975} = 4.303
$$

$s_d/\sqrt{n}$ は $\bar{d}$ 自体の揺れ（標準誤差）で，$t_{n-1,\,0.975}$ は自由度 $n-1$ の $t$ 分布の 97.5% 点である．**標本が少ないほど大きくなる**——$n = 3$ の $4.303$ は，標本が十分あるときの $1.96$ の2倍以上ある．

区間が $0$ を含まないなら，差の向きは手元のデータで決められる．**含むなら，「差が無い」ことが示されたのではなく，向きを決められないというだけである．** 標本が3つなので区間は広く，そこから読める上限も緩い．

**同じ設定でも，乱数種を変えれば結果は変わる．** その変わる幅を，設定を変えていない baseline の3本だけからも測っておく．群間の差がこの幅の内側にあるなら，設定の違いによる差なのか，乱数種の違いによる差なのかを区別できない．

### 3.4 整合が働いたことを，どう確かめるか

問い1–4 を測る前に，操作が意図どおり働いたことを確かめる．**proposal と ablation の値は配管の確認であって，仮説の支持証拠ではない**——ここで動く量は，整合損失が直接小さくしようとしている量そのものだからである．baseline の値だけは事情が違う．整合が何も掛かっていない群なので，こちらが動かした量ではなく，整合前の幾何そのものの記述である（→ [§5.1](#51-問い1整合は署名の読み取り精度を上げた)）．

報告用データから抜いた 4,000 件で測る．署名が一致する対の集合を $\mathcal{P} = \{\,(i,j) \mid i \neq j,\ y_i = y_j\,\}$，一致しない対の集合を $\mathcal{N}$ と書き，[§2.2](#22-整合損失) のコサイン類似度 $s_{ij}$ をそれぞれで平均したものを**同署名の類似度**・**異署名の類似度**と呼ぶ．**分離度** $\delta$ はその差を，両集合の標準偏差を自由度で重み付けして合わせた $\sigma$（pooled standard deviation）で割ったものである（Cohen's d）：

$$
\bar{s}_{\mathcal{P}} = \frac{1}{|\mathcal{P}|}\sum_{(i,j) \in \mathcal{P}} s_{ij},
\qquad
\bar{s}_{\mathcal{N}} = \frac{1}{|\mathcal{N}|}\sum_{(i,j) \in \mathcal{N}} s_{ij},
\qquad
\delta = \frac{\bar{s}_{\mathcal{P}} - \bar{s}_{\mathcal{N}}}{\sigma}
$$

$\delta = 1$ なら「標準偏差1つ分だけ離れている」と読む．$\sigma$ で割るのは，類似度そのものの大きさに左右されずに群を比べるためである．測った値は [§5.0](#50-確認整合損失は設計どおり働いた) に置く．

## 4. 検証方法

**問い1–5 の検証方法をここに置く．** 問い6 は未実施なので，その測り方は計画として [§7.1](#71-問い6に答える画像を加工したとき整合した表現は安定するか) にある．

### 4.1 問い1の検証——署名を当てるプローブ

表現を入力として署名を当てる線形分類器を当てはめ，どれだけ当たるかを見る．**当たるほど，署名の情報がその表現から線形に取り出せる形で載っていることになる．** この道具は**プローブ**（probe）と呼ばれる．以下その名で書く．長さ1に揃えた表現 $z \in \mathbb{R}^{H}$ に重み行列 $W \in \mathbb{R}^{C \times H}$ を掛け，得られたベクトル $Wz \in \mathbb{R}^{C}$ の第 $c$ 成分を，$c$ 番目の署名のスコアとする（$C$ は署名の種類数）．最も高い署名 $\arg\max_{c} (Wz)_c$ がこのプローブの答えで，当てはめるのは $W$ だけである．評価側でこの答えが正解の署名と一致した問の割合を，以下**読み取り精度**と呼ぶ．

**プローブが読むのは，整合損失が触るベクトルそのものである**（第16層の，質問を読み終えた位置．1問あたり 960 次元が1本）．同じベクトルだからこそ，読み取り精度の増分を整合の効果として読める．しかもこの位置は画像と質問文だけを読み終えた時点にあり，causal attention のもとで後ろは見られないのだから（→ [§2.3](#23-どこに掛けるか射影を挟まない中間層の一点)），評価時のバッチが正解を含んでいても，それがこのベクトルへ入ることはありえない．

- 当てはめ側と評価側の両方に例が要るので，**まず 10 問以上ある署名に限る**——報告用の 12,578 問・904 署名から，10,990 問・145 種が残る．
- 残った 10,990 問を，**問ごとに確率 1/2 で当てはめ側と評価側に振り分ける**（乱数種は固定）．
- **当てはめ側からさらに 2 割を取り分けた検証スライスで打ち切る**——検証スライスでの読み取り精度が最も高かった時点の写像で評価し，評価側には一度も触れない．固定のステップ数で全群を打ち切ると，当てはめの速さの違いが，担っている情報の量の違いに見えてしまうので採らない．
- **床**は，評価側で最も多い署名が占める割合である（当てはめを一切せず，常にその署名と答えても当たる下限）．

[§2.1](#21-解き方を比べられる形にするタスク署名) の交絡には，三つの対照を置く．

- **言い回しプローブ**：内部表現の代わりに質問文の言い回しを入力にした，同じ線形分類器．その語が現れるかどうかを語ごとに 0/1 で並べたものを入力にする——回数ではなく有無で，語の順序は残らない．語順をすべて捨ててしまわないよう，隣り合う2語の組を同じ形に並べたものも作り，両方を測って高いほうを報告する．**これは「質問文の語だけで当たる水準」であって，質問文から原理的に取れる情報の上限ではない**——語の順序も文の構造もほとんど使っていないので，質問文をもっと丁寧に読めばこれより上がありうる．群間の差を測る対照ではなく，得られた値が質問文を読むだけで説明できてしまわないかを見る基準である．
- **書き出しを分離した分割**：質問文の先頭4語が同じ質問は，当てはめ側と評価側に分かれないよう，まとめて一方へ寄せる．**評価側では質問の書き出しが必ず未見になるので，書き出しと署名の対応を覚えるだけでは当たらない**（ただし5語目以降の語まで未見になるわけではない）．寄せた結果，1種が片側だけに落ちて採点できなくなるので，この分割で残るのは 10,978 問・144 種である．
- **質問の形式の残差化**：上の二つは「質問文だけでどこまで当たるか」を競わせる対照である．これとは別に，内部表現から質問の形式で説明できる成分を抜いたうえで，それでも署名が読み取れるかを測る必要がある——語数や答えの型といった見かけの特徴（Sahoo らの言う task format）は，解き方とは別のものだからである．Sahoo らは，3つの推論ベンチマークを 100% で分離していたプローブが，出典・選択肢数・応答長で説明できる分を差し引いた途端，でたらめに答えたのと変わらない水準まで落ちる例を示した．本研究では**出典と選択肢数は定義上存在しない**（全問が単一コーパスの同一生成過程から来ており，多肢選択ではない）ので，残るのは長さである．質問の形式の特徴として，問ごとに次の3つを数える．

  - 質問文の語数
  - 答えの文字数
  - 答えが yes/no かどうか（そうなら 1，違えば 0）

  内部表現の各次元を，この3つから線形回帰で予測する．そして，予測できた分を内部表現から差し引く．当てはめに使うのは **ridge 回帰**——最小二乗に，係数が大きくなりすぎないための罰則を足したもの——で，罰則の強さは $\alpha = 1$ とする．3つの特徴は，単位の違いで罰則の掛かり方が変わらないよう，あらかじめ平均 $0$・標準偏差 $1$ に揃えてある．特徴と切片を並べた行列を $F$，長さ1に揃えた内部表現を並べた行列を $Z$ として（切片には罰則を掛けない）

  $$
  Z \;\longmapsto\; Z - F\,(F^{\top}F + \alpha I)^{-1} F^{\top} Z
  $$

  を取る．これを**残差化**と呼び，残った分の上で同じプローブを当て直す．差し引いた後に長さを揃え直すことはしない——揃え直せば，長さを大きく失った行も，ほとんど失わなかった行も，同じ長さに見えてしまう．署名ラベルは回帰に一切入らないので，当てはめ側と評価側の両方の行を使って回帰しても，これから当てさせる正解が漏れることはない．また，この3つだけを入力にしたプローブも並べて報告する．

  **残差化は，署名が質問の形式と正当に共有している分も一緒に落とす**——存在を確かめて終わる手順は，実際に yes/no の答えを生むからである．**したがって残差化後の値は，質問の形式を除いてなお残る量の下限である．**

### 4.2 問い2の検証——演算子を当てるプローブ

[§4.1](#41-問い1の検証署名を当てるプローブ) には反論が立つ——**整合損失は署名どうしの見分けやすさを上げ，プローブは署名どうしの見分けやすさを測るので，学習が自分の教えたことを読み返しているだけではないか．** これに答えるために，損失が一度も教えていない構造で測る．整合損失が与えているのは「署名が同じか違うか」だけであり，署名がどの演算子から組み立てられているかも，二つの署名が演算子を共有することも，一切教えていない．

- **ラベルを「使われている演算子の集合」に取り替える**——報告用データに現れる 118 種の演算子のうち，延べ 50 回以上現れる 46 種について，含むか含まないかを並べた 0/1 ベクトルにする（この下限は，次の分割の両側に例が揃うように置いてある）．
- **分割を署名単位で切る**——904 署名のうち 449 種をプローブの当てはめ側，残る 455 種を評価側に置く．評価側の演算子の組み合わせは，当てはめ側に一度も現れない（個々の演算子は当てはめ側にもある）．

  **ここで「未見」と言うのは，プローブにとってであって，モデルにとってではない．** 評価側の署名も，それを組み立てている演算子も，モデルは学習中に見ている．モデルにとって未見の署名を切り分ける測定は [§4.4](#44-問い4の検証署名の出現回数での層別と正誤で分けたプローブ) の $0$ の層であり，別の量である．

報告は AUC と完全一致率の2つである．**AUC** は，ある演算子を含む問と含まない問を1組ずつ取ったとき，含む側により高いスコアが付く割合である——でたらめなら $0.5$，含む問がすべて上に並べば $1$ になる（評価側に正例と負例の両方がある 42 種について平均する）．**完全一致率**は，46 個の予測がすべて正解と一致した問の割合である．当てはめと打ち切りは [§4.1](#41-問い1の検証署名を当てるプローブ) と同じ手順で，検証スライスで見るのはここでは AUC である——打ち切りに使う指標は，報告する指標と常に同じにする．

### 4.3 問い3の検証——正解率

各ステップで最も確からしい語を選ばせて（貪欲デコード）答えを作らせ，GQA 公式の評価器で採点する．**正解率**は，そこで正解した問の割合である（12,578 問すべて採点，採点漏れ0問）．群間で比べられる損失は $\mathcal{L}_{\mathrm{LM}}$ だけである——$\mathcal{L}$ には整合する群にのみ補助項が乗るので，同じ量ではない．

### 4.4 問い4の検証——署名の出現回数での層別と，正誤で分けたプローブ

**全体の正解率は，頻出する署名に支配される．** 問い4 が期待する利得は，未見の演算子の組み合わせと，学習にほとんど現れない署名という，どちらも稀な側にある——全体の平均を見ているかぎり，そこに効果があってもなくても数値は動かない．「効果が無かった」と「効果が現れうる場所で測っていなかった」を分けるために，問題を層別する．

- 報告用の 12,578 問を，**その質問の署名がモデルの学習データに何回現れたか**で $0$／$1$–$10$／$11$–$100$／$101$–$1{,}000$／$1{,}001$ 回以上の五つの層に分ける．
- **群間の比較は，各層の中で同じ質問集合の上で行う**（[§3.3](#33-乱数種3つのまとめ方) と同じ，種ごとに対にした差）．層ごとに正解率の水準は違うが，その違いは層の中の群間の差には効かない．
- 層別には問ごとの正誤が要る．公式の評価器は全体の値しか返さないので，**問ごとの判定はこちらで採点し直し，その全体値が公式の値と一致することを確かめたうえで層別に使う．** 報告する全体の正解率は，[§4.3](#43-問い3の検証正解率) のとおり公式の評価器のものである．

正解率が上がらなかったとき，その原因が署名の同定にあるのかを分けて測る．[§4.1](#41-問い1の検証署名を当てるプローブ) のプローブを，**モデルが正解した質問と誤答した質問に分けて当てる．** 誤答した質問の表現からも署名が読み取れるなら，誤りは署名を取り違えた結果ではなく，署名より後の段階で起きていることになる．

### 4.5 問い5の検証——答えを決める方向で当てるプローブと，位置への依存の大きさ

判定するのは次の二択である．

- **中立**——整合した構造は答えの生成に関与しているが，正解率を上げも下げもしない．
- **迂回**——整合した構造は答えの生成に関与しない方向へ押し出され，モデルはそれを使わずに答えを出している．

[§5.3](#53-問い3正解率への代償はあっても僅かである) の「正解率が変わらない」は，二つのどちらとも整合する（→ [§2.3](#23-どこに掛けるか射影を挟まない中間層の一点)）．

この問いは本研究に固有のものではなく，probing という枠組みへの既知の批判である（Belinkov による総覧がある）．Elazar らは BERT で，プローブの精度と，その情報がタスクで果たす役割とがほとんど相関しないことを示した——最もよく読めた性質は，除いても下流タスクの性能をまったく下げない性質だった一方，読み取り精度の低い性質を除くと性能は大きく落ちた．**読める量と使われる量は，同じ方向にすら動かない．**

**素朴な方法——整合を掛けた表現を壊して出力の変化を見る——は採らない．** 言語モデルには，ある層を潰すと別の層がその働きを肩代わりする自己修復が知られており（McGrath ら），「壊しても出力が変わらない」は「その層が答えの生成に寄与していない」ことを意味しない．Elazar ら自身も，後段の層が除いたはずの情報を復元することがあると限界に挙げている．

代わりに問うのは，**署名が表現のどこに載っているか**である．**この形の判定は，新しい手法ではない．** 表現から情報を除いて振る舞いの変化を見るやり方は Elazar らの **amnesic probing** として確立しており，同じ本数のランダムな方向を除いて比べる **Rand 対照**も彼らが既に使っている——性能の低下が単なる階数の減少で説明できてしまわないかを見るものである．本研究が新しいのは手法ではなく，掛ける対象である：既にある表現から性質を除くのではなく，損失で作り込んだ構造が使われているかを問う．

以下，三つの段を踏む．**第1段と第2段は，構造がどこに載っているかを問う**——第1段は答えを決める方向を出力層からそのまま取り，第2段は同じ方向を第16層へ引き戻してから取る．取った後にすることは両段で同一である（同じ行に同じプローブを当て，同じ対照と突き合わせ，同じ判定量で読む）．**第3段は，答えがその位置にどれだけ頼っているかを問う**——載っている場所が分かっても，そこが読まれる度合いは分からないからである．

#### 第1段——出力層が読む方向を，そのまま当てる

**モデルを走らせずに済み，保存済みの表現と出力層の重みだけで完結する．**

1. **答えの選択を決める方向を集めて，部分空間 $U_m$ を作る．** 出力層は，最終層の表現に重み行列を掛けて語ごとのスコアを出す．その行列の1行が1語に対応し，ある語の行と表現との内積が，その語のスコアである——どの語が選ばれるかを決めているのは，これらの行が指す方向にほかならない．GQA の答えは閉じた語彙なので（報告用データで 722 種），答えの先頭トークンに対応する行だけを抜く（答えを決めているのは先頭トークンだからである）．抜いた行を並べて行列を作り，列ごとの平均を引く．その上位 $m$ 個の主成分を，正規直交な列として並べたものが $U_m \in \mathbb{R}^{H \times m}$ である．$U_m$ は群ごとに，その群自身の出力層から作る．問うているのは，各モデルが自分の答えを読む方向に自分の署名が載っているかであって，ある一つのモデルの方向に他の群を当てることではない．整合は出力層の重みも動かすので，群をまたいで一つの $U_m$ を使えば，出力層どうしの違いが読み取り精度の差として現れ，署名がどこに載っているかと区別できない．$m$ はこの部分空間の次元で，$8$／$32$／$128$ の3通りを試す．平均を引くのは，すべての答えの行に共通する成分が，どの答えのスコアも同じだけ動かし，答えの選択を決められないからである．
2. **$U_m$ の中と外で読み取り精度を比べる．** 長さ1に揃えた第16層の表現 $z$ を，中の成分（$U_m$ 上の座標 $U_m^{\top} z$——$m$ 個の数）と，外の成分（$z - U_m U_m^{\top} z$——$H$ 次元のまま，$U_m$ に載る分だけを抜いたもの）に分け，[§4.1](#41-問い1の検証署名を当てるプローブ) と同じプローブをそれぞれに掛ける．対照として，出力層と何の関係もない $m$ 次元のランダムな正規直交基底 $R_m$ を置き，中と外の両方をこれと突き合わせる．中に対照が要るのは，次元が広ければどんな部分空間でもある程度は当たるからで，$U_m$ の中で当たること自体は証拠にならない．外にも同じだけ要る．$H$ 次元から $m$ 方向を抜いただけの表現は，抜いた方向が何であれほとんど落ちないので，$U_m$ の外でなお読み取れること自体も証拠にならない．迂回とは，出力が読まない側に構造が載ることなのだから，対照を欠いて読めなくなるのは外の側である．

   **$R_m$ は5本引いて平均する．** 1本では，判定量が対照そのものの揺れをどれだけ含んでいるかが，値の中に見えない——同じ幅でも引き方を変えれば別の部分空間になり，そこで測った増分も変わる．5本の平均を取り，各本の値も残して，判定量をその散らばりと突き合わせられるようにする（散らばりの大きさは [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) に置く）．

**$U_m$ は最終層の空間で定義した部分空間であり，それを第16層のベクトルに当てている．** 両者は同じ $H$ 次元だが，同じ空間ではない——この近似が成り立つかどうかを，第2段が測る．

#### 第2段——同じ方向を，第16層へ引き戻してから当てる

第16層と出力層のあいだには16層が挟まっている．**その16層を線形化すれば，答えを決める各方向は第16層にも像を持ち，それが第16層で答えを動かす方向である．** これが J-lens の考え方である（Gurnee ら）．$U_m$ の $m$ 本をこの向きに引き戻し，直交化したものを $J(U_m) \in \mathbb{R}^{H \times m}$ と書いて，$U_m$ の代わりに使う．要るのは与えられた方向に対するベクトル–ヤコビ積だけなので，$m$ 本それぞれについて逆伝播を1回流せば足り，$H \times H$ のヤコビ行列そのものは作らない．

**平均を取るのはプロンプトについてであって，位置についてではない．** Gurnee らは層から層への一般の写像を求めるので位置についても平均するが，本研究が問うているのは一つの位置にあるベクトルである（→ [§2.3](#23-どこに掛けるか射影を挟まない中間層の一点)）．画像と質問文の位置にある表現は整合が一度も触っていないので，それらを混ぜた写像は，測ろうとしているベクトルについての写像ではなくなる．報告用データから引いた 64 問で平均する．

**引き戻す前後の向きの隔たりも測る．** 各方向とその像のコサインの絶対値を，$m$ 本について平均したものである．第1段はこれが $1$ であると置いていたのだから，測れば第1段の近似が何を仮定していたかが値で言える．

#### 第3段——答えが，その位置にどれだけ頼っているか

第2段は引き戻した方向を正規直交化して向きだけを使い，**長さを捨てている．** 捨てた長さがここで要る量である——第16層を動かしたとき答えがどれだけ動くかは，方向の重なりではなく，その大きさが決める．中立と迂回は依存の度合いで分かれるのだから，これを測らないかぎり二つは分かれない．

**生の長さは群間で比べられない．** ベクトル–ヤコビ積が返すのは「第16層を1動かすと読み出しが $u$ 方向にどれだけ動くか」で，第16層の表現の大きさにも読み出しの大きさにも左右される．整合はそのどちらも動かしうるので，生の長さを比べれば，表現が縮んだことを依存の低下として読んでしまう．そこで両端の大きさで割り，**弾性**として報告する．プロンプト $p$ と方向 $u$ について，第16層のベクトルを $h_p$，読み出しを $r_p$，ヤコビ行列を $J_p$ として

$$
e_p(u) \;=\; \frac{\lVert J_p^{\top} u \rVert \; \lVert h_p \rVert}{\lVert r_p \rVert}
$$

と定める．**第16層を相対的に1%動かしたとき，読み出しが $u$ 方向に何%動くか**という無次元の量である．$m$ 本の方向とプロンプトについて平均する．

**平均するのは長さであって，ベクトルではない．** 第2段はベクトルを平均する——一つの部分空間が要るからである．向きの揃わないベクトルの平均は短くなるので，それは大きさではなく一致度の話になる．依存は大きさなので，先にノルムを取ってから平均する．

**プロンプトの本数は，仮定せずに確かめる．** 第2段は 64 問で平均したが，64 で足りることは示していなかった．同じ逆伝播から，弾性の走行平均と，第2段の方向が何本目で落ち着くかを，前置きの本数ごとに出す．

読み方は次のとおりである．

| 結果 | 意味 |
| --- | --- |
| proposal の弾性が baseline より小さい | **迂回**——答えは，整合が触った位置に頼らなくなった |
| 3群で変わらない | **中立**——構造は広がったが，位置への依存は落ちていない |
| proposal のほうが大きい | 整合は依存をむしろ強めた．[§5.3](#53-問い3正解率への代償はあっても僅かである) の正解率が動かないことと突き合わせる必要がある |

**ablation が要る理由は，ここでも [§3.2](#32-三つの群) と同じである．** 弾性が下がったとして，それが署名ラベルによるのか，同じ位置に対照学習を掛けたこと自体によるのかは，並べ替えたラベルの群と比べなければ分かれない．

#### 判定量

**判定は，読み取り精度の水準ではなく，[§5.1](#51-問い1整合は署名の読み取り精度を上げた) の増分がどこで生き残るかで行う．** 水準は部分空間の幅だけで決まってしまい，増分は $U_m$ でもランダムな部分空間でも同じように現れる．残るのは両者の差である．

$g(V)$ を，部分空間 $V$ の中の座標だけで測ったときの整合の効果——proposal の読み取り精度から baseline のそれを引いたもの——とし，$g'(V)$ を，$V$ に載る分を抜いた残りで測った同じ効果とする．判定量は，各幅 $m$ について

$$
\Delta_m = g(U_m) - g(R_m),
\qquad
\Delta'_m = g'(U_m) - g'(R_m)
$$

の2つである（$\Delta_m$ が中，$\Delta'_m$ が外）．第2段では $U_m$ を $J(U_m)$ に置き換えた同じ2つを取る．読み方は次のとおりである．

- **$\Delta_m$ が正に立つ**——整合が作った構造は答えを決める方向に載っており，迂回は否定される．
- **$\Delta'_m$ が正に立つ**——構造は出力が読まない側に載っている．迂回である．
- **どちらも立たない**——その段では決着していない．

**$m$ の3通りで結論が変わらないことを確かめる**——一つの $m$ でしか成り立たない結論は，その $m$ の性質である．$\Delta$ には二つの揺れが乗るので，どちらとも突き合わせる．**乱数種3種の符号が揃わない $\Delta$ は，学習の揺れの中にある**（[§3.3](#33-乱数種3つのまとめ方) と同じ読み方で，ここでは3種の値をそのまま並べて示す）．**対照5本の標準誤差を超えない $\Delta$ は，引き方の揺れの中にある**——超えない値は，向きが揃っていても単独では根拠にならない．

**両段とも，射影しない表現そのものにも同じプローブを当てる．** その増分が [§5.1](#51-問い1整合は署名の読み取り精度を上げた) の値を再現しなければ，読んでいる重みと保存済みの表現が別の実行のものだという合図になる．

## 5. 結果

3群 × 3乱数種の9回の学習による．群ごとの数値は3種の平均である．

### 5.0 確認——整合損失は，設計どおり働いた

| 9回の学習が残した表現（平均 ± 標準偏差） | baseline | proposal | ablation |
| --- | --- | --- | --- |
| 同署名の類似度 $\bar{s}_{\mathcal{P}}$ | 0.9458 ± 0.0021 | 0.7381 ± 0.0226 | 0.9947 ± 0.0005 |
| 異署名の類似度 $\bar{s}_{\mathcal{N}}$ | 0.9228 ± 0.0032 | 0.2177 ± 0.0061 | 0.9938 ± 0.0005 |
| **分離度 $\delta$** | **0.731 ± 0.029** | **2.469 ± 0.073** | **0.413 ± 0.093** |
| 整合損失 $\mathcal{L}_{\mathrm{align}}$ | — | 2.1192 ± 0.0471 | 3.4338 ± 0.0002 |
| 言語モデル損失 $\mathcal{L}_{\mathrm{LM}}$ | 0.658 ± 0.003 | 0.657 ± 0.004 | 0.660 ± 0.006 |

**proposal の分離度は baseline の 3.4 倍で，3種でほぼ完全に再現する**（標準偏差は平均の3%）．ablation では上がらない．

**ただし proposal は，同署名を近づけたのではない．** 同署名の類似度も下がっており，異署名の類似度がそれ以上に下がった結果として分離度が上がっている．ablation は逆に，同署名・異署名を問わず類似度が $0.99$ を超え，すべての表現がほぼ同じ向きに集まった．

**その集まり方は，ablation のラベルに情報が無いことの裏づけになる．** 全ベクトルが同じ向きに揃えばどの対も $s_{ij} = 1$ になり，[§2.2](#22-整合損失) の式は $\log\bigl((B-1)e^{1/\tau}\bigr) - 1/\tau = \log(B-1)$ となる——温度が打ち消し合うので，$\tau$ がいくつであっても整合損失はこの値である．$B = 32$ なら $\log 31 = 3.4340$ で，ablation が到達した値は3種ともこれである．並べ替えられたラベルは質問と無関係なので，質問から作る表現をどう変えても同ラベルだけを近づけることはできない——損失に残された下げ方は，すべてを同じ向きに潰すことだけだった．

### 5.1 問い1——整合は，署名の読み取り精度を上げた

**この増分の向きは，損失の定義から予想できる．** 同じラベルの表現を近づけ違うラベルを遠ざける損失は，そのラベルを線形に分離しやすくする——だから「上がった」こと自体は発見ではない．この節が確定させるのは向きではなく，三つの対照が支える次の三点である——増分が署名ラベルに固有であること（ablation），質問文からは説明できないこと（言い回しプローブ），質問の書き出しを未見にしても保たれること（書き出しを分離した分割）．予想から外れる所見は [§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) にある．

| 第16層の表現からの，署名の読み取り精度 | 通常の分割 | 書き出しを分離した分割 |
| --- | --- | --- |
| baseline（整合前） | 83.1% | 81.1% |
| **proposal（整合後）** | **95.9%** | **95.6%** |
| **整合の効果（proposal − baseline）** | **+12.8pt** | **+14.6pt** |
| ablation | 81.6% | 78.3% |
| （参照）言い回しプローブ（質問文だけを入力） | 69.7% | 66.1% |
| （参照）質問の形式の特徴だけを入力 | 35.3% | 34.3% |
| （参照）床（最も多い署名の割合） | 28.8% | 31.0% |

- **整合前も，署名は読み取れる——ただし幾何として近いわけではない．** baseline の 83.1% は床の 28.8% から遠い一方，同署名の類似度 $0.946$ と異署名の $0.923$ の差はわずかで，分離度は $0.73$ にとどまる（→ [§5.0](#50-確認整合損失は設計どおり働いた)）．
- **整合は，読み取り精度を 83.1% から 95.9% へ上げた（+12.8pt）．** 種ごとに対にした差は $12.41 / 12.43 / 13.46$ で，3種とも向きが同じうえ，いずれも 12pt を超える．書き出しを分離した分割では +14.6pt と，差はむしろ広がる．これが問い1 に対する答えである（→ [§6.1](#61-答えたこと問い15)）．
- **ablation では上がらない（81.6%，整合前と −1.5pt）．** 対照学習という形式そのものではなく，署名ラベルが差を生んでいることの，最も直接的な対照である．しかも ablation は [§5.0](#50-確認整合損失は設計どおり働いた) のとおり分離度が baseline より低い（$0.413$ 対 $0.731$）のに，読み取り精度は baseline のままである——表現どうしの距離と，そこから線形に取り出せる情報の量は，別の量である．
- **類似度が $0.99$ を超えても，署名の情報は消えない．** 全ベクトルが細い円錐に収まっても，平均方向に直交する小さな成分が署名によって系統的に変わっていれば，線形写像はそれを取り出せる（分類器の重みの大きさに制限は無いので，成分をいくら小さくしても線形に分離できるかどうかは変わらない）．したがって ablation の 81.6% は「壊し損ねた残り」ではなく，$\mathcal{L}_{\mathrm{LM}}$ だけで保たれる水準である——情報が無いときの水準は床の 28.8% であり，そこからは遠い．
- **得られた値は，質問文を読むだけでは説明できない．** 質問が program から生成されている以上，質問文の言い回しと署名は相関している（→ [§2.1](#21-解き方を比べられる形にするタスク署名)）が，言い回しプローブは 69.7% にとどまり，整合後はそこを +26.2pt 上回る（書き出しを分離しても +29.5pt）．なお整合前でも +13.4pt 上回るので，署名は整合前の内部表現からも言い回しプローブを超える精度で読み取れる．
- **質問の形式を残差化しても，増分は動かない．** 残差化した内部表現の上で測り直すと，読み取り精度は baseline 82.9%・proposal 95.6% となり，整合の効果は 12.76pt から 12.76pt へ，小数第2位まで変わらない（書き出しを分離した分割でも 14.55pt → 14.57pt）．質問の形式の特徴だけを入力にしたプローブも 35.3% で，床の 28.8% を 6.5pt 上回るにとどまる．
- **Sahoo らが示した機構——プローブが読んでいたのは質問の形式だった——は，ここでは働いていない．** 彼らの設定では質問の形式を除いた途端に読み取り精度がでたらめの水準まで落ちたが，本研究では除いても 0.24pt しか落ちない（→ [§4.1](#41-問い1の検証署名を当てるプローブ)）．なお ablation の落ち幅だけは 1.05pt とやや大きく，一方向に集まった内部表現に残る署名の情報は，整合した表現のそれより質問の形式に寄っている．

### 5.2 問い2——損失が教えていない演算子の組み合わせも，読み取れるようになる

| プローブが一度も見ていない演算子の組み合わせについて | 演算子ごとの AUC | 組み合わせの完全一致率 |
| --- | --- | --- |
| baseline（整合前） | 0.903 | 35.8% |
| **proposal（整合後）** | **0.951** | **45.2%** |
| ablation | 0.913 | 32.6% |
| （参照）言い回しプローブ（質問文だけを入力） | 0.936 | 29.2% |

- **整合は，プローブが見ていない組み合わせの完全一致率を 35.8% から 45.2% へ上げた（+9.3pt）．** 「署名が同じか違うか」しか教えられていないモデルが，損失が小さくしようとしていない量を言い当てている——[§5.1](#51-問い1整合は署名の読み取り精度を上げた) の増分は，学習が自分の教えたことを読み返した結果ではない．これが問い2 に対する答えである（→ [§6.1](#61-答えたこと問い15)）．
- **ablation では上がらない（32.6%，整合前より $-3.2$pt）．** [§5.1](#51-問い1整合は署名の読み取り精度を上げた) と同じ対照が，損失が教えていない構造の上でも成り立つ——対照学習という形式そのものではなく，署名ラベルがこの増分を生んでいる．
- **ただし増分は [§5.1](#51-問い1整合は署名の読み取り精度を上げた) より小さい．** 完全一致率では +9.3pt だが AUC では +0.048 にとどまる．損失が直接作っている構造から離れるほど，増分は小さくなる．
- **演算子を1つずつ判別する能力では，整合前の内部表現は言い回しプローブに劣る**（AUC 0.903 対 0.936）．整合後にようやく上回るが，その差は +0.015 しかない．これを「内部表現は質問文より多くの情報を持つ」と読んではいけない——言い回しプローブは質問文から取れる情報の上限ではないので（→ [§4.1](#41-問い1の検証署名を当てるプローブ)），わずかに上回ったことは何の上限も超えていない．言えるのは，組み合わせ全体を当てる課題（完全一致率）でのみ差が大きく開くことである（整合前でも +6.7pt，整合後は +16.0pt）．

### 5.3 問い3——正解率への代償は，あっても僅かである

| 正解率（`testdev_balanced`） | baseline | proposal | ablation |
| --- | --- | --- | --- |
| 乱数種 42 | 53.04 | 52.73 | 54.21 |
| 乱数種 43 | 53.77 | 53.43 | 53.51 |
| 乱数種 44 | 53.96 | 53.11 | 54.05 |
| **平均 ± 標準偏差** | **53.59 ± 0.49** | **53.09 ± 0.35** | **53.92 ± 0.37** |

**どの群間にも有意差は無い．** proposal の baseline に対する差は種ごとに $-0.31 / -0.34 / -0.85$，したがって $\bar{d} = -0.50$，$s_d = 0.303$，$s_d/\sqrt{3} = 0.175$ で，[§3.3](#33-乱数種3つのまとめ方) の区間は

$$
-0.50 \;\pm\; 4.303 \times 0.175 \;=\; -0.50 \pm 0.75 \;=\; [-1.25,\; +0.25]
$$

3種とも負ではあるが，この区間は $0$ を跨ぐ．baseline を乱数種だけ変えて3本走らせたときのばらつき（標準偏差 $0.49$，幅 $0.92$pt）の内側でもある．ablation を絡めた残り2組も同様に $0$ を跨ぐ．

**符号が揃っている以上「差は無い」とは言わない．言えるのは上限である——低下は最大でも $1.25$pt，$53.6$ に対して2%強にとどまる．** $\mathcal{L}_{\mathrm{LM}}$ の群間の差も，乱数種ごとのばらつきより小さい（→ [§5.0](#50-確認整合損失は設計どおり働いた)）．これが問い3 に対する答えである（→ [§6.1](#61-答えたこと問い15)）．

### 5.4 問い4——正解率は上がらず，誤りは署名より後の段階で起きている

署名が学習に現れた回数で層別しても，**利得の現れる層は無い**：

| 署名が学習に現れた回数 | 質問数 | yes/no の割合 | baseline | proposal | proposal−baseline |
| --- | --- | --- | --- | --- | --- |
| 0（未見） | 162 | 91.4% | 69.14 | 67.90 | −1.23 |
| **1–10** | 320 | 78.1% | 70.21 | 68.02 | **−2.19** |
| 11–100 | 778 | 69.4% | 61.91 | 62.25 | +0.34 |
| 101–1,000 | 1,567 | 57.2% | 64.26 | 63.45 | −0.81 |
| 1,001+ | 9,751 | 27.6% | 50.41 | 49.96 | −0.45 |

**5つの層のうち4つで proposal が下回る．** 唯一上回った 11–100 の層（$+0.34$）は種ごとの差が $-1.16 / +1.03 / +1.16$ と符号すら揃わないので，利得ではなく乱数種のばらつきである．信頼区間が $0$ を跨がないのは 1–10 だけで，3種すべてで下回り，差は $-2.19$（$[-4.24,\,-0.13]$）——学習にほとんど現れなかった署名では，整合は正解率を下げる．

**一方，未見（0回）の層からは，低下も利得も読み取れない．** 162 問しかなく，種ごとの差は $+2.47 / -1.85 / -4.32$ と符号が割れ，区間は $[-9.77,\,+7.30]$ に広がる．平均が $-1.23$ であることを，低下の証拠として読んではいけない．

なお，行ごとに正解率の水準が違うのは署名の出現回数ではなく質問の型を映している（出現回数の少ない行ほど yes/no 型が多く，yes/no は正解率が高い）．**群間の比較は各行で同じ質問集合の上で行うので，この交絡を受けない．**

**誤答の原因は，署名の取り違えではない．** [§4.4](#44-問い4の検証署名の出現回数での層別と正誤で分けたプローブ) のとおりプローブを正誤で分けて当てると，どの群でも誤答した質問のほうが読み取り精度がわずかに高い（baseline 81.8% 対 84.6%，proposal 95.4% 対 96.4%）．つまりモデルが答えを外した質問でも，その第16層の表現からは正しい署名が 96.4% の精度で読み取れる——署名の情報が表現に在ってなお，答えは誤っている．誤答は，解き方を別の解き方と取り違えた結果ではなく，署名より後の段階で起きている．したがって署名の表現をどれだけ良くしても，それらの誤答は直らない．

**ただし，誤答側のほうが高いことを「誤答した問のほうが署名を読み取りやすい」と読んではいけない**——正解側と誤答側とでは，入っている質問の中身が違うためである．誤答は最も多い署名 `select > relate > query` に偏っており（誤答した問の約36%，正解した問では約17%），プローブにとって最も当てやすい署名が誤答側に多く集まっている．上の結論が要求するのは誤答側の水準が高いことだけで，両者の大小には依らない．

**これは実験の偶然ではなく，整合という操作の構造から予期できたことである．** 整合損失が与える署名ラベルは program の注釈から作られており，モデルが推論時には受け取らないものなので，外から情報が入ってはいる．しかしそれは，誤答の原因になっていない変数についての情報である．既に取り違えていない変数を教え直しても，答えは変わらない．したがって $\lambda$ や掛ける層を変えても正解率は動かないと考えられる．

**この最後の一段は，測定ではなく推論である．** 層別の数値と正誤で分けた読み取り精度そのものは測定が保証するが，$\lambda$ や層を変えても覆らないという見込みは保証しない——それを検証するのが [§7.4](#74-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ) である．また本節の二つの説明——誤答が署名より後の段階で起きていることと，それが設計の調整では覆らないこと——は，どちらもプローブが迂回された副産物を読んでいないことを前提とする．**その前提は，測ってみると成り立たない側に傾いた**（→ [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた)）．署名が読めても答えがそれを以前ほど読んでいないのだから，proposal について「誤りは署名より後の段階で起きている」と決めることはできない．baseline にはこの留保が掛からない．

### 5.5 問い5——整合は，答えを決める方向を選ばず，その位置への依存を下げた

**第1段が置いた近似は，成り立っていなかった．** 答えを決める方向とその第16層での像とのコサインは，絶対値の平均で baseline $0.229$・proposal $0.247$・ablation $0.218$ である．$1$ に近ければ第1段の部分空間がそのまま使えたことになるが，そうではない——出力層から読んだ方向をそのまま第16層に当てることは，別の方向を当てることだった．

**そのことは，部分空間そのものの性質にも出ている．** 出力層から直に取った $U_m$ は，整合前の群にとって署名について特権的ではない——baseline は $U_m$ の中を同幅ランダムより $+0.13$／$-0.55$／$+0.01$pt しか違えずに読む（$m = 8$／$32$／$128$）．引き戻した $J(U_m)$ では $+3.35$／$+1.09$／$+0.63$pt になり，ablation では $m = 8$ で $+12.84$pt に達する（ablation のランダム側は床の $28.8$% である）．**引き戻して初めて，署名を担う方向が捉えられている．**

判定量（[§4.5](#45-問い5の検証答えを決める方向で当てるプローブと位置への依存の大きさ) の $\Delta_m$ と $\Delta'_m$，単位は pt）は次のとおりである．**対照は5本引いて平均してあり，両段は同じ対照を使うので，引き方に由来する標準誤差は両段で共通である．**

| $m$ | 判定量 | 第1段（$U_m$） | 乱数種ごと | 第2段（$J(U_m)$） | 乱数種ごと | 引き方の標準誤差 |
| --- | --- | --- | --- | --- | --- | --- |
| 8 | $\Delta_m$（中） | +0.83 | +3.56 / −1.96 / +0.88 | **−3.38** | −4.86 / −3.05 / −2.24 | 0.27 |
| 32 | $\Delta_m$（中） | +0.73 | +1.19 / +0.56 / +0.45 | −0.39 | −0.12 / −0.29 / −0.75 | 0.61 |
| 128 | $\Delta_m$（中） | +0.04 | −0.01 / +0.51 / −0.38 | **−0.64** | −0.75 / −1.03 / −0.12 | 0.26 |
| 8 | $\Delta'_m$（外） | −0.09 | −0.12 / −0.12 / −0.04 | −0.08 | −0.14 / −0.18 / +0.07 | 0.07 |
| 32 | $\Delta'_m$（外） | +0.05 | +0.23 / −0.07 / −0.02 | −0.13 | −0.44 / +0.30 / −0.24 | 0.02 |
| 128 | $\Delta'_m$（外） | **+0.16** | +0.31 / +0.02 / +0.15 | **−0.35** | −0.51 / −0.18 / −0.36 | 0.06 |

太字は，乱数種3種の符号が揃い，かつ引き方の標準誤差の2倍を超えた値である——12 のうち4つしかない．**両段とも，射影しない表現そのものの増分は $+12.76$pt で，[§5.1](#51-問い1整合は署名の読み取り精度を上げた) と小数第2位まで一致する**——読んだ重みと保存済みの表現は同じ実行のものである．

- **第1段は決着しない．** 中の $\Delta_m$ は3幅とも正だが，3種の符号が揃うのは $m = 32$ だけで，その $+0.73$pt は引き方の標準誤差 $0.61$ の2倍に届かない．決着しない理由も測れている——$U_m$ は整合前から特権的でないのだから，そこで測った差は，答えを決める方向についての差ではない．
- **第2段では，中の $\Delta_m$ が3幅とも負で，3種の符号もすべて揃う．** $m = 8$ の $-3.38$pt と $m = 128$ の $-0.64$pt は引き方の標準誤差の2倍を超え，$m = 32$ の $-0.39$pt は誤差の内側にとどまる．**中立を示す証拠——答えを決める方向で増分が保たれること——は，どの幅でも得られない．**
- **外の $\Delta'_m$ は，第2段では一度も正に立たない．** 迂回を定義どおりに示す証拠も無い．条件を満たす正の値は第1段の $m = 128$ の $+0.16$pt だけだが，第1段の部分空間は上のとおり答えを決める方向を捉えていないうえ，第2段の同じ幅では $-0.35$pt と符号が逆になる．なお外の側はもともと差が出にくく，$960$ 次元から $128$ 方向を抜いても読み取り精度はどの群でも $0.3$pt 以内でしか動かない．**外での不検出を，迂回でないことの証拠として読んではいけない．**
- **整合前にあった特権は，狭い側と広い側で消える．** baseline は $J(U_m)$ の中を3幅ともランダムより高く読む（$+3.35$／$+1.09$／$+0.63$pt）のに対し，proposal は $m = 8$ で $-0.03$pt，$m = 128$ で $-0.00$pt と差が無い．$m = 32$ では $+0.70$pt が残るが，baseline の $+1.09$pt より小さい．

**$\Delta_m$ の負を「整合が答えを決める方向を避けた」と読んではいけない．** $m = 8$ の到達点は proposal の $72.04$% と $72.07$% でほとんど同じであり，差が付いているのは出発点のほうである（baseline $47.22$% 対 $43.87$%）．先に進んでいた側の増分が小さくなるのは，避けたからではなく，先に進んでいたからでもありうる——**この観測が確定させるのは，整合後に特権が無いことであって，整合が特権を避けたことではない．**

**ここまでは，構造がどこに載っているかである．答えがその位置にどれだけ頼っているかは，第3段が測る．**

| 第16層への依存（弾性，[§4.5](#45-問い5の検証答えを決める方向で当てるプローブと位置への依存の大きさ) の $e$） | $m = 8$ | $m = 32$ | $m = 128$ |
| --- | --- | --- | --- |
| baseline | 0.3957 | 0.2970 | 0.2398 |
| **proposal** | **0.2896** | **0.2321** | **0.1957** |
| ablation | 0.3770 | 0.2897 | 0.2361 |
| **proposal の baseline に対する変化** | **$-26.3$%** | **$-21.7$%** | **$-18.3$%** |
| ablation の baseline に対する変化 | $-4.0$% | $-2.2$% | $-1.4$% |

- **整合した群は，第16層に頼らなくなっている．** 弾性は3幅とも下がり，乱数種ごとの変化も $-32.9$／$-19.0$／$-27.0$%（$m = 8$）と3種すべて同じ向きである．[§4.5](#45-問い5の検証答えを決める方向で当てるプローブと位置への依存の大きさ) の読み方では，これが**迂回**である．
- **ablation では下がらない．** $-4.0$／$-2.2$／$-1.4$% にとどまり，3幅とも乱数種の符号が割れる．proposal との落ち幅の差は $-22.3$／$-19.5$／$-16.9$pt で，こちらは3幅・3種すべて符号が揃う．**依存の低下は，同じ位置に対照学習を掛けたことではなく，署名ラベルに固有である．**
- **下がったのは2割前後であって，ゼロではない．** 言えるのは依存が減ったことまでで，答えが第16層をまったく読まなくなったことではない．
- **64 問で足りているかも，同じ逆伝播から確かめた．** 弾性の走行平均は前置き 8／16／32／48／64 問で baseline $0.3691$→$0.3957$，proposal $0.2882$→$0.2896$ と落ち着いており，第2段の方向は 48 問で最終値と $|\cos| = 0.98$（proposal は $0.96$）まで近づく．**ただしこの指標は 64 問の平均を基準に取るので，64 で $1.000$ になるのは定義による**——示せるのは近づき方が平坦になることまでで，64 問より先は測っていない．

**二つの測定は，同じ向きを指している．** 構造は答えを決める方向に選んで載っておらず，答えはその位置に以前より頼らない．**これが問い5 に対する答えである**（→ [§6.1](#61-答えたこと問い15)）．

**ただし，これは一次近似の測定である．** 弾性は第16層のまわりで線形化した感度であり，非線形の経路まで否定しない．**「使っていない」ではなく「頼る度合いが下がった」が，測定の言える範囲である．**

## 6. 問いに対する答え

### 6.1 答えたこと（問い1–5）

| | 答え | 答えの及ぶ範囲 |
| --- | --- | --- |
| **問い1（読み取り）** | **担う**——整合前でも 83.1%，整合後は 95.9%（+12.8pt） | 質問文の言い回しでも，質問の形式でも説明できない．10 問以上ある 145 署名についての値である |
| **問い2（組成）** | **及ぶ**——プローブが見ていない組み合わせの完全一致率 35.8% → 45.2%（+9.3pt） | 組み合わせ全体を当てる課題でのみ差が開く．演算子を1つずつ判別する能力では +0.015 |
| **問い3（代償）** | **損なわない**——低下は最大でも 1.25pt | 「差が無い」ではなく，上限つきの答えである |
| **問い4（利得）** | **上がらない**——誤りは署名より後の段階で起きている | 転移は否定される．未見の組み合わせは 162 問しかなく判定できない |
| **問い5（忠実性）** | **使う度合いを下げている**——構造は答えを決める方向に選んで載らず，その位置への依存が2割前後下がる | 依存はゼロではない．弾性は一次近似で，非線形の経路までは否定しない |

問い1 と問い2 が，現時点での主張である．一文で言い切れば——**署名が一致する質問の内部表現を近づける学習は，第16層の表現に署名を線形に読み取れる形を与え，その形は，署名を組み立てている演算子にまで及ぶ．** 前者は損失の定義から予想でき，後者は予想できない．後者が非自明なのは，損失が与えているのが「署名が同じか違うか」だけで，演算子のことも，二つの署名が演算子を共有することも，一度も教えていないからである．

**問い1 の答えには，整合前についての部分がある．** 整合前の表現でも署名は 83.1% で読み取れ，床の 28.8% からは遠い——一方その幾何は，同署名と異署名の類似度の差が $0.023$，分離度が $0.73$ にとどまる．[§0](#0-要約) 冒頭の「同じ解き方で解ける質問どうしは近いか」への答えは，**わずかに近いだけだが，署名の情報は線形に取り出せる**，である．

**問い3 では，必須条件が上限つきで満たされた．** 3種とも符号が負である以上「差は無い」とは言わないが，低下は最大でも 1.25pt であり，内部状態を読めるようにする代償としてこの水準にとどまる．整合の強さを一つしか試していないので，この上限が $\lambda$ を変えても保たれるかは測っていない（→ [§7.4](#74-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ)）．

**問い4 の答えは，半分である．** 期待した二つの利点のうち，学習にほとんど現れない署名への転移は，測れる精度で否定される（1–10 の層で $-2.19$pt，区間が $0$ を跨がない唯一の層）．未見の演算子の組み合わせへの汎化は，162 問しかなく判定できない．問い2 が表現の側で組成の汎化を確かめたことは，出力の側の汎化を確かめたことにはならない——測る対象が違う（→ [§1.3](#13-六つの問い)）．**残る半分を埋めるには，同じ層別を表現の側でも行う**（→ [§7.2](#72-問い4の答えを完成させる稀な署名を表現の側で測る)）．

**上がらない理由まで測れたことは，答えの一部である．** 誤答した質問でも署名は 96.4% の精度で読み取れるので，誤りは署名の同定ではなく，その後の段階で起きている——署名の表現をどれだけ良くしても，それらの誤答は直らない．正解率を上げることは目的ではないと [§1.2](#12-本研究の目的とすること) で述べたが，上がらないことを，理由とともに測れた．ただし**その「後の段階」がどこかは測っていない**——視覚的な対象の特定か，演算子列の実行か，その双方かは分けていない．そこは候補であって，結論ではない．

**問い5 の答えは，迂回である．** 二つの測定が同じ向きを指した（→ [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた)）．整合が載せた構造は答えを決める方向に選んで載っておらず——整合前は答えを決める8方向が同幅ランダムより $3.35$pt よく読めたのに，整合後はその差が無い——そのうえ答えは，整合が触った位置に以前より頼らない（弾性が $-26.3$／$-21.7$／$-18.3$%）．**並べ替えたラベルの群では依存が下がらないので，この低下は署名ラベルに固有である．**

**したがって [§5.1](#51-問い1整合は署名の読み取り精度を上げた) の $+12.8$pt と [§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) の $+9.3$pt は，表現の形式が組み替わったことを意味するのであって，モデルが署名を使うようになったことを意味しない．** これは問い1・問い2 の答えを取り消さないが，その及ぶ範囲を確定させる——読み取れるようになった構造は，答えの決まり方へは以前ほど届いていない．**強さや層を変えて同じ数字を精密にしても，精密になるのはこの範囲の中である．**

**ただし依存はゼロになっていない．** 下がったのは2割前後であり，弾性は第16層のまわりで線形化した一次の量である．**言えるのは「頼る度合いが下がった」までで，「使っていない」ではない．**

**答えた五つを貫く一文は，次のものである．** 整合は，表現の形式を組み替えるが，答えの決まり方は変えない——組み替えは答えを決める方向を選ばず，答えはその位置に以前より頼らなくなる．

### 6.2 答えていないこと（問い6）

**問い6——画像の加工に対して表現が安定になったかも，測っていない．** [§1.1](#11-出力が同じでも内部表現が同じとは限らない) で挙げた出発点の問題は，答えが変わらないまま内部表現が動くことだった．整合した群でその動きが小さくなるなら本研究はその問題に応えたことになり，変わらないなら整合が変えるのは表現の形式だけだったことになる．どちらであるかを [§7.1](#71-問い6に答える画像を加工したとき整合した表現は安定するか) が決める．

### 6.3 答えの及ぶ範囲

**設計の選択肢を，一つも変えて試していない．** $\lambda = 0.1$，第16層，質問を読み終えた位置，$\tau$ の初期値 $0.07$ は，いずれも一組の値で固定したままである．[§6.1](#61-答えたこと問い15) の五つは「この一点における整合の効果」であって，「整合という手法の最良の姿」ではない．とりわけ [§5.3](#53-問い3正解率への代償はあっても僅かである) の僅かな正解率の低下と [§5.1](#51-問い1整合は署名の読み取り精度を上げた) の読み取り精度の利得が $\lambda$ でどう釣り合うかは未測定であり，これを測るのが [§7.4](#74-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ) である．

**答えが署名に固有だとは，まだ示していない．** [§3.2](#32-三つの群) の ablation が示すのは，並べ替えた無意味なラベルでは同じことが起きない，までである．別の意味のあるラベルで整合しても同じ増分が出るなら，[§6.1](#61-答えたこと問い15) の問い1・問い2 の答えは「署名を近づけると」ではなく「意味のあるラベルで近づけると」と書き直さなければならない．これを分けるのが [§7.3](#73-答えが署名に固有かを確かめる別のラベルで整合する) である．

**署名が解き方の形式化として最良だとは示していない．** GQA 公式の一貫性（consistency）指標は含意関係にある質問対に整合した答えを要求するが，`val_balanced` の 20,867 対のうち 52.1% は署名が異なる——本研究の損失が引き離す対に対して，公式指標は揃った答えを求めている．ただし，この食い違いは署名の誤りではなく，二つが別のものを捉えていることの現れである．GQA の含意関係は同じ場面についての問を結び，署名は解く手順を区別する．事実，署名が異なる対の 44.2% は yes/no 型の問と自由回答型の問を組にしている（署名が一致する対では 0.0%——手順が同じなら答えの型も必ず同じである）．最も多い食い違いは `select > relate > query` と `select > relate > relate > query` の対，すなわち関係をたどる回数が1つ違うだけの対である．それでも，手順を演算子の系列で代表させることが最良かどうかは，別の形式化と比べていない以上，未検証である．

**迂回は，第16層について測った．** [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) の弾性は整合が触った位置のものであり，別の層で整合したときに同じことが起きるかは測っていない．整合が触る位置は答えの先頭トークンがそこから選ばれる位置なので，構造が使われているという仮説には最も有利な位置である——そこで迂回なら，経路がより間接的な位置ではなおさら迂回すると考えてよい．層についてはそう言えない（→ [§7.4](#74-答えの及ぶ範囲を広げる整合の強さそして別のモデルとデータ)）．

**適用範囲は一点である．** 単一モデル・単一データセット・単一層・1エポックでの結果であり，規模や別のデータセットへの転移は測っていない．

### 7.1 問い6に答える——画像を加工したとき，整合した表現は安定するか

**[§1.1](#11-出力が同じでも内部表現が同じとは限らない) で挙げた出発点の問題に，本研究が応えたかどうかを決める測定である．** Wani らが示したのは「出力が同じでも内部表現は変化する」ことだった——それが本研究の動機であるのに，整合した群でその変化量が小さくなるかを，まだ測っていない．

3群それぞれについて，画像に正解を変えない加工（平行移動・拡大縮小・回転・文字の重ね書き）を施し，加工の前後で第16層の表現がどれだけ変化するかを比べる．**変化量そのものではなく，無関係な画像対の距離分布を基準にした比で報告する**——Wani らと同じ形の指標にすることで，値が単位に左右されなくなる．幾何的な加工では Wani らの測定でも変化量は小さいので，群間の差が現れうるのは主に文字の重ね書きである．

**Wani らの値と直接は比べられない．** 彼らが測ったのは言語側の最終層で，モデルは Qwen3-VL と LLaVA-OneVision，データは SEEDBench・MMMU・POPE である．本研究が測るのは SmolVLM の第16層，GQA の画像である．**借りるのは指標の形だけで，読めるのは3群のあいだの差である．**

| 結果 | 意味 |
| --- | --- |
| 整合した群で変化量が小さい | **整合は表現の安定性を高める．**[§1.1](#11-出力が同じでも内部表現が同じとは限らない) の問題に直接応えたことになる |
| 差が無い | 整合が変えるのは**表現の形式だけ**であり，安定性には及ばない——射程を限定した主張になる |
| 整合した群で変化量が大きい | 分離を強めた副作用として脆くなっている．**代償が正解率の上限だけでは済まなくなる**ので，必ず確かめる |

### 7.2 問い4の答えを完成させる——稀な署名を，表現の側で測る

**[§6.1](#61-答えたこと問い15) の問い4 の答えを，半分から全体にする．** 転移が否定されたこと（1–10 の層で $-2.19$pt）は出力の側の測定であり，同じ層別を表現の側では行っていない．[§5.4](#54-問い4正解率は上がらず誤りは署名より後の段階で起きている) と同じ五つの層の上で [§4.1](#41-問い1の検証署名を当てるプローブ) のプローブを当て直せば，二択が分かれる．

- **表現も組み替わっていない**——稀な署名では，同じ署名の質問が同じバッチに揃うことが少なく，整合損失がほとんど働かなかったことになる．このとき正解率の低下は，整合が届かなかった場所で起きた副作用である．
- **表現は組み替わっているが，出力に届かない**——読み取り精度は稀な層でも上がっているのに，正解率は下がる．このとき問い4 は問い5 に合流し，[§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) が答えた迂回がここでも効いていることになる．

**この測定は，設計を何も変えない．** 保存済みの表現を層別に読み直すだけだからである．ただし層が細かくなるぶん，[§4.1](#41-問い1の検証署名を当てるプローブ) の「10 問以上ある署名に限る」という条件が層ごとに掛かり直す——稀な層ほど署名あたりの問数が少ないので，どの層で読み取り精度を採点できるかを先に確かめる．

### 7.3 答えが署名に固有かを確かめる——別のラベルで整合する

**[§6.1](#61-答えたこと問い15) の問い1・問い2 の答えは「署名が一致する質問の内部表現を近づけると」で始まる．その「署名が」を支えているのは，いまのところ [§3.2](#32-三つの群) の ablation だけである**——並べ替えた無意味なラベルでは同じことが起きない，までしか言えない．

第4の群を足す．$\lambda$ も損失の形も同じまま，ラベルを**答えの型**（yes/no か自由回答か）にする．署名はこれを厳密に細分する——手順が同じなら答えの型も必ず同じで，`val_balanced` の含意対では例外が 0.0% である（→ [§6.3](#63-答えの及ぶ範囲)）．したがってこのラベルは，署名が持つ情報のうち最も粗い部分だけを取り出したものになる．

| 結果 | 意味 |
| --- | --- |
| 増分が出ない | **答えは署名に固有である．** 問い1・問い2 の答えはそのまま立つ |
| 増分の一部が出る | 出た分は，署名のうち答えの型で説明できる部分である．答えを「署名を近づけると」から「署名の粗い分割でも」へ書き直す |
| 同じ増分が出る | 答えは署名についてではなく，**意味のあるラベル一般についてのもの**になる |

**この対照で最も効くのは，演算子を当てるプローブ（→ [§4.2](#42-問い2の検証演算子を当てるプローブ)）である．** 答えの型は演算子の集合をほとんど決めないので，[§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) の +9.3pt がこの群でも出るなら，組成の所見は署名とは無関係だったことになる．

**乱数種3つの3 run で足り，約9時間である．** ただしこの対照が比べる [§5.2](#52-問い2損失が教えていない演算子の組み合わせも読み取れるようになる) の +9.3pt は，[§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) のとおり答えの決まり方へ以前ほど届いていない構造についての数字である．**分かるのは，その構造が署名に固有かどうかまでである．**

### 7.4 答えの及ぶ範囲を広げる——整合の強さ，そして別のモデルとデータ

**[§6.1](#61-答えたこと問い15) の五つの答えは，すべて $\lambda = 0.1$ という一点についてのものである．** 「読み取り精度は上がり，正解率はほとんど落ちない」は，二つとも単一の測定であって，**読み取り精度が安く買えたのか，代償がまだ始まっていないだけなのかを区別できない．** 区別するには，同じ二つの量を複数の強さで測って並べるほかない．

$\lambda \in \{0.03,\ 0.3,\ 1.0\}$ を追加する．$\lambda = 0$ は baseline，$\lambda = 0.1$ は proposal として**既に測ってあるので，走らせ直さない**．乱数種は 42 の1本から始める——曲線の形は1本で見え，区間を締めるのは形が見えてからでよい．**同じ種の run は初期化もバッチの順序も共有するので，新しい点は既存の2点とそのまま同じ軸に載る．**

| 読めるもの | それが答える問い |
| --- | --- |
| 読み取り精度が $\lambda$ とともに飽和する強さ | 整合はどこまで強めれば足りるか |
| 正解率が乱数種のばらつきを超えて落ち始める強さ | 問い3 の上限は，どこまで有効か |
| 両者の隔たり | **整合は安く買えるのか**——一点では答えようのなかった問い |

**これは [§5.4](#54-問い4正解率は上がらず誤りは署名より後の段階で起きている) の推論を検証する測定でもある．** そこでは「$\lambda$ を変えても正解率は動かない」と述べたが，それは推論であって測定ではない．**動けば，その推論は誤りである．**

掛ける層についても同じことが言える（第8層・第24層）．ただし**強さと層を同時に振らない**——一つの曲線に二つの説明が混ざる．**層のほうが，本節の中では先に来る．** [§5.5](#55-問い5整合は答えを決める方向を選ばずその位置への依存を下げた) が第16層で迂回と答えたからである——第16層の後にはまだ16層が続いており，出力に近い層で整合すれば，構造が押し出される余地はその分小さい．迂回が層の深さで変わるなら，そのこと自体が [§2.3](#23-どこに掛けるか射影を挟まない中間層の一点) の設計判断への答えになる．

**モデルとデータセットを増やすのは，この節のどれよりも高い．** [§6.3](#63-答えの及ぶ範囲) の「適用範囲は一点である」を外すには，別の規模の VLM と別のデータセットで同じ五つを測り直すほかない．**ただし別のデータセットには，署名を作れることが要る**——GQA を選んだのは functional program が付いているからで（→ [§2.1](#21-解き方を比べられる形にするタスク署名)），注釈の無いデータセットでは署名そのものが定義できない．したがって規模を振るほうが先で，データセットを替えるにはまず署名に代わる形式化が要る．
