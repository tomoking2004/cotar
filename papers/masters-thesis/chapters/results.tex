\section{表現の頑健性}
\label{sec:robustness}

\draftnote{context.md §A.6 と §8.1（設計と比の作り方の詳細は付録\ref{sec:app-robustness}）．出発点（\ref{sec:background}節）に応える測定：Wani ら \cite{wani} の加工 23 通りを報告用データの全問に施し，第16層の表現の変化量を，同じ質問に別の画像を与えたときの距離の平均に対する比で3群について比べる．この測定だけは乱数種45・46を足した5本で読む．判定に使う比の表（23 通りすべてで baseline 14.75／proposal 9.92／ablation 20.95\%），proposal−baseline は $-4.82$pt $[-7.87, -1.77]$（5本すべてで負），ablation−baseline は +6.21pt，proposal−ablation は $-11.03$pt で，三つとも区間は 0 を含まない．5本の結果を見る前に決めた判定の表（§8.1）では1行目に当たる．ただし比の分母は群ごとに違い，距離そのものでは第16層で proposal のほうがよく動く（+1.97，単位は $10^{-3}$，区間は 0 を含まない）．そこで「整合は表現の安定性を高める」とは書かず，安定性は比で見るか距離で見るかに依ると書く．最終層の比と答えでは，幾何的な加工について3群の差が見られないこと．}
