\section{表現の頑健性の測定の詳細}
\label{sec:app-robustness}

\draftnote{context.md §A.6 の設計と，結果のうち判定に使う比以外．Wani ら \cite{wani} の付録が定めた加工の族と値（原典が書いていない背景色・補間・箱の位置と大きさ・縮小と余白の率はこちらで決めたこと，指示文の選び方だけは原典から逸脱したこととその理由），対照を「同じ質問に別の画像」とした理由（問まで入れ替えると，整合が作り変えた質問どうしの配置を測ってしまう），走らせる前（2026-10-23）に決めた判定の表．比の分母が群ごとに違うこと（proposal は加工による距離が約3倍，対照が約5倍），距離そのものでは向きが逆になること，走らせた後に足した五つの比の作り方（どれでも proposal $<$ baseline $<$ ablation の順，proposal−baseline の区間は対照を同署名の別の問にした比を除いて 0 を含まない，差の大きさは，対照が同じ質問に別の画像を付けた比の作り方のあいだで約2倍変わり（$-2.2$--$-4.8$pt），対照を別の問にした二つでは $-0.75$・$-0.49$pt）．Cohen's d が群の比較に使えない理由（d の大きさはほぼ，加工と対照を合わせた標準偏差を対照の平均で割った値で決まり，対照の変動係数が群ごとに 0.34 から 0.78 まで違う）．文字のある重ね書きで proposal は最終層の比と答えが baseline より少し動きにくいが，proposal−ablation の区間が 0 を含むので署名ラベルには帰せないこと．}
