# 論文組版の原則

`papers/` 以下の全原稿に適用する．**決定はこの文書が唯一の在処であり，各原稿の TeX はこれを実装する**——両者が食い違ったら，どちらが正しいかをここで決めてから直す．公式テンプレートを持つ媒体（PCSJ/IMPS 予稿）では**テンプレートの定めが優先**し，本原則はテンプレートが定めない範囲にだけ及ぶ．何を書くか（内容・主張・数値の出どころ）は [.claude/context-philosophy.md](../.claude/context-philosophy.md) の領分であり，本原則は**どう組むか**だけを扱う．

## 1. 一般的な設定にする

**最も美しい組版は，最も普及した構成を既定のまま使ったものである．** 珍しいクラス・凝ったプリアンブル・手ずからの調整は，読み手と将来の自分に説明の負債を残す．逸脱してよいのは，外部の制約（ページ数上限・提出要件）を満たすための**慣習的な手段**だけで，必ず理由をコメントに書く．

| 原稿 | 構成 | 組版 |
| --- | --- | --- |
| 修士論文 | jsbook（report・既定の A4・10pt）＋ pLaTeX | `platex` を2回 → `dvipdfmx` |
| PCSJ/IMPS 予稿 | 公式 `pcsjimps-j.sty`（jarticle 10pt）＋ pLaTeX | `platex` を2回 → `dvipdfmx -p a4` |

- どちらも同じ道具立て（pLaTeX → dvipdfmx）で組む．jsbook は日本語の学位論文で最も広く使われるクラスであり，クラスオプションも既定から増やさない．
- **本文で寸法をいじらない．** 版面の上書き・見出しやリストの再定義・`\vspace`・`\hspace`・改行の `\\` を本文に置かない．例外は2箇所だけ——修論の表紙（一枚ものの配置は手で組むしかない）と，予稿の公式サンプル由来の定型（連絡先の `〒\hspace{0pt}`）．
- **ページ数上限に収める手段は，順序が決まっている．** まず本文の推敲（削って収める），次に慣習的なサイズ指定（表の `\small`・参考文献の `\footnotesize`——予稿で常用される範囲）．見出しの間隔や行送りの書き換えには進まない．
- **プリアンブルに，使っていないパッケージを置かない．** 例外は amsmath・amssymb——本文の数式が研究文書の形（`\mathbb`・`\varnothing`）をそのまま使うことが確定しているため，骨組みの段階から置く．
- **予稿の公式サンプルが定めるもの**（<https://www.pcsj-imps.org/proceedings/samplefile2017.zip>，中身は 2015 年版．写しは `pcsj-imps-2026/template/`）：A4・図表込み2ページ以内／版面 180 × 252mm・段間 8mm（sty が設定）／表題 16pt・和文著者名 14pt・英文著者名 12pt・所属と本文 10pt（マクロが設定）／和文アブストラクト 300 字程度／発表者連絡先を最終頁右下に `\simplefootnotetext` で／図表は `[t]`・`[b]`／全フォント埋め込み／`platex` → `dvipdfmx -p a4`．一段組も可．技術研究報告のテンプレートは不可（開催案内）．手元の `pcsjimps-j.sty` は公式と同一に保つ．
- **アップロード画面（電子情報通信学会の発表申込システム）が加えるもの**：PDF のみ・3MB 以下・「編集不可」やパスワードをかけない・原稿に ⓒ／copyright の記載を置かない・タイトルと著者名を登録内容（[presentations/abstract.md](../presentations/abstract.md)）と一致させる．

## 2. フォント

**エンジンの既定に任せる．** pLaTeX ＋ dvipdfmx は TeX Live 2022 の既定で和文に原ノ味を使い，全フォントを埋め込む（走査2で確認する）．フォント指定のパッケージは読み込まない．

- 強調は `\textbf`——jsclasses は太字指定の和文をゴシックで組むので，これが日本語の慣習（強調はゴシック）にそのまま合う．強調は節に数回まで．
- 全角英数字・半角カナを使わない．数字と欧文は半角．和文中の括弧は全角（），欧文・数式中は半角 ()．

## 3. 記法

- 句読点は「，．」．
- 全角ダッシュ「——」・コロン「：」による挿入や言い換えは原稿では使わず，文を切って書く．研究文書（.claude/context.md）の圧縮した書き方を原稿に持ち込まない．読者が一般用語と誤認する造語・借用語（例：「弾性」）も使わず，定義が透けて見える説明的な語（例：「相対感度」）を選ぶ．
- 数値範囲は en dash「`--`」（`18--28\%`，`pp. 160--175`）．波ダッシュ「〜」は使わない．
- 負号は数式モード（`$-2.50$`）——ハイフンや U+2212 を地の文に直置きしない．修論の〔執筆メモ〕は研究文書からの写しなのでこの限りでなく，本文化するときに直す．
- 別行立ての数式は `equation` で番号を振る．記号は研究文書の定義をそのまま使い，原稿側で別記法を発明しない．

## 4. 図表

- **表は booktabs**——`\toprule`・`\midrule`・`\bottomrule` の横罫3種だけを使い，縦罫・二重罫を引かない．キャプションは上，単位は列頭に．
- **図はベクタ（PDF）**を原則とし，幅は `\linewidth` 比で指定する．キャプションは下．白黒で判読できること（予稿集は白黒印刷で，修論も印刷提出がありうる）．
- 配置指定は `[tb]`．`[h]` を使わない（予稿テンプレートの指示でもある）．
- 予稿の表だけは公式サンプルの様式（`\hline` と縦罫）に従う——テンプレート優先の実例である．

## 5. 相互参照と文献

- `\label` は種別接頭辞＋英語スラッグ——`chap:`・`sec:`・`tab:`・`fig:`・`eq:`．
- 文献は `thebibliography` に手で書く（本数が少なく，形式を完全に制御できる）．並びは**本文初出順**．
- 形式は「著者, ``題名,'' 発表先, 年.」．著者が3名以上なら「筆頭著者 {\it et al.}」，国際会議は「in Proc. {\it 会議名}」，雑誌名はイタリック（杉村先生の指示，2026-10）．vol. を書くなら no.・pp. も揃える．予稿は紙幅のため vol.・no.・pp. を省き「発表先, 年」で統一する．arXiv 掲載のみの論文は「arXiv:ID, 年.」，URL は `\url{}`——パッケージは xurl（url 互換で URL をどこでも改行でき，Underfull を作らない．URL 由来のバッドボックスへの慣習的な対処）．
- hyperref は hidelinks——リンクは機能として残し，紙面には出さない．pLaTeX では pxjahyper を添えて目次の和文しおりを通す．

## 6. 確定前の走査

**綺麗に見えることは根拠にならない．以下がすべて期待値を返してから確定する．** 文字走査は PowerShell で行う——Git Bash の grep は UTF-8 の文字クラスを誤マッチする．いずれも `papers/` で実行する．**予稿については，この走査と §1 の定めを `pcsj-imps-2026/check.py` が機械化している**——合格した組版が `manuscript.pdf` である．

1. **コンパイル**（2回目）：エラー0・未解決参照0・Overfull/Underfull 0・警告0．
2. **フォント埋め込み**：`pdffonts <PDF>` の emb 列がすべて yes．
3. **文字**（0件）：
   ```powershell
   Get-ChildItem -Recurse -Filter *.tex | Select-String -Pattern '[、。]|[０-９Ａ-Ｚａ-ｚ]|[ｦ-ﾟ]|〜'
   ```
4. **手動空白**（§1 の例外2箇所以外に無いこと）：
   ```powershell
   Get-ChildItem -Recurse -Filter *.tex | Select-String -Pattern '\\vspace|\\hspace'
   ```
5. **ラベル規約**（0件）：
   ```powershell
   Get-ChildItem -Recurse -Filter *.tex | Select-String -Pattern '\\label\{' | Where-Object { $_.Line -notmatch '\\label\{(chap|sec|tab|fig|eq):' }
   ```
6. **文献の並び**：`\cite` の本文初出順と `\bibitem` の順を突き合わせる．
7. **提出前のみ**：修論は `\draftnote` が0件，予稿は2ページ以内．
