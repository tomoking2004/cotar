# Information-Theoretic Probing with Minimum Description Length

**著者**：Elena Voita，Ivan Titov（ともに University of Edinburgh と University of Amsterdam）
**掲載**：Proceedings of the 2020 Conference on Empirical Methods in Natural Language Processing（EMNLP），pp. 183–196，Association for Computational Linguistics，2020-11（オンライン開催）．arXiv:2003.12298 v1，2020-03-27
**原文**：[arXiv](https://arxiv.org/abs/2003.12298)・[ACL Anthology](https://aclanthology.org/2020.emnlp-main.14/)

**プローブの良さを精度ではなく「表現を知ったうえでラベルを送るのに要る記述長」で測れば，精度では差が出にくい比較——本物のタスク対 control task，学習済み対ランダムに初期化したモデル——に差が出て，結果はプローブの設定や乱数種に対して安定する．**

## 主張

要旨は出発点をこう置く——"Despite widespread adoption of probes, differences in their accuracy fail to adequately reflect differences in representations."．要旨によれば，精度は学習済みの表現をランダムに初期化した表現より大きくは優遇せず，本物の言語学的ラベルと無作為な合成タスクとで近い値になりうる．これらの対照に対して妥当な精度の差を見るために，先行研究はプローブの学習データ量かモデルの大きさを制限しなければならなかった．

そこで，ラベルを予測するプローブの学習を，データを効率よく送る問題に置き換え，表現が与えられたときのラベルの**最小記述長（MDL）**を測る．要旨（arXiv の abs ページの表記）は "In addition to probe quality, the description length evaluates "the amount of effort" needed to achieve the quality." と述べる——記述長は，プローブの質に加え，その質に到達するのに要る「手間」も評価する．推定法は variational code と online code の二つで，"We show that these methods agree in results and are more informative and stable than the standard probes."．

## 手法

### 枠組み——ラベルを送る（§2）

送り手は表現 $x_{1:n}$ とラベル $y_{1:n}$ の組を，受け手は $x_{1:n}$ だけを持つ．ラベル数を $K$ とすると，データから何も学ばない一様な符号では $n \log_2 K$ ビットかかる（**一様符号**）．モデル $p$ を両者が前もって共有していれば，ラベルの符号長は $-\sum_i \log_2 p(y_i \mid x_i)$ になる（式 (1)）．しかし受け手は学習後のモデルを知らないので，モデル自体も明示的または暗黙に伝えなければならない．全体の符号長は，モデルの当てはまりの良さ（データの符号長）と，モデルを伝える費用を合わせたものである．著者は，表現がラベルに対してはっきりした構造を持てば，プローブが単純で済むか，構造を明らかにするのに要るデータが少なくて済む，と説明する（§1）．表の**圧縮率**（compression）について，原文は式を示さず，Table 4 の注が "compression – with respect to the corresponding uniform code" とする．

### variational code（§2.2.1）

モデルを明示的に送る二部符号の一種である．パラメタに事前分布 $\alpha(\theta)$ を置き，パラメタの値の不確かさを表す分布を $\beta(\theta)=\prod_{i=1}^{m} \beta_i(\theta_i)$ とすると，符号長は

$$
L^{\mathrm{var}}_{\beta}(y_{1:n} \mid x_{1:n}) = \mathrm{KL}(\beta \,\|\, \alpha) - \mathbb{E}_{\theta \sim \beta}\left[\sum_{i=1}^{n} \log_2 p_\theta(y_i \mid x_i)\right]
$$

となる（式 (2)）．$\beta$ はこの符号長を最小にするように選ぶ．符号を反転した $-L^{\mathrm{var}}_{\beta}$ は変分推論の目的関数である ELBO にあたる．符号長の正当化は bits-back の議論に拠る——不確かなパラメタほど低い費用で送れる．実験には Louizos ら（2017）の圧縮法（Bayesian compression）を用いる．この方法はパラメタに sparsity-inducing な事前分布を置き，ELBO を最適化する副産物としてプローブのニューロンを刈り込むので，プローブの複雑さを記述長 $\mathrm{KL}(\beta \,\|\, \alpha)$ と，得られたアーキテクチャの両方で見られる．

### online（prequential）code（§2.2.2）

モデルを直接には送らない．データをブロックに区切り，最初のブロック（$t_1$ 件）は一様符号で送り，**以後の各ブロックは，それより前のデータ全部で学習したモデルで符号化する**．区切りは，全実験でデータセットの 0.1，0.2，0.4，0.8，1.6，3.2，6.25，12.5，25，50，100% の点である（脚注4）．符号長は

$$
L^{\mathrm{online}}(y_{1:n} \mid x_{1:n}) = t_1 \log_2 K - \sum_{i=1}^{S-1} \log_2 p_{\theta_i}\!\left(y_{t_i+1:t_{i+1}} \mid x_{t_i+1:t_{i+1}}\right)
$$

となる（式 (3)．$\theta_i$ は先頭 $t_i$ 件で学習したモデルのパラメタ）．少ない学習例でよく当てるモデルほど符号長が短くなり，online code は学習曲線（学習例の数に対する質）の下の面積に関係する．online code はモデルの費用を明示的には含まないが，全データで学習したモデルの交差エントロピーと online 符号長の差をモデルの費用と解釈できる（§2.3）．実装の面では，online code は通常のプローブを，データの部分集合を増やしながら学習するだけで済み，variational code はプローブをベイズモデルに変え，損失を式 (2) に変える必要がある．著者は "the online code is easier to implement" と書く．

## 実験設定

### control task（§3）

| | |
| --- | --- |
| 表現 | 5.5 billion-word で事前学習した ELMo の LAYER 0（埋め込み層）・LAYER 1・LAYER 2 |
| タスク | 品詞タグ付け（Penn Treebank，45 ラベル．構文解析で従来使われる学習／開発／テストの分割．学習 39,832 文・950,028 ターゲット．付録の Table 7） |
| control task | Hewitt & Liang（2019）の設定に従う．**語の型ごとに**，言語データのタグの経験分布から独立に引いた品詞タグを割り当てる（各トークンは文脈によらず，その型のタグを受け取る） |
| プローブ | Hewitt & Liang の MLP-2（隠れ層2つ，大きさ 1000，dropout なし），Adam，学習率 0.001．精度は開発セットではなくテストセットで報告（脚注6） |

### ランダムに初期化したモデル（§4）

学習済みの ELMo（Billion Word Benchmark で学習．付録 B.1）と，そのうち "all weights above the lexical layer (LAYER 0) are replaced with random orthonormal matrices" としたもの（LAYER 0 は学習済みのまま）を比べる．タスクは Tenney ら（2019）の edge probing の一式（品詞・構成素・依存関係・固有表現・SRL・共参照・関係分類 SemEval）で，プローブは与えられた区間の中の表現だけを見る．プローブは区間の表現を作ったあとに2層の MLP を置く形で，隠れ層の大きさ 256，dropout 0.3 である．variational code では dropout を使わない（付録 B.1）．

## 結果

### control task では，精度と記述長が逆を指す層がある（§3.2）

| 層 | 精度 | variational 符号長 | variational 圧縮率 | online 符号長 | online 圧縮率 |
| --- | --- | --- | --- | --- | --- |
| LAYER 0 | 93.7 / **96.3** | 163 / 267 | 31.32 / 19.09 | 173 / 302 | 29.5 / 16.87 |
| LAYER 1 | 97.5 / 91.9 | 85 / 470 | 59.76 / 10.85 | 96 / 515 | 53.06 / 9.89 |
| LAYER 2 | 97.3 / 89.4 | 103 / 612 | 49.67 / 8.33 | 115 / 717 | 44.3 / 7.11 |

- **LAYER 0 では，精度は control task のほうが高い**（96.3 対 93.7）．しかし符号長は control task のほうが長い（variational で 267 対 163，online で 302 対 173）．著者はこれを，符号長がその精度に到達する難しさを表すからだと説明する．
- **control task の符号長は，どの層でも本物のタスクより長く**，埋め込み層から上がるほど長くなる．著者は本文で control task の符号長を "(at least twice larger)" と書き，LAYER 0 についても "the code is twice longer than for the linguistic task" と書く．しかし表の値では，2倍を超えるのは LAYER 1・2 であり，LAYER 0 は variational で約1.6倍，online で約1.7倍である（倍率は表の値からこちらで計算した）．本物のタスクで符号長が最も短いのは LAYER 1 である．
- **二つの符号は同じ傾向を示す．**

**刈り込まれたプローブの形**（EMNLP 版 Table 2，arXiv v1 では Table 3．出発点は 1024-1000-1000）は，本物のタスクのほうが control task よりずっと小さい．LAYER 1 なら本物のタスクが 664-55-35（精度 97.7），control task が 824-272-260（精度 92.2）である．本物のタスクのプローブが第2・第3層に残すニューロンは 33〜75 個である．

### 精度の結論は設定と乱数種で揺れ，記述長は揺れない（§3.3）

- **プローブの設定を10通り変えた結果（付録 A の Table 6）を LAYER 0 について示した Figure 3 の説明文は，精度は10のうち8の設定で誤り，MDL は常に正しい，とする．** 著者は，MDL の結果は設定によらず安定しており，プローブの設定の探索を要しないと述べる．
- 乱数種（0〜4）を変えると，精度では層の順位が変わりうる．LAYER 1 と LAYER 2 の精度は乱数種 1 で 97.48 と 97.31，乱数種 0 で 97.38 と 97.48 である．著者は，MDL の結果は安定しており，層ごとの値がよく分かれていると述べる．

- **ランダムに初期化した層でも精度は高い**——品詞の LAYER 1 なら 95.7 で，学習済みの 97.8 と 2.1pt の差である（差は表の値からこちらで計算した）．著者は，ランダムに初期化したモデルの表現でプローブが強い成績を出すという先行研究を挙げ，精度だけでは表現が何を符号化しているかが映らないと述べる．
- **符号長では，ランダムに初期化したモデルは学習済みより長い**，と著者は書く．上の抜粋ではすべての行でそうなっている．ただし Table 4 の共参照の LAYER 2 では，variational 符号長が学習済み 56.8 に対しランダム 54.3 で，逆である．
- 著者は，文脈を使うことによる利得はランダムに初期化したモデルでは学習済みの半分以下（"at least twice smaller"）だと書く．これは圧縮率を文脈なしの LAYER 0 と比べた文である．表の品詞の LAYER 1 で確かめると，LAYER 0 からの圧縮率の増分は online で学習済み 34.3 対ランダム 14.0 と半分以下だが，variational では 30.6 対 18.0，符号長の減少でも variational で 274 対 210 であり，半分以下にはなっていない（こちらで計算した）．
- **LAYER 0 の符号長は文脈つきの層より長い．** 著者は多くのタスクで約2倍違う（"codelengths differ about twice for most of the tasks"）と書き，ランダムに初期化したモデルでも文脈つきの表現のほうが LAYER 0 より良いことを両方の符号が示すと述べる．
- 著者は，ランダムに初期化したモデルでは MDL が層の間で同じだと述べる（表でも2層の値はほぼ同じである）．学習済みのモデルについては "LAYER 2 is worse than LAYER 1 for all tasks." と書き，層の間での表現の変化が学習の目的によって決まることと結びつける．ただし Table 4 の online 符号長では，固有表現（27 対 26）と関係分類（8.8 対 8.6）で LAYER 2 のほうが僅かに短い．

### 精度でなく記述長で比べる理由（著者の論点の整理）

1. **精度は手間を見ない．** 記述長は，到達した質に加えて，そこへ到達するのに要る手間——プローブのモデルの大きさ，または高い質に達するのに要るデータの量——も評価する（要旨）．variational code ではモデルの費用として，online code では少ないデータから学べる度合いとして，これが符号長に入る．
2. **精度は対照と逆を指しうる**（LAYER 0 の control task）．符号長は，Table 1 と付録の10設定のいずれでも control task のほうが長い．
3. **精度の結論はプローブの設定・乱数種に左右される．** MDL の結果は設定によらず安定で，設定の探索を要しない．variational code ではプローブの形も学習の副産物として得られる．
4. **二つの異なる推定法が一致する．** 著者は，この一致は望ましく，結果の妥当性と信頼性を示唆すると述べる（§3.3）．

## 著者が明記した限界

独立した限界の節は無い（節は 1 Introduction から 6 Conclusions までと付録 A・B）．本文に書かれているのは次の点である．

- **符号長は理論値である**——送信アルゴリズムの実際の実装は考えず，"codelength" は対応する符号化の理論上の符号長を指す（脚注2）．
- **variational code は実装に変更を要する**——プローブをベイズモデルに変え，損失を変える必要がある．online code は通常のプローブを，データを増やしながら学習するだけで済む（§2.3）．

## 射程の外

- 実験の対象は**言語モデル ELMo の表現**であり，VLM ではない．全文で画像に触れるのは，Blier & Ollivier（2018）が MNIST・CIFAR-10 で実験したという言及（§3.3）だけである．
- **プローブは既製の表現に対して学習する．** 比べるのは学習済みの ELMo と，LAYER 0 より上の重みをランダムな直交行列に置き換えたものであり，表現を作るモデルの側を追加の損失で学習し直す実験は無い．
- 記述長が測るのは，表現を知ったうえでラベルを送るのに要る符号長である．モデルがその情報を自分の予測に使っているかを測る実験や議論は，全文に見当たらなかった（検索した語：causal，intervention，mechanism，use．mechanism は，関連研究の節が注意重みやニューロンを調べる他の分析法を挙げる一文にだけ現れる）．
- 対照は「語の型ごとに無作為に割り当てたタグ」と「重みのランダムな初期化」である．**ラベルを並べ替えて学習した表現**を対照とする設定は見当たらなかった（検索した語：shuffle，permut．random labels の語は control task のタグを指して現れる）．
- タスクは品詞・構成素・依存関係・固有表現・意味役割・共参照・関係分類の**言語学的な注釈**である．GQA・SmolVLM の語は全文に現れない．
