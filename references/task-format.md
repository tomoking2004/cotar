# Linear Probes Detect Task Format, Not Reasoning Mode in Language Model Hidden States

**著者**：Subramanyam Sahoo，Vinija Jain，Aman Chadha，Divya Chaudhary
**掲載**：6th Workshop on Trustworthy NLP，ACL 2026（採択）．arXiv:2606.02907 v1 2026-06-01／v2 2026-06-03
**原文**：[arXiv](https://arxiv.org/abs/2606.02907)

**線形プローブが高精度で当てられることは，その情報をモデルが使っていることを意味しない——当てているのはタスクの形式かもしれない．**

## 主張

LLM の隠れ状態への線形 probing は，「モデルは推論の種類ごとに異なる表現を学んでいる」と主張する根拠として広く使われている．本論文はその推論が成り立たない例を示す．演繹・帰納・仮説形成の三分法に対応する3つのベンチマークで probing すると**第32層（全40層）で交差検証精度 100%**，幾何も綺麗に分離する．ところが**この分離は形式の交絡で完全に説明される**——出典・選択肢数・応答長を残差化すると精度はチャンスまで落ちる．因果的な steering でも，狙った方向はランダム方向と区別できない（p = 0.286）．

したがって高いプローブ精度は計算構造ではなく**タスク形式**を反映しており，機構解釈の研究では形式の脱交絡を標準手順にすべきである．

## 手法

### probing

| | |
| --- | --- |
| モデル | **Qwen3-14B**（40層，次元 $d = 5120$，bfloat16）．**1モデルのみ** |
| 取り出し位置 | 全層について「最後の入力トークン」の隠れ状態 |
| 分類器 | ロジスティック回帰（L2 正則化，強さ $C = 1.0$），層化5分割交差検証 |
| 最良層 | 第32層 |
| 推論設定 | non-thinking モードのみ |
| 幾何の解析の対象 | 正答した問だけ |

### データと「推論様式」ラベル

各250件に均衡させた3つのベンチマーク．

| 様式 | データ | 形式 |
| --- | --- | --- |
| 演繹 | LogiQA 2.0 | 文脈つき4択 |
| 帰納 | ARC-Challenge | 4択の理科問題 |
| 仮説形成 | αNLI | **2択** |

**ラベルは出典そのものから与える**——"Reasoning-mode labels are assigned by dataset provenance—the intended reasoning type of each benchmark—not by post-hoc classification."

> **推論様式ラベルと出典ラベルは，同一の3分割である．** ラベルの作り方からしてそうなるので（原文は "in perfect correspondence" と書き，二つのプローブは情報として同等だと述べる），出典を残差化することは様式を定義している変数そのものを抜くことにあたる．この設計上の重なりは，下の残差化の結果をどう読むかに直接効く（→ [射程の外](#射程の外)）．

### 形式の交絡の四段

(i) 同じプローブで出典を予測する．(ii) 選択肢数だけを入力にしたプローブ．(iii) 4択の2つ（LogiQA と ARC，500問）に絞って様式を当て直す——それでも精度はほぼ完全で，選択肢数のほかに語彙や文体の差が効いていると読む．(iv) 残差化（次節）．

### 残差化

出典の one-hot・選択肢数・応答長 $|\mathbf{y}_i|$ を並べた形式の特徴ベクトル $\mathbf{f}_i$ を作り，**そこから隠れ状態を予測する Ridge 回帰**を当てる．観測から予測を引いた残差を新しい表現とし，その上で同じプローブを当て直す．

### trace-anchor 一致度

様式ごとに，観測可能な推論の型を記述した anchor 文を用意する（演繹なら "applies a known rule step-by-step" など）．生成された推論列と anchor を**最終層の隠れ状態**で埋め込み，コサイン類似度が最大の様式へ各 trace を割り当てる．

### 因果 steering とランダム対照

様式の対 $s \to t$ について，平均の差を正規化した **steering ベクトル** $\hat{\mathbf{v}}_{s \to t} = (\mu_t - \mu_s)/\lVert \mu_t - \mu_s \rVert$ を作る．強度 $\alpha^{*}$ は coherence の掃引と Otsu 閾値で決める．

**対照としてランダム方向を引く**——本数 $N_{\text{rand}} = \max(5, \min(20, 2 n_{\text{steered}}))$，実際には $N_{\text{rand}} = 20$．経験的 $p$ 値は Laplace 補正つきで $p = (k+1)/(N_{\text{rand}}+1)$（ここで $k$ は狙った方向の指標に並ぶか上回ったランダム方向の数）．

## 結果

### プローブ（第32層）

| プローブの対象 | 生の隠れ状態 | 残差化後 |
| --- | --- | --- |
| 推論様式 | **100.0%** | 約 33.5% |
| **出典** | **100.0%** | 約 33.5% |
| チャンス | 33.3% | 33.3% |

**生の状態では様式も出典も 100%，残差化するとどちらもチャンスに落ちる．**

### 幾何

- 内在次元（TwoNN）：演繹 20.6，帰納 28.5，仮説形成 33.6
- 凸包の混入：全様式で **1.5% 以下**
- 分離比：全ての対で 1.0 超

### 推論そのものは共有されている

trace-anchor 一致度は **42.5%**（チャンス 33.3%）にとどまり，著者は "the model does not substantially change how it reasons when moving between deductive, inductive, and abductive tasks" と読む．

### 因果 steering

狙った方向での steering は，**同じ強度のランダム方向の摂動と同程度の効果**しか示さない——正答への回復は狙った方向 40.0%，ランダム方向の平均 31.7% で，$p = 0.286$（20本のうち5本が並ぶか上回る）は有意でない．**幾何と推論様式のあいだに機能的な結びつきは見られない．**

### モデル自体の正解率

全体 86%（LogiQA 73.2%，ARC 93.6%，αNLI 91.2%）．

## 著者が明記した限界

1. **単一モデル**——Llama・Mistral・GPT-4 での追試が要る．
2. **Ridge 回帰は本物の信号も一緒に落としうる．** 出典を入れず，選択肢数と応答長だけを除く中間の分析は，今後に残している．
3. trace-anchor が手書きの記述に依存する．より細かい行動分析が要る．
4. **αNLI だけ2択**で，他の2つ（4択）との間に選択肢数の交絡が残る．
5. 因果実験の規模が小さい（最大15問）．
6. non-thinking モードのみ．

## 著者の推奨

- **データセットをまたいで probing するときは，様式の予測精度と並べて出典の予測精度を必ず報告する．**
- 残差分析を標準の対照として入れる．
- steering 実験にはランダム方向の対照を置く．
- 形式・選択肢数・語彙分布を揃えた**形式統制ベンチマーク**を設計する．

## 射程の外

- **言語モデル単体**（Qwen3-14B）であって，VLM ではない．画像は関与しない．
- **ラベルは3つの別々のコーパスの出自**である．同一コーパス内で解き方だけが違う問を分けたものではない．したがって**出典という交絡変数が存在する設定**で，それが存在しない設定については何も言っていない．形式の揃ったベンチマークの中での probing は，著者が今後の方向に挙げている．
- 上記のとおり**様式ラベルと出典ラベルが同一の分割**なので，「出典を残差化すると様式が読めなくなる」は形式交絡の証拠であると同時に，定義上そうなる面を持つ．著者は前者として読み，残差化が保守的であることは限界に挙げている．
- **学習による介入を行わない．** 既製のモデルに自然に生じている分離を測っており，**損失で意図的に構造を作り込んだ場合にそれが使われるか**は扱っていない．
- ラベルは3値の粗い分類であって，演算子列のような**組み合わせ的な手順**ではない．未見の組み合わせへの汎化も測っていない．
- **入力を摂動したときの表現の安定性**は扱わない．
- GQA・SmolVLM はいずれも使われていない．

## 学会で聞かれたら

本研究についての答えは研究文書（`.claude/context.md`）の範囲で書いた．

- **問：どんな論文ですか．**
  答：Qwen3-14B で演繹・帰納・仮説形成の3つのベンチマークをプローブすると第32層で 100% 当たりますが，出典・選択肢数・応答長を残差化するとチャンスまで落ちる，という論文です．当てていたのは推論の種類ではなく形式だ，と主張します．（出所：原典 要旨，§5.2）
- **問：本研究の署名も，質問の形式を読んでいるだけではないですか．**
  答：語数・答えの文字数・yes/no かどうかの3つを残差化しても，読み取り精度は baseline 82.9%，proposal 95.6% で，整合の効果は 13.02pt から 12.67pt へ 0.35pt しか動きません．この3つだけを入力にしたプローブは 35.3% です．（出所：研究文書 §A.1）
- **問：出典や選択肢数は，なぜ除かないのですか．**
  答：全問が単一コーパスの同一生成過程から来ていて，多肢選択でもないので，どちらも定義上ありません．残るのが長さなので，長さと答えの型を除きました．（出所：研究文書 §A.1）
- **問：質問文の語を覚えているだけではないですか．**
  答：質問文の語だけを入力にした分類器は 69.7% で，整合後の表現はそれを 26.2pt 上回ります．質問の書き出しを未見にしても整合の効果は +14.5pt です．ただしこの分類器は，質問文から取れる情報の上限ではありません．（出所：研究文書 §5.1，§A.1）
- **問：原典では落ちたのに，本研究ではなぜ落ちないのですか．**
  答：原典では様式ラベルと出典ラベルが同じ分割なので，出典を除くと様式を定義する変数も抜けます．本研究の署名ラベルは回帰に入っていません．ただ，モデルもデータも違うので，この違いが原因かどうかは本研究では確かめていません．（出所：原典 §5.2，研究文書 §A.1）
- **問：原典の steering と本研究の測定はどう違いますか．**
  答：原典は様式の方向へ steering して，ランダム方向と比べます．本研究は steering をせず，答えを決める方向の中と無作為な方向の中で読み取り精度を比べ，第16層への相対感度を測りました．（出所：原典 §3.6，研究文書 §A.4）
- **問：本研究の貢献は，原典とどう違いますか．**
  答：原典は，高いプローブ精度は内部の計算構造の十分な証拠ではない，と既製のモデルで示しました．本研究は損失で読める構造を作り込み，それでも答えの生成に使われるとは言えないことを示す点が違います．（出所：原典 §8，研究文書 §2）
- **問：原典の推奨に，本研究は従っていますか．**
  答：残差分析とランダムな方向の対照は置きました．出典の予測は，単一コーパスなので当てはまりません．形式を揃えたベンチマークでは確かめていません．（出所：原典 §6.2，研究文書 §A.1，§A.4）
