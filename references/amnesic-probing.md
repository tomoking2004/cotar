# Amnesic Probing: Behavioral Explanation with Amnesic Counterfactuals

**著者**：Yanai Elazar，Shauli Ravfogel，Alon Jacovi，Yoav Goldberg
**掲載**：Transactions of the Association for Computational Linguistics（TACL）2021．arXiv:2006.00995
**原文**：[arXiv](https://arxiv.org/abs/2006.00995)・[ACL Anthology](https://aclanthology.org/2021.tacl-1.10/)

**プローブの精度は，その情報がタスクで使われているかを予測しない——相関はほぼゼロだった．**

## 主張

probing は「モデルが何を符号化しているか」を測るが，そこから**振る舞いについての結論を導くことはできない**．著者らは "the inability to infer behavioral conclusions from probing results" を指摘し，**何が符号化されているかではなく，どう使われているか**に焦点を移す方法を提案する．

中心にある直観は，**ある性質の有用性は，それを表現から取り除く因果的介入の影響を測れば分かる**というものである．

## 手法

### 情報の除去——INLP

**Iterative Nullspace Projection（INLP）** で，ある性質の**線形な**予測可能性を潰す．線形分類器を当てては，その分類器が使う方向の零空間へ表現を射影する，を繰り返す——分類器が多数派クラスの精度しか出せなくなるまで続ける．

こうして作った**反実仮想の表現**（性質を除いたもの）を下流タスクに通し，振る舞いの変化を見る．

### 二つの対照

| 対照 | 何を潰すか |
| --- | --- |
| **Rand** | **同じ本数のランダムな方向**を除く．性能低下が単なる階数の減少で説明できてしまわないかを見る——Rand の低下が Amnesic の低下に迫るなら，その性質はタスクにとって重要ではない |
| **selectivity** | 除いた表現に正解の性質を連結して再学習する．元の性能が戻れば損害は除いた性質に帰せられ，戻らなければ巻き添えで別の情報も落ちている |

### 設定

- **モデル**：BERT（bert-base-uncased），全12層
- **除く性質**：品詞（粗・細），依存関係ラベル，固有表現，句境界
- **下流タスク**：マスク言語モデリング（MLM）
- **データ**：UD Treebank・OntoNotes から10万トークン

## 結果

**probing の精度とタスクでの重要度は相関しない**——Spearman の順位相関は **0.085（p = 0.871）**．著者の言葉では "high probing performance does not entail this information is being used"．

食い違いの具体例：

| 性質 | probing 精度 | 除いたときの MLM の変化 |
| --- | --- | --- |
| 依存関係ラベル | 76% | **−87 ポイント**（決定的に使われている） |
| 句境界 | 83–85% | **+0.2 ポイント**（使われていない．むしろ僅かに邪魔） |

**プローブが最もよく読めた性質が，最も使われていない性質だった．**

Rand との比較では，実際に使われている性質（依存・品詞・固有表現）は Amnesic の低下が Rand を大きく上回り，句境界では両者が同程度になる——**ランダム方向との差が，使われているかどうかの判定になる．**

## 著者が明記した限界

1. **INLP が消せるのは線形な情報だけ**——非線形に符号化された性質や，他の性質と絡み合った性質は残りうる．"One has to be cautious of *causal* interpretations."
2. **後段の層が情報を復元することがある**——巻き添えの損害か，除去が不完全かのどちらか．
3. **性質どうしの重要度は比べられない**——性質ごとに除くべき次元数が違うため．
4. **手法依存**——非線形な除去法を使えば結論が変わりうる．

## 射程の外

- **言語モデル単体**（BERT）であって，VLM ではない．
- **学習による介入を行わない．** 既にある表現から情報を除く方向の操作であり，**損失で構造を作り込んだ場合**は扱わない．
- 除く対象は品詞・依存・固有表現といった**言語学的な注釈**で，解き方の手順ではない．
- 下流タスクは MLM であって，質問応答の正解率ではない．
