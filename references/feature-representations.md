# What shapes feature representations? Exploring datasets, architectures, and training

**著者**：Katherine L. Hermann，Andrew K. Lampinen（ともにスタンフォード大学．二人は同等貢献）
**掲載**：Advances in Neural Information Processing Systems 33（NeurIPS 2020），pp. 9995–10006．arXiv:2006.12433 v2（2020-10-22．v1 は 2020-06-22）
**原文**：[NeurIPS Proceedings](https://proceedings.neurips.cc/paper/2020/hash/71e9c6620d381d60196ebe694840aaaa-Abstract.html)・[arXiv](https://arxiv.org/abs/2006.12433)

**二つの特徴がラベルを冗長に予測するとき，モデルは一方を優先して表現し，その選好は学習前のモデルから最も線形に読み出せた特徴を反映する．**

## 位置づけ

特徴とラベルの関係を直接統制できる合成データを使い，モデルがどの特徴を表現するかを，decoding と表現類似度分析（RSA）で調べた研究．学習による**強化**（enhancement）と**抑制**（suppression）の両方を，学習前のモデルからの decodability の増減として測る．

## 主張

1. **多くの入力特徴は，学習前のモデルの上位層で既に部分的に表現されている．** 学習は課題に関係する特徴を強化し，課題に関係しない特徴と，課題に関係する特徴の一部を抑制する．抑制された特徴も完全には消えず，多くの場合なお部分的に読み出せる（6章）．
2. **二つの特徴がラベルを冗長に予測すると，モデルは一方を選好する．** 選好の構造は**学習前の decodability** に沿う．
3. **モデルが「怠ける」場合がある．** "suppress a more predictive feature in favor of an easier-to-extract, but less predictive, feature"．
4. **表現の類似度は容易な特徴に支配される．** 容易な特徴は，困難な特徴よりも，試行間で一貫した表現を生む．容易な特徴と困難な特徴の両方を答えるよう学習した多課題モデルの表現は，容易な特徴だけで学習したモデルの表現によく似る．

## 手法

### decodability の測り方

学習済みモデルがどの特徴を表現しているかを決めるために，学習済みで凍結したモデルのある層の活性から，**線形層一つ＋softmax（多項ロジスティック回帰）**で特徴ラベルを予測するデコーダを学習する．デコーダを学習するラベルは，一般には，ネットワークを学習したラベルと同じではない．

| 項目 | 設定 |
| --- | --- |
| 読む層 | AlexNet の pool3・fc6・fc7，ResNet-50 の pre-pool・post-pool（global average pool の前後） |
| デコーダの学習（視覚モデル，付録 B.1.1） | Adam，250 エポック，バッチ 64．学習率 6 値と weight decay 6 値の組合せから，検証精度の最も高いデコーダを選ぶ |
| デコーダの学習（Binary Features，付録 B.1.2） | 5000 エポック，学習率 10⁻³．weight decay もハイパーパラメタ探索も使わない |
| チャンス水準 | Trifeature 14.3%（1/7），Navon 4.3%（1/23） |

### 類似度の測り方

層ごとに表現の非類似度行列（RDM）を相関距離で作り，二つの RDM の上三角どうしの Pearson 相関で比べる（RSA）．CKA と，ユークリッド距離を RDM の尺度にした RSA でも同様の結果になると報告する（付録 B.4，図 A.13）．

## 実験設定

### データセット

| データ | 構成 | 規模 |
| --- | --- | --- |
| **Navon** | 大きな文字（shape）を小さな別の文字（texture）の写しで描く．shape と texture の組合せ（26×26）を 5 位置に描画 | **3250** 項目（shape と texture が同じ組を除いた後）．出力 23 クラス |
| **Trifeature** | 形10・テクスチャ10・色10 の組合せ．3章の実験では特徴は互いに無相関 | 学習 **3430**，検証 **3570**．出力 7 クラス（特徴の種類ごとに 7 クラスで学習し，3 クラスを保留） |
| **Trifeature (Correlated)** | 一対の特徴について，一方が他方に一致する条件付き確率を 0.1（無相関）〜1（完全相関）で設定 | 学習 **4900** |
| **Binary Features**（非視覚） | 32 要素の二値ベクトル．前半 16 要素が線形層一つで取り出せる「容易」な特徴を，後半 16 要素が XOR の計算を要する「困難」な特徴を担う | 学習 **256**，評価・デコード **512** |

### モデルと学習

- **視覚**：AlexNet と ResNet-50．Adam（学習率 3×10⁻⁴，weight decay 10⁻⁴），バッチ 64，90 エポック．重みの初期値は実験間で固定．
- **Binary Features**：5層 MLP（層の大きさ 256・128・64・64）．交差エントロピー損失，全バッチ勾配降下（lr = 0.001）．困難な特徴の予測力（predictivity）は **0.9 で固定**，容易な特徴の予測力を **0.5〜1** で変える．図 6・図 8 は**条件ごとに 5 回**の試行．

## 結果

### 学習前のモデル（3.1節）

- 二つのデータセットと二つの構造を通じて，視覚特徴は学習前のモデルの上位層から有意にチャンスを上回って読める．Trifeature での順序は **color > shape > texture**．
- 色は AlexNet の最終畳み込み層と ResNet-50 から**完全に**読める．
- Navon の shape・texture は AlexNet の最終畳み込み層から **60% 超**（チャンス 4.3%），ResNet-50 の global average pool の前で **約 25%**．

### 学習後——強化と抑制（3.2節）

- **標的特徴は強化**される（既に天井に達していない限り，学習前のモデルより decoding 精度が高い）．
- **非標的特徴は部分的に抑制**され，decoding 精度は学習前を下回るが，**チャンスより上に残る**．

### 冗長な特徴（条件付き確率 1.0，4.1節）

- shape と color が相関する課題では，AlexNet で色がほぼ完全に読め，shape は pool3 と fc6 で**学習前のモデルより読みにくくなる**．
- shape と texture が相関する課題では，shape の decodability が texture よりかなり高く，texture は pool3 で学習前のモデルより読みにくくなる．
- **この選好の構造は，学習前のモデルからの decodability の順と一致**する．同じ順序は ResNet-50 でも成り立つ．

### 信頼できるが困難な特徴 vs 容易だが弱い特徴（Binary Features，4.3節）

| 条件 | 起きること |
| --- | --- |
| 容易な特徴の予測力が低い | 困難な特徴に頼る |
| 容易な特徴の予測力 **0.8**（困難な特徴は **0.9**） | **容易な特徴を選好する**——予測力が並ぶ前に乗り換える |

- **容易な特徴は，予測力がなくても比較的高い精度で読める．困難な特徴は，使われているときにだけ確実に読める**——"the difficult feature could be decoded reliably only when the feature-specific tests showed it was being used"．非線形のデコーダでも，困難な特徴をあまり高い精度では回復できない（図 A.10）．
- 対応する特徴に予測力がなくても，どちらの入力の組からも，入力単位一つの値は **約 80%** で読める．著者はこれを，関係しない入力が完全には抑制されないことの表れとする．
- 容易な特徴の予測力が 0.65 の例（図 A.9）では，容易な特徴は学習前から **約 75%**（チャンス 50%）で読め，困難な特徴はチャンスを上回っては読めない．

### 表現の類似度（RSA，5章）

| 比較（Trifeature，無相関） | 類似度（平均，bootstrap 95%CI） |
| --- | --- |
| texture の課題で学習した二つのモデル | **0.408** [0.394, 0.420] |
| shape の課題で学習した二つのモデル | 0.624 [0.615, 0.632] |
| 学習前の二つのモデル | 0.619 [0.542, 0.702] |

- 同じ課題で学習したモデルどうしは，別の課題で学習したモデルどうしよりはるかに似る．ある課題で学習したモデルは，**別の課題で学習したモデルよりも学習前のモデルに似る．** 課題の影響に比べ，構造や層の影響は小さい．
- Binary Features では，**両方の特徴を分類するよう学習した多課題モデルの表現が，予測力の高い容易な特徴で学習したモデルの表現によく似る**——著者は，困難な特徴も表現しているときでさえ，容易な特徴が多課題モデルの表現を支配することを示唆するとする．

## 著者が明記した限界

- **設定の広さ**："future work should explore broader settings"．
- 全結合層の幅が特徴表現に与える影響を，今後の問いとして挙げる（AlexNet の全結合層は出力のクラス数に比例して狭めてある）．
- 検証集合の特徴相関を学習集合に揃えたが，揃えない設計も妥当だとする（脚注2）．

## 著者が述べる含意

- **ラベルに関係する特徴が使われるとも，表現されるとも仮定すべきでない**——"practitioners should not assume that label-relevant features will be used, or even represented by, a model"．
- 学習前のモデルの表現を分析することは，モデルがどの特徴を使いそうかを予測する安価な方法になりうる．
- **表現の類似度は，複雑な設定や多課題の設定で誤解を招きうる**——"representational similarity is dominated by easier features"．複数の特徴や複数の課題で学習したモデル（や脳）に RSA を当てるときは，注意して解釈すべきだとする．

## 射程の外

- **実験の対象は画像分類の AlexNet・ResNet-50 と，5層 MLP である．** 言語モデル・VLM・Transformer を使った実験は見当たらなかった（検索した語：language，transformer，attention，vision-language，VLM．言語モデルは，序論で BERT を転移の出発点の例として挙げる一か所だけに現れる）．
- **特徴は色・形・テクスチャと，合成した二値の特徴**であり，推論手順や問いの構造ではない．
- **学習時に表現へ補助損失を掛ける介入は見当たらなかった**（検索した語：auxiliary，regulariz．どちらも参考文献の題にだけ現れる）．操作するのは，データ中の特徴とラベルの関係（特徴どうしの相関，特徴の予測力）と，学習する課題である．
- 特徴に「頼る」度合いを測るのは Binary Features の実験だけで，もう一方の特徴の予測力を無くしたテスト集合での成績で測る（4.3節）．視覚の実験で報告するのは decodability と表現の類似度である．ヤコビアンなど勾配に基づく感度の測定は見当たらなかった（検索した語：Jacobian，gradient，sensitiv．gradient は学習法の記述にだけ現れる）．
