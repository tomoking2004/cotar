# Supervised Contrastive Learning for Pre-trained Language Model Fine-tuning

**著者**：Beliz Gunel，Jingfei Du，Alexis Conneau，Ves Stoyanov（Stanford University，Facebook AI）
**掲載**：ICLR 2021．arXiv:2011.01403 v3，2021-04-02（v1 は 2020-11-03）
**原文**：[OpenReview](https://openreview.net/forum?id=cu7IUiOhujH)・[arXiv](https://arxiv.org/abs/2011.01403)

**事前学習済み言語モデルの微調整で，交差エントロピーと [CLS] 表現上の教師あり対照項（SCL）を重み λ で重み付き平均すると，少数ショットとノイズのある学習データで精度が上がる．**

以下の数値・表番号・引用は，すべて v3 のものである（v1・v2 は表番号が違い，付録の表 8〜10 を持たない）．

## 位置づけ

教師あり対照項を**微調整の目的関数**に入れ，交差エントロピーとの重み付き平均として使った例．原文の記述では，対照項は "the l2 normalized final encoder hidden layer before the softmax projection" に掛かり，別個の射影 head は本文に現れない．著者は Khosla ら（2020）の supervised contrastive loss を関連研究に挙げ，付録の表 8 で Khosla らの二段階の方法と比べている．

本研究との対応は次の範囲にとどまる．

- **同じ点**：対照項を主損失と同時に最適化する．同じラベルの表現どうしを近づけ，違うラベルの表現どうしを遠ざける．l2 正規化した表現に掛ける．本研究も射影を挟まない（研究文書 §3.3）．
- **違う点**：原典は `(1 − λ) L_CE + λ L_SCL` の重み付き平均で，λ = 0.9 が最良とされる．本研究は `L_LM + λ L_align` の加算で λ = 0.1 である（研究文書 §3.2）．原典は最終層の [CLS]，本研究は第16層のプロンプト末尾の位置（同 §3.3）．原典の温度は格子探索で選ぶ値，本研究は学習可能なパラメタ（同 §3.2）．原典のラベルはタスクの正解クラス，本研究は署名（同 §3.1）．

## 主張

- 交差エントロピー単独の微調整に，同じクラスの例を近づけ異なるクラスの例を遠ざける教師あり対照項（SCL）を加える．
- **特殊な構造・データ増強・メモリバンク・追加の無ラベルデータを使わずに**，RoBERTa-Large の強い基準線を，GLUE の複数のデータセットの少数ショット設定で上回る（要旨）．
- 微調整の学習データのノイズに対してより頑健になり，ラベルの少ない関連タスクへの汎化もよくなる（要旨）．

## 手法

### 目的関数

```
L = (1 − λ) L_CE + λ L_SCL                                                     (1)

L_CE  = −(1/N) Σ_{i=1}^{N} Σ_{c=1}^{C} y_{i,c} · log ŷ_{i,c}                    (2)

L_SCL = Σ_{i=1}^{N} −1/(N_{y_i} − 1) Σ_{j=1}^{N} 1_{i≠j} 1_{y_i=y_j}
          log [ exp(Φ(x_i)·Φ(x_j)/τ) / Σ_{k=1}^{N} 1_{i≠k} exp(Φ(x_i)·Φ(x_k)/τ) ]  (3)
```

- `N`：バッチの大きさ（"a batch of training examples of size N"）．対照項はバッチの中で計算する
- `N_{y_i}`：バッチの中で y_i と同じラベルをもつ例の総数
- `τ > 0`：温度．"an adjustable scalar temperature parameter that controls the separation of classes" と説明される．温度が低いと，分けにくい例の影響が増し，事実上より難しい負例を作ることになる，と著者は述べる
- `λ`：課題と設定ごとに調整する重み．**交差エントロピー側に (1 − λ) が掛かる**重み付き平均である点に注意（単純な加算ではない）

### どの表現に掛けるか——[CLS] の最終層，l2 正規化

- "Φ(·) ∈ R^d denotes an encoder that outputs the l2 normalized final encoder hidden layer before the softmax projection"．
- 単文・文対いずれのタスクでも，Φ(x_i) は "uses the embedding of [CLS] token as the representation for example" x_i．
- **別個の射影 head は本文に見当たらない**（全文で "projection" は "softmax projection" の2か所だけ，"head" は関連研究の "classification head" の1か所だけ）．
- l2 正規化と調整可能な温度はいずれも性能を上げる，と著者は経験的な観察として述べる．

### 対照群 CE+CE

SCL 項を交差エントロピーに置き換え，**l2 正規化と温度スケーリングは残した**群（付録の表 8・9・10）．著者はこれを，l2 正規化と温度スケーリングの重要さを調べる ablation と位置づける．

## 実験設定

- **モデル**：RoBERTa-Large（fairseq）．バッチの大きさの比較（表 6・9）は RoBERTa-Base
- **最適化**：Adam，学習率 1e-5，dropout 0.1．バッチ 16（特記なき限り）
- **探索**：λ ∈ {0.1, 0.3, 0.5, 0.7, 0.9, 1.0}，τ ∈ {0.1, 0.3, 0.5, 0.7} の格子．テスト精度が最良のモデルは，全実験設定を通じて "overwhelmingly" τ = 0.3，λ = 0.9 の組を使う，と著者は述べる
- **少数ショット**：SST-2・QNLI・MNLI で N = 20，100，1000．学習集合を10通り無作為に抽出し，検証精度で上位3モデルのテスト精度の平均±標準偏差を報告．GLUE の検証集合の半分をテスト集合とし，同じ検証集合から 500 例を検証用に抽出する
- **全データ**：GLUE 6タスク（SST-2，CoLA，MRPC，RTE，QNLI，MNLI），乱数種10．GLUE の元の検証集合で報告
- **ノイズのある学習集合**：WMT'18 の英独・独英の翻訳モデルによる逆翻訳．ビーム探索でなく無作為サンプリングを使い，サンプリング温度 T（表では 0.3，0.5，0.7，0.9）を上げてノイズを強める．教師あり例と増強例の比は 1:3．T = 0.9 では文法の誤りや事実の誤りが一部に入る
- **p 値**：基準線に対する p 値を併記する．検定の種類は本文に見当たらない（検索した語：t-test，Wilcoxon，significance test）
- **エポック数**：本文に見当たらない（"epoch" は関連研究と，検証集合の大きさの説明の2か所だけ）

| 20 | CE | 85.9±2.1 | 65.0±2.0 | 39.3±2.5 |
| 20 | CE+SCL | 88.1±3.3 | 75.7±4.8 | 42.7±4.6 |
| 20 | p 値 | 5e-10 | 1e-46 | 1e-8 |
| 100 | CE | 91.1±1.3 | 81.9±0.4 | 59.2±2.1 |
| 100 | CE+SCL | 92.8±1.3 | 82.5±0.4 | 61.1±3.0 |
| 100 | p 値 | 3e-17 | 1e-20 | 2e-4 |
| 1000 | CE | 94.0±0.6 | 89.2±0.6 | 81.4±0.2 |
| 1000 | CE+SCL | 94.1±0.5 | 89.8±0.4 | 81.5±0.2 |
| 1000 | p 値 | 0.6 | 1e-12 | 0.5 |

**ラベル付きの例が増えるほど，基準線に対する改善は小さくなる**，と著者は述べる（§5.1）．N = 20 の QNLI で **10.7 ポイント**の改善（p 値 1e-46）．N = 1000 の SST-2（p 値 0.6）と MNLI（p 値 0.5）の改善は統計的に有意でない，と著者自身が認めている．

**対照群 CE+CE（N = 20，表 10）**：SST-2 86.5±2.2，QNLI 75.1±3.5，MNLI 40.8±3.7．平均値はいずれも CE+SCL（88.1，75.7，42.7）より低い．QNLI では CE+CE が CE（65.0）を 10.1 ポイント上回り，CE+SCL との差は 0.6 ポイントである（差はこちらの計算．著者はこの比較について本文で述べていない）．

統計的に有意なのは MRPC と QNLI だけである，と著者自身が認めている（§5.3）．付録の表 8 では CE+CE の平均は 89.9 で，CE+SCL の平均（90）との差は 0.1 である（差はこちらの計算）．

**バッチの大きさ（RoBERTa-Base，表 6）**：バッチ 16，64，256 のいずれでも，4タスク（SST-2，CoLA，QNLI，MNLI）すべてで CE+SCL の平均精度が CE を上回る．例えば MNLI は 16 で 84→85.3，256 で 84.4→86.6．CE+SCL はバッチを 16 から 256 へ増やすと4タスクとも精度が上がる．代わりに学習速度が落ち，毎秒の平均更新数はバッチ 16 で 15.9（CE）から 15.08（CE+SCL）へ，バッチ 256 で 2.46 から 1.54 へ下がる．

**関連タスクへの転移（SST-2 の全学習集合で微調整したモデルを転移．クラスあたり20例，N = 40．表 7）**：Amazon-2 で 87.4±6.4 → 90.3±0.6，Yelp-2 で 90.8±2.2 → 91.2±0.4．SCL 項は転移元と転移先の両方で使う．著者は，学習集合の抽出にわたる分散が大きく減ると述べる．

## 著者が明記した限界

- **より大きなバッチは今後の課題**："We hypothesize larger batch sizes lead to better performance, but we leave that for future work"（原文の文はこの後も続く）．著者はこの仮説の証拠として，RoBERTa-Base でバッチの大きさを変えた表 6 を挙げる．
- **有意でない結果**：少数ショットの N = 1000 の SST-2 と MNLI，全データの MRPC と QNLI 以外の4タスクは，改善が統計的に有意でないと著者が認めている．
- **NLP のデータ増強は未成熟**："data augmentation methods in NLP and their effects on the downstream tasks are neither as effective nor as well understood" as their counterparts in the computer vision domain．
- **今後の課題**："In future work, we plan to study principled and automated data augmentation techniques for NLP"——SCL を半教師あり・自己教師ありの設定へ広げるため．

## 射程の外

- **実験の対象は単文・文対の分類の微調整**（GLUE の6タスクと Amazon-2・Yelp-2）である．VLM，VQA，生成の損失への適用は見当たらない（検索した語：VQA，visual question，vision-language，multimodal，GQA．"generation" は関連研究の他者の成果の1か所だけ）．損失そのものは，画像の encoder（例として ResNet）にも適用できると著者は述べるが，実験はしていない．
- **ラベルはタスクの正解クラス**（感情・含意など）である．正解とは別のラベル（本研究の署名，研究文書 §3.1）で対照項を掛ける設定ではない．
- **表現は最終層の [CLS]**．中間層への適用や層の比較は見当たらない（検索した語：intermediate，layer）．
- **定量的な評価は精度と学習速度（毎秒の更新数）**である．表現については tSNE の図（図 2，付録の図 3）で，SCL 項が同じラベルの例をよりまとまったクラスタにすると定性的に述べるにとどまる．プローブによる測定は見当たらない（検索した語：probe，probing，linear）．
- **最良とされるのは λ = 0.9（SCL 側の重みが大きい）**で，λ ごとの結果を示す表は無い．
- 温度は格子探索で選ぶ値で，学習可能な温度は見当たらない（検索した語：learnable，learned temperature）．
